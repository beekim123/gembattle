### 一、造型、体素特点与场景要求
注意：文案、皮肤名、技能名严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。正面统一朝向 `+Y`，`z = 0` 贴近水面/低悬空 `lift = 2~4`。

1. **主体造型**（推荐体素盒约 `38 × 40 × 44`）
   - 下半身是弯曲舒展的**大鳞片人鱼长尾 + 宽大扇形尾鳍**（环绕底座轻盈浮游，尾鳍截面 ≥ 2 格防碎），腰际配一圈如水裙般外张的贝壳/鳍片装饰；
   - 上半身线条优雅，双耳生有张开的像素耳鳍，头戴贝壳/珊瑚头冠，飘逸的波浪长发垂落肩后（额前留空，确保 0.6 俯视下双眼清晰可读）；
   - 右手持一柄**珊瑚三叉戟**（三叉尖端带独立自发光色槽的潮汐水核，叉柄与叉尖半径 ≥ 1.05 防断），左手微抬如在吟唱控水；
   - **优雅浮游待机（8 帧）**：鱼尾与宽尾鳍左右柔缓摆动、长发与肩鳍微飘、三叉戟随节奏轻晃，脚下常驻一圈缓缓荡开的细水纹。

2. **场景与受击靶**
   - 圆形浅海礁石水台底座（外圈浅水浪花与礁石边环，中央湿润石台带细微水波纹理），前方 `+Y` 方向放置像素堆叠训练靶桩（受击抖动、水花四溅、被大水泡罩住漂浮等反馈）。

### 二、4 套色系（零重建模一键换色，快捷键 `C` 或 HUD 按钮切换）
必须基于 `Uint8Array` 索引网格实现 `recolorAsset(skin)`（`< 2ms` 按索引重刷长条图集并清空精灵缓存回收至对象池，**严禁重跑 SDF 建模**），同时联动歌声涟漪、喷泉水柱、巨浪与水泡的配色：
1. **蔚蓝碧绿（浅海经典）**：海碧鱼尾 + 珍珠白上装与贝壳冠 + 靛青长发 + 蔚蓝浪花与白沫水柱特效；
2. **珊瑚粉金（礁石款）**：珊瑚粉橘鱼尾 + 暖金冠饰与三叉戟 + 浅金发色 + 粉金潮汐波纹与珊瑚彩泡特效；
3. **深海蓝紫（深海精锐）**：深海蓝紫鳞尾 + 苍蓝发色 + 青紫亮核三叉戟 + 靛紫激流与深蓝巨浪特效；
4. **霜白青鳞（寒海款）**：冰青白鳞尾 + 银白长发与冰晶三叉戟 + 冰白寒浪与碎冰水柱特效。

### 三、4 个技能演出（按钮或快捷键 `1~4` 触发）
所有技能展现控水与歌声的流畅大范围表现，包含完整 **前摇 → 释放与特效 → 靶桩反馈 → 归位**：
1. **歌声涟漪（1）**：海妖微仰头颅、双臂轻展吟唱，以自身为中心接连荡开 4 圈柔和扩张的像素水波纹，空中飘出若干跳动的像素小音符飞向靶桩，靶桩随节拍左右摇晃。
2. **水流喷泉（2）**：挥动珊瑚三叉戟直指靶桩 → 靶桩脚下先出现高速旋转的水圈预警 0.35 秒 → 轰然冲起一根粗壮旋转的像素水柱（多层体素水环叠加 + 顶部炸开白沫水花），将靶桩整根向上顶起并剧烈抖动，随后水柱回落溅满水滴。
3. **巨浪拍击（3）**：双臂高举三叉戟，身后迅速汇聚起一道弧形卷曲的立体像素浪墙，轰隆向前推卷横扫整个石台与靶桩，浪头翻涌大量像素白沫与飞溅水珠，带轻震屏效果。
4. **水泡禁锢（4）**：三叉戟尖凝出一颗饱满的像素大水泡（带亮色反点与半空泡环）缓缓飘向靶桩，将靶桩严密罩入其中并让靶桩在泡里离地上下晃动 1.2 秒，最后啪地炸开满屏飞溅水花与地面水渍。

### 四、工程性能与强制自检闭环（对照 `README.md` v2）
1. **第 0 步先写空间坐标预算表**，确保盘绕鱼尾、扇形尾鳍、长发、头冠、耳朵鳍与珊瑚三叉戟的坐标清晰不穿模，三叉戟与尾鳍厚度 ≥ 2 格，双眼与叉尖水核 0.6 俯视零遮挡。
2. **极速建模与旋转满帧架构**：
   - `Uint8Array` + 部件级 `fillAABB` + `despeckle()` + 垂直 3 档色阶 / 腔体 AO / 白名单 Crease AO + 单张长条图集（保留 `grid` 供 `recolorAsset` 换色），8 帧建模耗时目标 `< 120ms`；
   - 定倍角度烘焙缓存 `BAKE_SCALE = 2.5`（精确 `step = 2`、`1px` 半步压实、`3°` 量化 + 对象池 + 滚轮缩放不清空缓存）；
   - 预渲染天空 `bgc` + `2×` 小地表缓冲集成双层投影/水圈涟漪/水渍 + 缓存模式精灵直绘 `dctx` + 内外发光 `destination-out` 裁切（从 `minGlowZ` 起）+ `1/4` 独立小画布 `ebctx` 真降采样模糊；
   - HUD 支持：4 套色系一键切换 (`C`)、4 个技能 (`1~4`)、自动旋转、单体描边、模式切换（游戏缓存 / 高清逐层 / 复古低分）、导出带色系名长条 PNG、最短角路径重置视角、实时性能栏（建模耗时 / FPS / 单帧 ms / 绘制次数 / 色数 / 缓存）。
3. **强制验收闭环**：
   - 跑 Node 自动化脚本校验：色数 ≤ 48、无重色、无未着色、无孤立碎点、双眼与三叉戟水核正面 `+Y` 及 0.6 俯视射线遮挡 = 0、切换 4 套色系耗时 < 5ms；
   - 本地静态服务 + 浏览器实机验收：零 Console 报错；旋转 360° 检查鱼尾、长发与三叉戟完整不断裂；测试 4 套色系与 4 个技能演出；连续拖拽/自动旋转稳跑 60~120fps（单帧 < 2ms）；亲自审片并至少迭代打磨 1 轮后收尾清理临时服务。
