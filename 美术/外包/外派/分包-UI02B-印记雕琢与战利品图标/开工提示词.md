# 开工提示词：UI-02B 印记、雕琢与战利品图标（轻量包）

你是资深像素游戏 UI 美术与 Canvas 2D 前端工程师。请严格按本附件中的 `设计文档-印记雕琢与战利品图标.md` 与 `verify.mjs`，独立完成并打包 **`bundle_ui02b_icons.zip`**。

## 一、交付物（必须且仅包含以下 3 个文件，位于 zip 内的 `bundle/` 目录）
1. `bundle/pack_icons.js`
2. `bundle/manifest.json`
3. `bundle/交付说明.md`

## 二、核心硬约束（违背任意一条即不通过）
1. **必须合并挂载，严禁覆盖**：
   - 使用 `Object.assign(window.Code00ArtPacks.cards = window.Code00ArtPacks.cards || {}, { iconsVersion: 1, iconsName: '...', initIcons, drawSealIcon, drawLootBadge, drawCarveBadge })`；
   - **绝对不能**写 `window.Code00ArtPacks.cards = { ... }`（会覆盖 UI-02A 的卡牌接口）。
2. **完整覆盖 20 枚像素图标**：
   - `drawSealIcon(ctx, sealId, cx, cy, size, opts)`：全部 10 个 `sealId`（`shatter_tide`、`desperate`、`double_white`、`white_echo`、`rainbow_bridge`、`ring_keep`、`wide_bag`、`hold_edge`、`leap`、`chain_surge`）+ 未知 ID 兜底；
   - `drawLootBadge(ctx, lootKind, cx, cy, size)`：全部 6 个 `lootKind`（`carve`、`seal`、`arcana`、`hand`、`heal`、`attr`）+ 未知 ID 兜底；
   - `drawCarveBadge(ctx, kind, cx, cy, size)`：全部 4 个 `kind`（`sharp`、`twin`、`pierce`、`overflow`）+ 未知 ID 兜底。
3. **一次烘焙，零卡顿**：
   - `initIcons(makeCanvas)` 预烘焙 20 张 `24×24` 或 `32×32` 离屏画布；
   - 耗时 ≤ 30 ms，离屏总显存 ≤ 1.00 MB；
   - 绘制时设 `ctx.imageSmoothingEnabled = false`（画完恢复 `ctx.restore()`）。
4. **绝对零违规**：
   - 零 `.filter =` / `ctx.filter`；
   - 零 `shadowBlur`；
   - 零外部图片/URL/字体（`new Image`、`http://`、`https://`、`fetch(`）；
   - 字符串字面量严禁出现任何禁用字（`灯、烬、影、夜、魂、噬、幽、渊、星、光` 及 `守×者`、`×之×`）。
5. **精炼高效、严防超时**：
   - 用简洁的像素几何绘制辅助函数（如 `r(x,y,w,h,c)`、`frame(...)`、`sym(...)`）组合出 20 枚高辨识度像素徽章；
   - `bundle/pack_icons.js` 控制在 **350 ~ 650 行**，短小精悍、剪影锐利，切勿写上千行逐像素字符串数组导致生成超时。

## 三、执行与打包要求（务必遵守）
1. 在你的沙箱环境中，**直接用单个脚本一次性生成全部 3 个文件**；
2. 用附件里的 `verify.mjs`（原样保存并在同目录执行 `node verify.mjs`）跑通全部硬性校验，确认输出 `✅ 全部硬性校验通过！`；
3. 打包生成可下载的 **`bundle_ui02b_icons.zip`**（zip 根目录包含 `bundle/pack_icons.js`、`bundle/manifest.json`、`bundle/交付说明.md`）；
4. **回复正文严禁贴任何代码、JSON 或文档全文**，只简要报告校验结果（初始化耗时、离屏画布张数与 MB、行数）并提供 `bundle_ui02b_icons.zip` 下载链接。若未打包完成直接停下汇报进度。
