### 一、造型、体素特点与场景要求
注意：文案、皮肤名、技能名严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。正面统一朝向 `+Y`，`z = 0` 贴地。

1. **主体造型**（推荐体素盒约 `34 × 34 × 30`）
   - 饱满圆润的半球水滴形果冻躯体（底部略宽贴地、顶部圆滑微尖），用 `smin` 打造顺滑曲面；
   - **体素内部层次感**：不要画成死板实心纯色块——在内部偏中上埋入 1 颗略亮的高对比弹性内核（或表面浮现 2~3 颗大小错落的立体像素小气泡），配合前上方清晰的 2×2 深色豆豆眼与一点亮白反点（0.6 俯视绝不遮挡）；
   - **果冻 Q 弹待机（8 帧）**：通过相位的体积守恒挤压/拉伸（`scaleXY` 与 `scaleZ` 反向呼吸：`1.08×0.90 ↔ 0.92×1.10`），让史莱姆像真正有弹性的胶质一样一duang一duang微微晃动；
   - **皇冠金皮肤专属小彩蛋**：切到「皇冠金」色系时，头顶可切换戴上一顶精致的小巧像素金冠（带红宝石点缀，用独立部件或附加小模型叠在头顶 `z` 处，随弹性呼吸一起上下轻颠）。

2. **场景与受击靶**
   - 圆形苔藓林地/石砖底座（周期纹理 + 固定石边环），前方 `+Y` 方向放置像素堆叠训练靶桩（受击抖动 + 表面溅液滴 + 地面短暂液渍残留）。

### 二、4 套色系（零重建模一键换色，快捷键 `C` 或 HUD 按钮切换）
必须基于 `Uint8Array` 索引网格实现 `recolorAsset(skin)`（`< 2ms` 按索引重刷长条图集并清空精灵缓存回收至对象池，**严禁重跑 SDF 建模**），且全部技能的液球、水花、液浪、地面液渍颜色全部同步切换：
1. **水蓝（经典）**：清透水蓝体表 + 冰白亮边 + 浅青内核 + 蓝白水花特效；
2. **毒绿（酸液）**：亮毒绿体表 + 酸黄绿亮边 + 亮黄绿冒泡内核 + 冒泡毒渍特效；
3. **熔岩红（火胶）**：暗赤红表层 + 橘红中层 + 炽黄内核（带自发光色槽）+ 灼热碎火与焦渍特效；
4. **皇冠金（稀有）**：金属香槟金与暖金表层 + 亮白锐利反点 + 头顶小金冠 + 金色液滴与金粉飞溅特效。

### 三、4 个技能演出（按钮或快捷键 `1~4` 触发）
所有技能包含完整 **蓄力前摇 → 释放与特效 → 靶桩与地面反馈 → 回待机**，特效统一使用像素/体素风格：
1. **弹跳砸地（1）**：史莱姆先猛地压扁蓄力（宽扁弹性形变）→ 划出高抛物线跃向靶桩正上方并重重砸下（微震屏）→ 落地压扁回弹两次、四周炸开一圈飞溅的体素液滴与地面大滩水渍，随后蹦跳回原位。
2. **连吐液球（2）**：身躯一鼓一缩连续张口吐出 3 颗弹跳体素液球，呈小弧线连续砸中靶桩，每发命中炸散像素水花并在靶桩脚下留下短暂液渍。
3. **一分为二夹击（3）**：原地左右剧烈拉伸，啪地裂成 2 只略小的迷你史莱姆，沿左右两侧对称圆弧包抄滑冲撞向靶桩，把靶桩撞得连抖后，两只小史莱姆弹回中线重新合体成一大只并欢快一弹。
4. **膨胀震波（4）**：原地猛吸气不断膨胀变大（伴随内部气泡翻涌抖动与地面预警圆环）→ 到达极限后砰地收缩，贴地喷涌出一圈厚实扩张的环形像素液浪，把周围溅满细碎水花并震得靶桩后仰。

### 四、工程性能与强制自检闭环（对照 `README.md` v2）
1. **第 0 步先写空间坐标预算表**，确认本体、眼睛、气泡、金冠、靶桩范围无穿模与遮挡。
2. **极速建模与旋转满帧架构**：
   - `Uint8Array` + 部件级 `fillAABB` + `despeckle()` + 垂直 3 档色阶 / 腔体 AO / 白名单 Crease AO + 单张长条图集（保留 `grid` 供 `recolorAsset` 换色），8 帧建模耗时目标 `< 100ms`；
   - 定倍角度烘焙缓存 `BAKE_SCALE = 2.5`（精确 `step = 2`、`1px` 半步压实防漏缝、`3°` 量化 + 对象池 + 滚轮缩放不清空缓存）；
   - 预渲染天空 `bgc` + `2×` 小地表缓冲集成投影与地面液渍 + 缓存模式精灵直绘 `dctx` + 内外发光 `destination-out` 裁切（从 `minGlowZ` 起）+ `1/4` 独立小画布 `ebctx` 真降采样模糊；
   - HUD 支持：4 套色系一键切换 (`C`)、4 个技能 (`1~4`)、自动旋转、单体描边、模式切换（游戏缓存 / 高清逐层 / 复古低分）、导出带色系名长条 PNG、最短角路径重置视角、实时性能栏（建模耗时 / FPS / 单帧 ms / 绘制次数 / 色数 / 缓存）。
3. **强制验收闭环**：
   - 跑 Node 自动化脚本校验：色数 ≤ 48、无重色、无未着色、无孤立碎点、双眼正面 `+Y` 与 0.6 俯视射线遮挡 = 0、切换 4 套色系耗时 < 5ms；
   - 本地静态服务 + 浏览器实机验收：零 Console 报错；检查 4 套色系外观与特效色联动、4 个技能完整演出；连续拖拽/自动旋转稳跑 60~120fps（单帧 < 2ms）；亲自审片并至少迭代打磨 1 轮后收尾清理临时服务。
