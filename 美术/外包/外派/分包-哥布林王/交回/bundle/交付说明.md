## 三、外观、骨骼与性能设计要点

1. **四大标志记忆点**：
   - 歪戴巨型锯齿金冠（`crown` / `crownCharged` / `crownAskew`）：冠额并排镶嵌红、绿、蓝三原色大宝石，常态微歪、蓄力脉动、破盾歪弹后左手扶正；
   - 宽大狞笑头颅与金环双尖耳（`head` + `earL`/`earR`）：继承苔绿哥布林血脉，表面落点精雕 3×2 锐利邪眼（0.6 俯视 0 遮挡，`eyeGlint` 不进 `glowKeys`），超长金环尖耳用 `pivotToWorldXY` 锁死耳根；
   - 大肚腩战裙、赤红镶金披风与满溢大宝袋（`torso` + `cape` + `lootSack`）：袋口堆满金锭与三色晶石，二阶弹簧滞后颠簸并在巡营与蛮冲时颠落金粒；
   - 两段式手臂与黑铁镶金巨型狼牙重锤（`upperArm` + `forearm` + `mace`/`maceCharged`/`maceRaised`）：小臂滞后随动，重锤握柄枢轴锁死右手腕零脱节。
2. **防身腿分离与零穿模**：
   - `leg`（`8×9×11`）顶部直插 `z = 10.2`，深嵌 `lift = 7.5` 躯干战裙 `>= 3` 格；二足步态采用紧凑 `restX = ±5.0` 并附带 `clampFeetSafe` 最大偏移半径钳位，巡营、急转与蛮冲均不脱胯；
   - `cape` 与 `lootSack` 在躯干局部坐标系后置排布，结合 `bias` 层序（`leg -0.35 < cape -0.25 < lootSack -0.15 < torso +0.10 < head +0.40 < ear +0.45 < mace +0.55 < crown +0.65`）消除穿模。
3. **性能优化与复用**：
   - 技能 2 的 6 枚金块共享 1 份四重对称 `goldChunk`（`symDeg: 90`）资产，技能 3 的 2 只喽啰共享 1 份 `minionGoblin` 资产；
   - 技能粒子与抛射体池全部在实例初始化时预分配，运行期零高频对象分配；
   - 常态金冠与常态重锤不含自亮像素，避免非技能期触发额外自亮模糊开销。
