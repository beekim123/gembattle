## 0. 一页看懂

- **这是什么**：一款俯视的卡牌肉鸽。
  - 异世界的寻宝冒险家在工会接任务，进森林、遗迹，一片一片往深处走。
  - 碰到怪就打回合制卡牌仗，靠红绿蓝三色宝石按色环接链出伤。
  - 带着任务物品活着回去，在工会提交任务换金币，买会磨损的装备、雇只管一趟的队友，再出发。
- **一句话体验**：每一趟攒出一套「这把才有」的打法，打到后面数字炸开；死了回到大厅，也总有新东西让人想再进去一趟。
- **一趟**：10~40 分钟，看接的任务要走多深。一个地点分三个区、六层，两层一个看门的。
- **一仗**：1~3 分钟，回合不限时。每回合摸 1 张牌（养成最多到 5 张），出牌不限张数，一回合排一条链打出去。
- **原型**：画面全用色块；不取名，牌和怪只写功能。

## 2. 体验目标和设计支柱

**三种感觉，分主次**
1. **主：「这把成了」**。前几片在挑、在赌，中段打法成形，后段打出离谱的数字。参考小丑牌、哈迪斯。
2. **次：「下一片是什么」**。往深处走的好奇。出口上挂着记号，让人想赌一把。
3. **托底：「再来一把」**。死了也有收获，大厅里总有新东西。

**不要的**：一步一步算死的解谜式战斗（像陷阵之志那样）；大段读剧情。

**给谁玩**：玩过杀戮尖塔、小丑牌、哈迪斯的人。电脑单机，以鼠标为主。

**难度**：中等，死是常态。没有「走到头」（用户定的：肉鸽没有这个说法）。任务等级 C → SSS 就是往上爬的梯子，最高级的任务本身就是加码。

**三条设计支柱**：每加一样东西，先拿这三条问一遍。一条都沾不上的不要，跟哪条打架的要改。

| 支柱 | 意思 | 拿它怎么量 |
|---|---|---|
| 一、这把才有的打法 | 每趟拿到的东西不同，叠起来打法就不一样 | 这东西会不会让人换一种打法？能不能跟别的叠出 1 + 1 > 2？「伤害 +5%」这种平的东西要少 |
| 二、快、炸、看得懂 | 一回合很快能想完，打出去数字很大，而且知道大在哪 | 一回合十几秒能想完吗？这是量复杂度的，**回合本身不限时**（用户定的：这是 PVE）。打出一个大数，说得出是哪几样东西叠成的吗？ |
| 三、每个岔口都有得有失 | 挑出口、挑奖励、挑牌，每次都该犹豫 | 有没有永远选对的那个选项？有就删掉或改掉 |

## 3. 世界和结构（用户定的）

- **主角**：异世界的寻宝冒险家。异能是卡牌能力，靠三色宝石的机制战斗，打法偏远程法师。
- **为什么进去**：在工会接任务，去森林、遗迹这些地方，带回任务要的东西。
- **回来以后**：在工会提交任务换金币，用金币买装备、雇队友，再接任务出发。
- **队友**：出任务前招募，比如辅助、坦克、战士、刺客。花金币雇，只管一趟。
- **怪**：异世界的东西，放开设计。原型阶段只做机制，样子和名字以后再定。
- **大厅**：只负责摆入口。工会、招募、卡册这些都是独立的模块（第 8 节）。
- **地点**：森林、遗迹……每个地点各有入口，是一个独立的模块。原型只做森林。
- **最终目标**：暂时不设计，以后做的过程中有想法再加。
- **剧情**：放多少还没定。

## 4. 核心循环

| 层 | 多长 | 玩家在做什么 | 得到什么 | 为什么想做下一次 |
|---|---|---|---|---|
| 出一回合牌 | 十几秒 | 排一条链打出去 | 算式一步步亮出来，数字蹦出来 | 差一点就打死了；下回合可能摸到配得上的牌 |
| 走一片 | 2~3 分钟 | 进空地、打一仗、挑奖励、挑出口 | 牌组强一点，离任务近一点 | 出口上挂着想要的东西 |
| 跑一趟 | 10~40 分钟 | 带着任务一层层往里走；拿到东西后选回去还是继续 | 活着回去：交任务、带金币和战利品。死了：只剩一点金币 | 这把成形了想看能走多深；揣着东西越走越怕丢 |
| 回工会 | 跨很多趟 | 提交任务、买装备、雇队友、接新任务、看卡册 | 更好的装备，更高级的任务 | 更高一级的任务、卡册的空格、装备快坏了 |

- **每趟重来的**：牌组、加成、强化、属性、宝石等级、队友。
- **跨趟留着的**：金币、装备（会磨损）、冒险家等级和解锁、卡册。
- **撤离**：只能从每层最后的「回去」出口走（第 7 节）。所以「撤还是继续」本身就是一次挑出口。

## 5. 战斗

### 5.1　一回合

1. **回合开始**：摸牌；「每回合开始」时机的东西生效。
2. **玩家出牌**：把要打的牌排成一条链，一起打出去。出牌不限张数（用户定的），一回合只打一条链。
3. **队友出手**：会自己动的队友出手。
4. **怪出手**：倒计时到 0 的怪打主角。
5. **回合结束**：没打的牌留在手里。

| 项 | 规则 |
|---|---|
| 摸牌 | 开战先摸 3 张；之后每回合摸 1 张（用户定的：摸牌是养成的重点）。一趟里最多 +2，永久养成 +1，稀有装备 +1，每回合最多 5 张 |
| 手牌 | 没打的留到下回合，上限 10 张。所以每回合都要想：现在打，还是攒着凑一把大的？攒着的时候，怪照样打你 |
| 心 | 只有主角有心，起手 3 颗（用户定的：主角用心，队友不掉血）。心跨片带着走，一趟里不会自动回满 |
| 输赢 | 怪的血条全打空就赢；主角的心掉完，这一趟就死了。没有回合上限，不能逃跑 |

### 5.2　宝石牌组和色环接链（用户原型的规则）

**宝石牌是固定的一副 29 张**（用户定的）。不当奖励，一趟里也不加不删。每仗开打洗一遍；打出去进弃牌堆，牌堆摸完了，把弃牌堆洗回去，一直循环。一趟里拿到的功能牌混在这副牌里一起摸。

| 颜色 | 几张 | 带几颗宝石 |
|---|---|---|
| 红、绿、蓝 | 各 5 张 | 1 颗 |
| 黄（红 + 绿）、青（绿 + 蓝）、紫（红 + 蓝） | 各 4 张 | 2 颗 |
| 白（红 + 绿 + 蓝） | 2 张 | 3 颗 |

这是三原色叠加的混色，不是颜料的混色，界面上要把「红 + 绿 = 黄」画清楚。

**色环**：红 → 黄 → 绿 → 青 → 蓝 → 紫 → 红，白在圆心。

**每张牌跟链上前一张的关系**

| 关系 | 例子 | 效果 |
|---|---|---|
| 同色、邻色 | 红 → 红，红 → 黄 | 接上，倍率 ×2，在这条链上一路往上乘 |
| 隔一格 | 红 → 绿 | 断了，倍率回到 ×1，集到的颜色清空，只留这一色 |
| 正对面（补色） | 红 → 青 | 合白：倍率照样 ×2，这张牌再多打一轮白色的伤害（红、绿、蓝各一份），集到的颜色清空，只留这一色 |
| 白 | 任何 → 白 | 在圆心，跟谁都接得上，不算集色 |
| 无色的功能牌 | | 不算断，不改当前颜色，也不改倍率 |

- **集色**：每打一种颜色，色环上记下这一色，跨回合留着。六种颜色集齐就是**彩虹**：链打完以后，用彩虹色把这条链的发再打两遍，加起来正好 ×3；然后从这一色重新开始集。
- **跨回合**：当前颜色留着，下回合第一张跟上回合最后一张算关系；倍率每回合从 ×1 起。
- **组合色是桥**：红和绿隔一格，直接接会断；中间放一张黄，就接上了。
- **宝石等级**：打出带某色宝石的牌，这色攒经验，攒够了升级，这色每发更疼。一趟里有效。
- **暴击**：每发单独判。

**每回合要想的**
- **排顺序**：这几张怎么排接得最长？组合色当桥放哪？白留着救哪一段？
- **合白的时机**：多打一轮白色伤害，但集到的颜色会清空。现在要，还是忍着去攒彩虹？
- **攒还是打**：差一种颜色就彩虹、差一张桥就接长，等不等？
- **算牌**：牌组固定，打过的进弃牌堆，所以算得出牌堆里还剩什么。界面上直接显示牌堆里每种颜色还剩几张。
- **先破盾还是先堆伤害**：见 5.5。
- 排顺序的负担，靠三样压住：前期手里牌少；出牌前有预览和提示（接上没有、还差几色到彩虹）；手牌有上限。

### 5.3　伤害

**两个轴分开**（方向是用户定的）

| 轴 | 管什么 | 怎么算 |
|---|---|---|
| 发数 | 多 | 每颗宝石打「打到这张牌时的倍率」那么多发，**不封顶**。链越长，翻得越快 |
| 每发伤害 | 疼 | 攻击 × 宝石等级加成 × (1 + 增伤) × 暴击时的暴伤 |

- **每发伤害有个正常的范围**（用户定的，参考崩铁）：攻击最高三四千，暴击率能到 100%，暴伤加上各种加成能到 500%~1000%。
  - 前期每发几十到几百，后期几千到几万，顶天十几万，不会到「亿」。
  - 高级任务的怪血很厚，要靠超级多发去扛，而不是让单发变大。
- **宝石等级加成**：每级 +10%，不用原型的「每级 ×1.2」，免得单发冲出那个范围。
- **显示**：
  - 同一张牌的几发连着打出去；
  - 屏幕上同时飘的数字有上限，发数再多就几发合成一包，一包显示单发伤害；
  - 暴击的数字更大、换颜色；
  - 一条链打完，屏幕中间亮出这回合的总伤害。

### 5.4　单攻和群攻（用户提的要求）

**颜色的打一只，白色的和彩虹打所有。**
- **单攻**：原色牌、组合色牌打出的发，都打选中的那只。它死了，剩下的发自动转到下一只。
- **群攻**：白牌自己的发、合白多打的那一轮、彩虹再打的那两遍。打所有怪，每只都吃满，不平分。
- 白色伤害是红绿蓝三份，所以群攻打到哪只，就把哪只的三色盾各削一下。
- 只有一只怪的时候，群攻全打在它身上。
- 更多群攻的花样做成功能牌、队友的效果，不进基础规则。

### 5.5　怪：倒计时、盾、多重血条（用户定的方向：血条和破盾参考崩铁）

- **出手**：怪头上有倒计时，开始是 4，每回合减 1，到 0 就打主角。打过以后越数越短，打过两次以后每回合都打。倒计时旁边同时亮出「到 0 时它要干什么」。
- **挨一下**：普通怪掉半颗心；精英、看门的掉一颗。
- **防守**：基础规则里没有防守。挡、拨倒计时、削弱都做成功能牌、队友、装备的效果。在倒计时到 0 之前打死它，本身就是最好的防守。
- **盾（带颜色的韧性条）**：
  - 颜色只有红、绿、蓝三种。组合色的牌按它带的宝石来削：黄牌削红和绿，白牌三色都削。
  - **按颗削**：这一下打出去，每颗对色的宝石削 1 格，跟倍率、发数无关。所以分成两条线：链越长伤害越高，对色的宝石越多破盾越快。
  - 盾在的时候，怪受到的伤害 ×0.5。
  - 破盾那一下，怪的倒计时往后推 2 格。
  - 破盾以后到它下一次出手之前，受到的伤害 ×2；它出完手，盾回满。
- **多重血条**：普通怪 1 条，精英 2 条，看门的 3 条或更多。打空一条换下一条，下一条可以换盾的颜色、换特性；伤害能溢到下一条。
- **一群**（用户定的：有的仗打一只，有的打一群）：
  - 2~4 只，每只有自己的血条、盾、倒计时。
  - 出牌前点一下选目标，默认选倒计时最短的。
  - 破盾每只单独算。

### 5.6　功能牌

**两种用法**
- **马上用**：不排进链，点一下当场生效。比如摸牌，摸到的牌还能排进这回合的链。
- **排进链**：跟宝石牌一起排，放的位置有讲究。比如「倍率 ×2」放在链中间，只有后面的牌吃得到。

两种都是无色的，排进链也不算断。

**原型做 8 种**（抽牌是用户定的必有项）

| 管哪块 | 功能 | 用法 |
|---|---|---|
| 摸牌 | 马上摸 N 张 | 马上用 |
| 伤害 | 本轮宝石基础伤害 +X（加的是攻击） | 排进链 |
| 伤害 | 倍率 ×2 | 排进链 |
| 接链 | 变成当前色的补色，自己造一次合白 | 排进链 |
| 集色 | 把当前色两边的颜色直接记上 | 排进链 |
| 破盾 | 直接削某色盾 N 格 | 排进链 |
| 防守 | 挡掉怪的下一次攻击 | 马上用 |
| 防守 | 怪的倒计时 +1 | 马上用 |

**以后再加的 12 种**
- 下回合多摸 N 张；从牌堆挑一张指定颜色的牌；弃一张摸一张。
- 额外打 N × 倍率发；固定伤害，不吃倍率，不受怪的特性影响。
- 当任意颜色；这条链下一次断了，倍率不掉。
- 这回合合白、断色都不清空集到的颜色。
- 所有颜色的盾各削 1 格。
- 怪这一下少打半颗心；回半颗心。
- 某色宝石经验 +N。

### 5.7　队友（用户定的方向）

**参与方式**：每个队友功能不一样，没有一条通用规则（用户定的）。一个队友可以只用一种方式，也可以几种合着用：

| 方式 | 意思 |
|---|---|
| 自己动 | 每回合按自己的本事出手 |
| 塞牌 | 这趟牌组里多几张他的牌，打出来他才动 |
| 后台加成 | 不上场，一直生效 |
| 跟着触发 | 见了某色宝石或某种牌，就跟着出手 |

- **队友不掉血**，场上只有主角有心（用户定的）。所以坦克类的队友得用别的办法护住主角。
- **席位**：一开始带的少，养成以后解锁（用户定的）。起步 1 个，冒险家等级 B 级 2 个、S 级 3 个。
- **雇佣**：花金币雇，只管一趟（用户定的）。
- **看得懂**：每个队友身上挂一个参与方式的记号，配一句话；它加的那一份伤害，要在算式里亮出来。
- **探索的小本事**：每个队友再带一个只管地图的本事（第 7 节），不碰战斗规则。

**12 个候选**（用户定的：表里每格单独做成一个队友，每个只管一种机制；以后再加）

| 职业 | 方向 A | 方向 B | 方向 C |
|---|---|---|---|
| 坦克 | 自己动：怪每次出手，替主角挡掉这一下，每仗能挡 N 次 | 塞牌：几张「挡下一次」「倒计时 +1」 | 跟着触发：每破一次盾，怪的倒计时再多推一格 |
| 战士 | 自己动：每回合砍一刀，专削当前那条盾 N 格 | 跟着触发：每打出一颗某色宝石，跟着砍一刀 | 后台加成：攻击 +X |
| 刺客 | 后台加成：暴击率 +X%、暴伤 +Y% | 跟着触发：破盾那一下，补一刀单独的大伤害 | 跟着触发：每打中 N 发，补一刀 |
| 辅助 | 后台加成：每回合多摸 1 张（很强，当贵的队友） | 塞牌：几张「记两边的颜色」「倍率 ×2」 | 自己动：每仗开打时回半颗心 |

原型做 4 个，每个职业 1 个，正好把四种参与方式都试一遍。具体选哪 4 个，跟用户一起定。

### 5.8　怪的特性

每个特性都要逼出一种不同的打法。怪长什么样、叫什么，以后由用户设计（用户定的）。

**候选**

| 压哪块 | 特性 | 逼玩家怎么打 |
|---|---|---|
| 盾 | 有两种颜色的盾，两种都削完才破 | 链里要带两种颜色，组合色当桥 |
| 盾 | 盾每回合换一种颜色 | 各色的牌都得留一点 |
| 盾 | 盾没破时，伤害折扣更狠 | 非破盾不可 |
| 链 | 每回合挑一种颜色，这色打它伤害减半 | 绕开这个颜色排链 |
| 链 | 每次出手，把集到的颜色清空 | 彩虹要在它出手前集齐 |
| 链 | 已经集到几种颜色，它就少受几成伤害（用户原型里的） | 集色和打伤害之间要取舍 |
| 手牌 | 每回合遮住一张手牌，看不见颜色 | 排链要赌 |
| 牌组 | 往牌组里塞没用的牌 | 要删牌、多摸牌 |
| 倒计时 | 倒计时短 | 要么防，要么快打 |
| 倒计时 | 每被破一次盾，倒计时 -1 | 破盾要算好时机 |
| 发数 | 每回合挨的前 N 发不掉血 | 每发要疼 |
| 单发 | 单发超过某个数的部分不算 | 要靠发数 |
| 血 | 每回合回一截血 | 要在几回合内打死 |
| 命中 | 每发有几成打不中 | 多发更稳 |
| 多重血条 | 换一条血就换一个特性 | 每一段都要换打法 |

**原型的 7 种仗**

| 哪种仗 | 几条血 | 特性 | 试什么 |
|---|---|---|---|
| 普通，一只 | 1 | 两种颜色的盾 | 破盾、组合色当桥 |
| 普通，一只 | 1 | 每回合挑一色减半 | 绕开颜色排链 |
| 普通，一只 | 1 | 集到几色就少受几成 | 集色和打伤害的取舍 |
| 普通，一只 | 1 | 倒计时短 | 攒还是防 |
| 普通，一群 | 每只 1 | 3 只小的，血少，各一种单色盾 | 选目标、溢出、群攻 |
| 精英 | 2 | 每回合挨的前 N 发不掉血 | 每发要疼 |
| 看门的 | 3 | 每条血换一个特性：盾每回合换色 → 每次出手清空集到的颜色 → 每被破一次盾倒计时 -1 | 多重血条换打法 |

### 5.9　统一的「时机」

队友、装备、功能牌、加成、怪的特性，都用同一套「在哪个时机、做什么」来写。时机有：开战时、每回合开始、出一张牌时、打出某色宝石时、接上时、合白时、彩虹时、破盾时、打中一发时、挨打时、一直生效。

这样每样东西都是一个独立的小块，加一样东西不用改战斗本身。

## 6. 构筑

### 6.1　七条打法路子

全从战斗机制里长出来，不另加规则。原型先撑起前 5 条；多发、每发疼主要靠队友和装备。

| 路子 | 靠什么 | 什么喂它 | 打哪种怪顺手 | 怕哪种怪 |
|---|---|---|---|---|
| 长链 | 链接得长，倍率一路翻，发数爆 | 倍率 ×2、断了倍率不掉、当任意颜色、强化宝石牌 | 只有一只、血厚的 | 遮住手牌的 |
| 破盾 | 对色的宝石多，破盾后伤害翻倍、倒计时往后推 | 削某色盾、让某色削盾更快的加成、破盾时补刀或推倒计时的队友 | 双色盾、看门的 | 盾每回合换色的、每被破一次倒计时 -1 的 |
| 合白 | 故意接补色，多打白色伤害，三色盾各削一下 | 变成补色、跟合白有关的加成 | 一群、双色盾、集色减伤的 | 每回合挑一色减半的 |
| 彩虹 | 六色集齐，链打完再打两遍 | 记两边的颜色、这回合不清空 | 一群、血厚的、看门的 | 每次出手清空集到的颜色的 |
| 攒牌 | 摸得多、攒着，一回合打一条超长的链，中间靠防守撑 | 摸牌、手牌上限、挡、倒计时 +1、坦克 | 血厚的 | 倒计时短的、塞没用牌的 |
| 多发 | 发数多，「每打中 N 发就……」一路触发 | 额外打 N × 倍率发、每打中 N 发补刀的刺客 | 打不中几成的 | 前 N 发不掉血的 |
| 每发疼 | 攻击、增伤、暴击、暴伤 | 装备、加暴击的刺客、加攻击的战士、本轮宝石基础伤害 +X | 前 N 发不掉血的 | 单发超过某数不算的 |

**规矩**：每样东西主要喂 1~2 条路子。正好横跨两条的最值钱，比如「破盾时多打一轮白色伤害」同时喂破盾和合白，拿到它，玩家就会说「这把是破盾合白流」。

### 6.2　一趟里的奖励

打完一片，出口亮起来，每个出口挂一个记号，写明下一片打完给什么。

| 奖励 | 是什么 | 带出林子吗 |
|---|---|---|
| 功能牌 | 三选一 | 不带 |
| 加成 | 三选一，这一趟一直生效，能改规则。「这把是什么流」主要靠它 | 不带 |
| 强化 | 挑一张牌变强（6.3） | 不带 |
| 删牌 | 删一张功能牌，或者怪塞进来的没用的牌。宝石牌不能删 | 不带 |
| 属性 | 攻击、增伤、暴击率、暴伤、摸牌数、手牌上限，给其中一样 | 不带 |
| 回心 | 回一点心 | 不带 |
| 金币 | 一笔金币 | **带**（死了会丢，见 8.3） |

- **宝石牌不是奖励**（用户定的）。
- 出口上还会标出任务物品在哪片。
- 战利品在精英、看门的身上掉，不写在出口上。
- 打完精英、看门的，再多给一次加成三选一。
- 金币放进出口奖励，是为了让「为局外拿钱，还是为这一趟变强」成为一个真取舍。

### 6.3　一趟里怎么变强

| 项 | 规则 |
|---|---|
| 宝石牌的强化 | 挑一张，再从 2~3 个方向里选一个：疼（每发 +X%）/ 多（每颗多打 N 发）/ 破盾（每颗多削 1 格）/ 集色（打出时顺带记上旁边一色）。每个方向喂一条路子 |
| 功能牌的强化 | 数变大，比如摸 N 张变成摸 N + 1 张 |
| 强化次数 | 每张牌最多一次，强化过的有记号 |
| 功能牌 | 混进牌组。功能牌越多，摸到宝石就越少，所以不是越多越好 |
| 加成 | 不占牌组，原型不设上限，摆在界面一边随时能看 |
| 宝石等级 | 哪个颜色打得多，哪个颜色就越疼，每趟从 1 级起 |
| 摸牌数 | 最贵的东西，一趟里最多 +2 |
| 属性 | 拿一次涨一截 |
| 心 | 靠回心类的东西回；上限平时靠装备，极少数加成能涨 |

**变强的节奏**
- 前几片：零散的功能牌和属性，数字小。
- 中段：两三个加成到手，路子成形，单发几百到几千。
- 后段：强化、加成、宝石等级叠在一起，满屏几千几万。

### 6.4　起手

- **牌组**：只有 29 张宝石牌，不带功能牌。雇了「塞牌」的队友，他的牌另算。
- **第一片的出口里一定有一个是加成**：一开始就能挑方向。

| 项 | 起手 |
|---|---|
| 心 | 3 颗 |
| 摸牌 | 开战 3 张，每回合 1 张，手牌上限 10 |
| 攻击 | 主角底子 + 装备 |
| 增伤 | 0 |
| 暴击 | 10%，每发 ×1.5 |
| 宝石等级 | 三色都是 1 级 |
| 加成 | 没有 |

### 6.5　跨趟怎么变强

- **装备**：3 格，武器、护身、饰品，每格穿一件。每件 = 属性 + 0~1 个小特性。小特性是一个弱一点的加成，比如「破盾时这一下暴击率 +20%」。

  | 格 | 主要管 | 有的还带 |
  |---|---|---|
  | 武器 | 攻击 | 暴击之类的小数 |
  | 护身 | 心的上限 | 每仗开打先挡一次 |
  | 饰品 | 增伤、暴伤、手牌上限 | 极少数：每回合多摸 1 张 |

- **磨损**（用户定的：有磨损，用多了会坏，坏了重新买）：
  - 每出一趟磨 1 点，死在林子里多磨 1 点。
  - 磨到 0 就坏了，不能修。
  - 没坏之前属性不掉，界面上显示还能用几趟。
- **永久养成以解锁为主**：解锁席位，以及新的功能牌、加成、队友、装备进奖励池和商店。数值上的变强主要靠会坏的装备。
- **摸牌例外**：永久养成里给一次「每回合摸牌 +1」，当一个大里程碑。

## 7. 探索

**原则**：战斗、地图探索、构筑分开设计（用户定的）。探索不往战斗规则里加东西，比如从背后碰到怪也不会先手。

### 7.1　一片

- 一片是一块宽敞的空地，南边进、北边出，只有一两团鬼火（用户定的）。
- **不打仗的部分每片控制在半分钟到一分钟**。从进口走到出口十几秒。
- **一片里放什么**：
  - **怪**：必有，歇脚、商人、事件片除外。**打完才开出口**，不能绕开。
  - **0~1 样藏着的东西或小事件**：
    - 藏着的东西在角落、大石头后面，走近才看得见，给一点金币或小奖励。
    - 小事件是二选一，有得有失。
  - **任务物品**：照接的任务放。
- 藏着的东西和小事件不写在出口上，进去才发现。

### 7.2　片的种类

| 片 | 里面有什么 | 出口上显示 | 多久一次 |
|---|---|---|---|
| 普通 | 一只或一群普通怪 | 奖励记号 | 最常见 |
| 精英 | 一只精英。多给一次加成三选一，有机会掉战利品 | 奖励记号加红框 | 每层 0~1 |
| 歇脚 | 没有怪，三选一：回心、强化一张、删一张 | 歇脚记号 | 每层最多 1 |
| 事件 | 一件大一点的事，多选一，有得有失 | 问号 | 每层 0~1 |
| 商人 | 花身上的金币，买这一趟用的东西 | 商人记号 | 每层最多 1（原型可以先不做） |
| 看门的 | 一只看门的，3 条血 | 看门的记号 | 每个区最后 |

- **精英在出口上挑**：想冒险就走红框那个出口，不在片里另放。
- **一组出口里记号不重复**。
- **商人花的是要带回去的金币**，又是一次取舍。

### 7.3　区、层、出口

| 区 | 层 | 任务等级 | 区的最后 |
|---|---|---|---|
| 外头 | 第 1、2 层 | C、B | 看门的 |
| 中间 | 第 3、4 层 | A、S | 看门的 |
| 深处 | 第 5、6 层 | SS、SSS | 看门的 |

- 每层 2~3 片，走完 SSS 大约 15 片、3 个看门的、30~40 分钟。C 级只走第 1 层，十分钟以内。
- **每层最后一片打完**，出口里多一个「回去」；第 2、4 层的「接着往里」通向看门的。
- **只能往前走**，想回去只能走「回去」出口。
- **每片 2~3 个出口**。出口上显示：
  - 片的种类；
  - 奖励；
  - **一只还是一群**（影响怎么打，见 5.4）；
  - 任务记号。
- **不给整张路线图**，只在角上显示「第几层、这层第几片」。

### 7.4　走起来

- **操作**：鼠标点地走为主，WASD 也行。走到怪跟前开打；走到藏着的东西、事件跟前点一下用；走进出口去下一片。
- **视野**：主角周围一圈。鬼火发光，远远就看得见；藏着的东西要走近才看得见。出口打完才亮，记号那时才显示。
- **镜头**：原型固定角度，不转。
- **节奏**：鬼火在原地慢慢飘，不追人，可以先逛再打，打完还能接着逛。
- **事件扣心**：最多扣到剩半颗，死只会死在仗里。
- **队友**：在地图上跟着主角走。每个队友带一个探索的小本事，比如一进片就标出藏着的东西、事件多一个选项、商人便宜一点、歇脚多一个选项。具体哪个队友带哪个，跟用户一起定。

## 8. 局外

### 8.1　大厅的模块

大厅只摆入口；模块之间不直接调用，只读写存档里的数据（用户定的：都是独立模块，可以拆开、组合）。

| 模块 | 做什么 | 读什么 | 写什么 |
|---|---|---|---|
| 工会 | 任务板（接任务、点提交）；商店（买装备）；冒险家等级 | 金币、任务、身上的任务物品、等级、解锁 | 金币、任务、装备、等级、解锁 |
| 招募 | 花金币雇这一趟的队友（单独一个入口） | 金币、席位、解锁了哪些队友 | 金币、这趟带的队友 |
| 出发 | 挑地点；看这趟带了什么；穿脱装备；出发 | 任务、装备、队友、去过的地点 | 穿着的装备，开始一趟 |
| 卡册 | 查效果、看收藏（8.5） | 解锁、战利品、碰到过的怪 | 不写 |
| 设置 / 退出 | 通用 | | |
| 一趟（林子里） | 不在大厅，是出发以后的事 | 出发时带的全部 | 回来时：金币、任务物品和进度、战利品、装备磨损、碰到过的怪、触发的隐藏任务 |

### 8.2　任务

- **任务板**在工会里，每次回到大厅刷新，摆 4~6 个。能接到「冒险家等级 + 1」：自己这一级和以下的都能接，也能接高一级的去冒险。同时最多接 3 个。
- **8 种任务**（用户加了收集怪物身上的东西和隐藏任务）：

  | 种类 | 要做什么 | 出口上怎么标 |
  |---|---|---|
  | 采集 | 某层地上采 N 个 | 有得采的那片标任务记号 |
  | 收集怪物身上的东西 | 打某种怪，有几成会掉一样东西（比如牙齿），凑够 N 个 | 有那种怪的那片标 |
  | 讨伐 | 打某种怪 N 只，或者打某个区的看门的 | 同上 |
  | 找东西 | 某片角落里藏着一样东西 | 那片标；进去还得自己找 |
  | 挑战 | 在一趟里做到某件事，比如「一仗里打出一次彩虹」「不掉心走完第 2 层」 | 不标 |
  | 悬赏 | 打一只少见的精英，只在某几层出现 | 碰到它的那片标悬赏记号 |
  | 连环 | 做完一个才出下一个，最后一个给大奖励 | 跟着每一个的种类标 |
  | 隐藏任务 | 任务板上没有。在林子里碰到才出现：藏着的东西里翻出来、事件里选了某个选项、做到了某个条件。出现就算接下 | 出现以后照种类标 |

- 隐藏任务不占「同时 3 个」的名额，报酬更好，常带一个解锁或一件战利品。
- **提交**（用户定的）：
  - 任务做完了先算「做完、没交」。
  - 活着回到大厅，在工会的任务板上点「提交」才算交、才拿金币。
  - 没提交的东西回到大厅就安全了，只有死在林子里才会丢。
- **失败**：死了，没交的任务全算失败，回任务板可以重接。隐藏任务失败了，下次还得重新碰到它。
- **一趟里**：角上列着接的任务和进度。
- **报酬**：主要是金币，偶尔附带一个解锁。

### 8.3　金币

- **从哪来**：
  - 任务报酬，是大头。
  - 一趟里捡的：每仗打完掉一点、出口奖励的金币、藏着的东西。
- **死了**：只留每仗掉的那一点；出口奖励和藏着的东西给的都丢掉（用户定的：死了丢任务物品，打怪的那点金币留着）。所以身上钱越多，越要想撤还是继续。
- **花在哪**：
  - 装备，是大头，会磨损，一直要买。
  - 雇队友，每趟都要花。
  - 一趟里的商人。
- **解锁不花金币**，靠冒险家等级。

### 8.4　冒险家等级（用户定的叫法）

- 从 C 到 SSS，跟任务等级一一对着。做完足够多当前等级的任务就升一级，比如做完 3 个 C 级升到 B。
- **每升一级解锁**：
  - 能接更高一级的任务；
  - 商店多一批装备；
  - 奖励池多一批功能牌、加成；
  - 招募多几个队友。
- **几个里程碑**：席位 B 级 2 个、S 级 3 个；摸牌永久 +1 在 A 级。
- 不单独做「养成」模块，冒险家等级和下一级解锁什么，都放在工会里看。

### 8.5　卡册

| 页 | 收什么 | 什么时候亮 | 点开看什么 |
|---|---|---|---|
| 卡牌（用户加的） | 所有宝石牌和功能牌 | 解锁了的都能看，没解锁的显示一把锁 | 每张牌单独的效果：用法、强化以后什么样、在色环上挨着谁、补色是谁 |
| 战利品 | 每种一格，精英、看门的身上掉 | 第一次拿到 | 是什么、在哪掉的 |
| 怪 | 碰到过的怪 | 第一次碰到 | 几条血、什么盾、什么特性 |
| 加成（设计者建议加） | 所有加成 | 解锁了的都能看 | 效果，喂哪条路子 |
| 队友（设计者建议加） | 所有队友 | 解锁了的都能看 | 打仗的本事、探索的本事 |
| 装备（设计者建议加） | 所有装备 | 解锁了的都能看 | 属性、小特性、能用几趟 |

- 收齐一组（比如一个区的全部战利品）给一个解锁。
- 重复拿到的战利品自动换成一点金币。
- 原型先做卡牌、怪两页，加上战利品的空格子。

## 10. 工程：模块怎么分、怎么做（用户定的原则）

**原则**：每个模块都解耦，用单独的目录开发，做完能单独跑、单独测，最后再组合成完整的项目。从色块原型就这么做，不先写一堆揉在一起的代码再拆。

**放在哪**：以后可能让几种 AI 各做一份原型来横向对比，所以每份原型放在 `原型/<做的人>/` 下面，比如 `原型/claude/`。下面说的目录都在这一份原型的根目录下。

### 10.1　模块

| 目录 | 管什么 | 碰不碰画面 |
|---|---|---|
| `modules/shared/` | 共用的约定：存档、出发包、开战包、战斗结果、回来包的格式（10.3），时机的名字（5.9），色环和七种颜色，随机数。不放玩法 | 不碰 |
| `modules/battle-rules/` | 一仗的规则：给它开战包和玩家的操作，算出结果 | 不碰 |
| `modules/battle-view/` | 一仗的画面和操作 | 碰 |
| `modules/content/` | 所有内容的数据，分 `cards/`、`buffs/`、`allies/`、`gear/`、`monsters/`、`events/`、`quests/`，效果都用「时机 + 做什么」写 | 不碰 |
| `modules/run-rules/` | 一趟的规则：区、层、片、出口、奖励、任务进度、回去、死了 | 不碰 |
| `modules/explore-view/` | 一片空地的画面和操作 | 碰 |
| `modules/save/` | 存档读写、版本、旧存档升级 | 不碰 |
| `modules/guild/` | 工会，分 `rules/` 和 `view/` | `view/` 碰 |
| `modules/recruit/` | 招募，分 `rules/` 和 `view/` | `view/` 碰 |
| `modules/depart/` | 出发，分 `rules/` 和 `view/` | `view/` 碰 |
| `modules/album/` | 卡册，分 `rules/` 和 `view/` | `view/` 碰 |
| `modules/hub/` | 大厅，只摆入口 | 碰 |
| `modules/render/` | 画东西的接口。现在用 `blocks/`（色块），以后换 `stack/`（像素堆叠）。画面模块只调这套接口 | 碰 |
| `modules/ui/` | 公共界面小件：按钮、文字、数字、面板、提示框 | 碰 |
| `app/` | 唯一的组装处：主循环、场景切换、Electron 的壳 | 碰 |
| `tools/` | 截图试玩、模拟器、跑全部单测 | |

### 10.2　解耦的规矩

1. 每个模块对外只有一个入口 `index.js`，别的模块不许伸手进它目录里的其他文件。
2. 每个模块自带：`README.md`（管什么、接口、读写哪些数据）、`test/`（不开窗口就能跑的单测）、`demo.html`（用假数据单独跑起来看，画面模块才有）。
3. 规则模块不碰 `document`、`canvas`，所以单测和模拟器能直接在 node 里跑。
4. 画面模块只认规则模块的对外接口，加上 `render/`、`ui/`，自己不算规则。
5. 模块之间只用 `shared/` 里约定好的数据来往。
6. 只在 `app/` 里组装。别的模块互相不知道对方存在。
7. 用浏览器自带的 ES 模块，不用打包工具。Electron 用 `file://` 读不了 ES 模块的话，在 `app/` 里注册一个本地协议。这一点写代码时验证。

### 10.3　模块之间传的东西

| 东西 | 谁交给谁 | 里面有什么 |
|---|---|---|
| 存档 | `save` 读写；大厅各模块读、改 | 金币、冒险家等级、任务（做完没交的也在）、装备和磨损、解锁、卡册记录 |
| 出发包 | `depart` → `run-rules` | 地点、接的任务、穿的装备、带的队友、起手的数 |
| 开战包 | `run-rules` → `battle-rules` | 玩家这边：牌组、属性、心、加成、队友、宝石等级。对面：一只或一群怪，各自的血条、盾、特性 |
| 战斗结果 | `battle-rules` → `run-rules` | 赢了还是死了、剩几颗心、宝石经验、掉了什么、碰到了哪些怪 |
| 回来包 | `run-rules` → `app`（拿去改存档） | 活着还是死了、金币、任务物品和进度、战利品、装备磨损、碰到过的怪、触发的隐藏任务 |

只要这五样的格式不变，每个模块里面怎么改，都不影响别的模块。

### 10.4　做的顺序

每一块做完都要能单独跑、单独测；到一个阶段，在 `app/` 里组装一次，变成能玩的东西。

| 阶段 | 做哪些 | 做完能看到什么 |
|---|---|---|
| 0 骨架 | 目录、`shared/` 的约定、`render/blocks/`、`ui/`、`app/` 空壳、跑全部单测的脚本、能截任何一个 demo 页的截图工具 | 一个空大厅，各模块的 demo 页都能打开 |
| 1 战斗 | `battle-rules` → `content/` 里的 8 种功能牌和 4 种仗（双色盾、集色减伤、一群、看门的）→ `battle-view` → 组装，大厅里临时放一个「试打」入口 | **先给用户玩**：一回合十几秒想得完吗？数字爽不爽？有没有在想「攒还是打」「先破盾还是先堆伤害」？不好玩就先改战斗，不往下做 |
| 2 一趟 | `run-rules` → `content/` 里的 12 个加成、小事件、C 和 B 级任务 → `explore-view` → 组装 | 从第 1 层走到第 2 层的看门的：挑出口、拿奖励、回去或者死 |
| 3 大厅 | `save` → `guild`、`recruit`、`depart`、`album`，各自先 `rules/` 再 `view/` → `hub` → 组装 | 大厅 → 接任务 → 招募 → 出发 → 走一趟 → 回来点提交，完整一圈 |
| 4 调数 | `tools/` 里的模拟器，只用 `battle-rules`、`run-rules`、`content`，跑几千把 | 照第 9 节的目标调数 |
| 5 往后 | 中间区、深处区、更多内容；`render/stack/` 换上正式美术；取名 | 跟用户一起定 |

约定（阶段 0）定好以后，同一阶段的模块可以分开做，甚至可以同时做。

### 10.5　以前的美术实验

在 `旧/美术样片/`，已经隔离开，新原型不用它的代码。等以后做正式美术，再回去参考它的像素堆叠画法，整理进 `render/stack/`。能借鉴的还有：像素字、无窗口截图试玩的工具、规则单测的写法。

## 12. 设计者自己看到的风险（给审核的人参考）

1. **排顺序会不会太烧脑**：出牌不限张数，又有色环、补色、集色、破盾、单攻群攻好几样要同时想，可能撑不住支柱二「十几秒想完」。现在靠三样压：前期手牌少、出牌前有预览提示、手牌有上限。够不够，阶段 1 要实测。
2. **倍率 ×2 一路翻，数值容易失控**：链长 10 就是 ×512，发数很快上万。显示要打包，数值要靠模拟器调；长链会不会压过其他路子，也要看。
3. **前期会不会太慢**：每回合只摸 1 张，起手 3 张，头几回合可能只能打两三张，一仗容易拖。
4. **功能牌冲淡宝石牌**：一回合只摸一两张，摸到功能牌就等于少摸宝石，可能让人不想拿功能牌。
5. **群攻每只吃满**：对一群可能太强，合白、彩虹在一群仗里可能永远是对的选择，跟支柱三打架。
6. **盾在时伤害 ×0.5、破盾后 ×2**：破盾可能变成「永远先破盾」，取舍不够。
7. **装备磨损**：每趟都要掏钱换装备，可能让人觉得烦，而不是想再挣一趟钱。
8. **任务种类多**：8 种任务加隐藏任务，原型阶段的内容量和测试量都不小。
9. **探索是不是够**：一片里只放 0~1 样东西，宽敞的地图可能还是显得空。
10. **模块切得很细**：十几个模块加五样约定，一开始的搭架子成本不低；约定要是定错了，后面改起来会牵动好几个模块。
