# 开工提示词（新开窗口时整段贴进去）

---

这个文件夹（`card-stack/`）是一个游戏原型。我想请你**自己当这个游戏的设计师、程序和美术**：在这个原型的基础上，设计一套完整的玩法，然后一步步把它做成一个能从头玩到尾的游戏。我只定大方向，具体怎么设计、怎么做由你决定。

## 这是个什么游戏
- 一个卡牌系的异能者误入一片迷雾森林。林子里能随便走、随便探索，碰上怪就进入回合制卡牌战斗，打赢了拿奖励、变强，接着往深处走。
- 俯视第三人称，画面用**像素堆叠**（sprite stacking）：每个东西是一层层水平切片叠起来的，能 360 度转。美术全部用代码画（逐个体素生成）。
- 桌面端，Electron + 原生 JS + Canvas 2D。

## 现在有什么（当底子用，不用守着它）
- **大厅**：一块林间空地、一块刻符文的石碑，菜单进林子 / 看牌组。
- **林子**：按区块程序生成、走不到头；只看得见主角周围一圈（主角身边绕着三颗宝石，宝石的光照亮周围）；有树、水塘、小路、萤火虫，右上角小地图。
- **怪**：林子里飘着鬼火，碰上就进战斗。现在只有一只怪（提可，带翅膀的小飞虫）。
- **战斗**：俯视，拖牌排进序列再施法。牌上带红绿蓝宝石，按色环接链翻倍，还有色灯、彩虹、补色白光、宝石等级这些机制。打赢三选一拿牌，可以逃跑、回大厅。
- **美术**：`src/models.js` 是代码生成的模型；`art/neo-1/` 是外包画师画的一版切片（`src/art.js` 读它，网址加 `?art=0` 就换回代码生成的）。两套都可以用、改、扔。
- 怎么跑：双击 `启动.command`，或者 `npm start`；也可以用任意静态服务器打开 `index.html` 在浏览器里看。文件分工见 `README.md`。

## 我想要的
- **一个完整的玩法**：从大厅出发 → 探索 → 战斗 → 变强 → 越走越深、怪越来越强 → 有一个目标和结局（打倒什么、走到哪），死了或回大厅以后还想再来一局。整局怎么组织、有哪些系统，你来设计。
- **越打越强、伤害数字要爽**：现在的数值是乱来的。手牌一开局就补满 8 张、出牌又不限张数，排一长串牌，满屏飘的却是 5、6、7 点，没有意义。我想要的是满屏直接打出几千、几万的伤害，后面更大。前期应该弱一点（比如一开始只抽一两张，按回合慢慢变多，或者靠全局 buff 一点点叠上去），后面靠成长打出夸张的数字。现在的战斗规则只是参考，觉得不好就改、就换。
- **画面**：暗、偏恐怖的林子，但不要血腥；画面干净、主次清楚，一眼知道看哪；像素方正清楚（整数倍放大），不要糊、不要乱糟糟拼凑的感觉。
- 怪、牌、名字都可以自己设计，要原创，不要照搬已有的游戏。

## 只有这几条是硬的
- Electron + 原生 JS + Canvas 2D，不用游戏引擎、不用 3D 库。
- 俯视像素堆叠，美术用代码画（可以用 `art/` 里现成的）。
- 界面中文。
- 不要去读上一级 `../异能卡牌/` 里的规范和旧设计文档，那是旧的做法，会把你框住。

## 怎么做
1. 先把原型跑起来、玩一下、读一遍代码，搞清楚现在有什么。
2. 写一份**简短**的设计（放 `设计.md`）：整局流程、核心循环、成长、战斗规则、数值大致曲线、要做哪些怪和牌。写完先停下来给我看一眼，我点头再开工。
3. 然后一步步做，**每一步做完都能玩**。每步完了在 `进度.md` 记一行做了什么，自己跑一遍（可以用无窗口浏览器截图看画面、看控制台有没有报错），再接着做下一步。
4. 动手前先 `git init` 提交一次当起点，之后每做完一步本地提交一次，方便回退。不推远端。
5. 最后我双击 `启动.command`，就能从大厅开始玩完整的一局。

## 记进度（我会换账号、换模型接着做，必须随时能交接）
- `设计.md`：现在的设计。设计改了就直接改这里，别让它跟游戏对不上。
- `进度.md` 分两段：
  - **开头“现在”一段，每次都整段重写**：做到哪了、现在能玩到什么、下一步具体做什么、已知的毛病和坑、还没跟我确认的事。换一个人只读这一段就能接着干。
  - **下面“记录”一段，只往下加**：每做完一步一行，带日期，写做了什么、改了哪些文件。
- 每做完一步：更新 `进度.md`、本地 git 提交一次（提交说明写清这一步做了什么）。
- 对话快满、或者要停下来之前，先把“现在”那段更新好再停，不要留一半没记的改动。
- 目录里的 `CLAUDE.md` 和 `AGENTS.md` 是给接手的人看的，开头就叫他先读这几份。
