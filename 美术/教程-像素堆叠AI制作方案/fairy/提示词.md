### 一、造型、体素特点与场景要求
注意：文案、皮肤名、技能名严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。正面统一朝向 `+Y`，`z = 0` 为最低有效层，通过 `lift = 9~12` 表现明显的空中漂浮感。

1. **主体造型**（推荐体素盒约 `34 × 32 × 32`，悬空 `lift = 10`）
   - 娇小精致的林间妖精轮廓：头戴小花瓣/叶片发饰、柔和的圆润发髻与小尖耳、0.6 俯视清晰可见的大眼（刘海抬高 1 层绝不遮眼！）；
   - 身穿分层展开的花瓣小裙（下摆略微外张，立体感强），双腿悬空微曲；
   - **标志性两对蝶/蝉翼**：一对较大的上翅 + 一对较小的下翅，翅根牢牢锚入后背（`t = 0` 位移为 `0`），**翅面厚度务必 ≥ 2 格**以防 360° 旋转碎裂，翅缘带对比色花纹边；
   - 右手握一根比身高略长的**弯头花枝法杖**（顶端嵌一颗独立自发光色槽的彩色花苞/露珠核）；
   - **轻盈悬空待机（8 帧）**：两对翅膀高频上下扇动、整体随正弦优雅漂浮轻晃、花瓣裙摆微微起伏，地面投影因悬空而略小偏淡。

2. **场景与受击靶**
   - 圆形青苔林间花石底座（周期纹理 + 零散像素小花点缀 + 固定石边环），前方 `+Y` 方向放置像素堆叠训练靶桩（受击抖动、花粉飘落、藤蔓缠身等反馈）。

### 二、4 套色系（零重建模一键换色，快捷键 `C` 或 HUD 按钮切换）
必须基于 `Uint8Array` 索引网格实现 `recolorAsset(skin)`（`< 2ms` 按索引重刷长条图集并清空精灵缓存回收至对象池，**严禁重跑 SDF 建模**），同时联动全部技能的花粉、法弹、藤蔓、花瓣涟漪配色：
1. **嫩绿林间（经典）**：嫩叶绿花瓣裙 + 青白带金边双翅 + 金棕发色 + 翠绿与嫩黄花粉/绿藤特效；
2. **粉樱花季**：樱粉渐变花瓣裙 + 浅粉白蝶翅 + 浅茶发色 + 粉白落花与桃红法弹特效；
3. **冰青寒霜**：冰蓝白霜瓣裙 + 剔透天青双翅 + 银白发色 + 冰晶青白飞弹与霜藤特效；
4. **琥珀秋叶**：暖枫橘金花瓣裙 + 琥珀红边蝶翅 + 栗棕发色 + 金红枫叶与暖橘花粉特效。

### 三、4 个技能演出（按钮或快捷键 `1~4` 触发）
所有技能轻盈灵动，包含完整 **前摇 → 释放与特效 → 靶桩/地面反馈 → 归位**：
1. **花粉散射（1）**：妖精轻快绕着靶桩空中画半个弧圈飞行，翅膀高频振颤并沿途洒下一串色彩鲜亮的像素花粉团，花粉缓慢飘落并在靶桩四周啪啪炸开彩粉微粒。
2. **法杖连发（2）**：悬空后仰举起花枝法杖在身前画一小圈，顶端花苞亮起，紧接着连发 4 枚带弯曲追踪像素尾迹的彩色小法弹，接连击中靶桩炸开小花环。
3. **藤蔓缠绕（3）**：花杖朝下一点，靶桩脚下先亮起草绿圆环预警，随即地面钻出 3 条立体扭动的像素绿藤（带小叶片）螺旋向上紧紧缠绕靶桩，令靶桩剧烈抖动片刻后藤蔓缩回地底。
4. **治愈微风（4）**：原地轻盈旋转一圈并舒展双翼，脚下石台荡开两道柔和扩张的彩色涟漪，周身螺旋升起大量上升的像素小十字与花瓣微粒，呈现清爽治愈氛围。

### 四、工程性能与强制自检闭环（对照 `README.md` v2）
1. **第 0 步先写空间坐标预算表**，重点保证两对薄翅厚度 ≥ 2 格且翼根不断裂、发饰/刘海不压眼睛、花杖顶端亮核在 `+Y` 与俯视下零遮挡。
2. **极速建模与旋转满帧架构**：
   - `Uint8Array` + 部件级 `fillAABB` + `despeckle()` + 垂直 3 档色阶 / 腔体 AO / 白名单 Crease AO + 单张长条图集（保留 `grid` 供 `recolorAsset` 换色），8 帧建模耗时目标 `< 100ms`；
   - 定倍角度烘焙缓存 `BAKE_SCALE = 2.5`（精确 `step = 2`、`1px` 半步压实、`3°` 量化 + 对象池 + 滚轮缩放不清空缓存）；
   - 预渲染天空 `bgc` + `2×` 小地表缓冲集成投影与地面涟漪 + 缓存模式精灵直绘 `dctx` + 内外发光 `destination-out` 裁切（从 `minGlowZ` 起）+ `1/4` 独立小画布 `ebctx` 真降采样模糊；
   - HUD 支持：4 套色系一键切换 (`C`)、4 个技能 (`1~4`)、自动旋转、单体描边、模式切换（游戏缓存 / 高清逐层 / 复古低分）、导出带色系名长条 PNG、最短角路径重置视角、实时性能栏（建模耗时 / FPS / 单帧 ms / 绘制次数 / 色数 / 缓存）。
3. **强制验收闭环**：
   - 跑 Node 自动化脚本校验：色数 ≤ 48、无重色、无未着色、无孤立碎点、双眼与法杖顶端核正面 `+Y` 及 0.6 俯视射线遮挡 = 0、切换 4 套色系耗时 < 5ms；
   - 本地静态服务 + 浏览器实机验收：零 Console 报错；旋转 360° 检查两对薄翅无破碎穿模、悬空感自然；测试 4 套色系与 4 个技能演出；连续拖拽/自动旋转稳跑 60~120fps（单帧 < 2ms）；亲自审片并至少迭代打磨 1 轮后收尾清理临时服务。
