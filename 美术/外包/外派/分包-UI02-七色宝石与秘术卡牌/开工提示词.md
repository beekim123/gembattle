你正在接手一个独立、自包含的像素奇幻卡牌与图标集外包制作任务（UI-02）。你只需要阅读本外包目录内的文件，严禁虚构外部依赖，也不要改动已有验收文件。

请先依次阅读本目录内的以下文件：
1. ./README.md
2. ./设计文档-宝石卡牌与图标集.md（7 色切面宝石牌、8 张秘术牌、废牌/牌背、4 雕琢、10 印记、6 战利品与全部接口签名）
3. ./verify.mjs（自动化硬校验红线）
4. ./preview.html（独立验收展示台）

【交付目标】
请用单个脚本一次性在 ./bundle/ 目录产出以下 3 个文件，并打包为可下载的 bundle_ui02_cards.zip（内含 bundle/pack_cards_icons.js、bundle/manifest.json、bundle/交付说明.md）：

1. ./bundle/pack_cards_icons.js：
   - 登记到 window.Code00ArtPacks = window.Code00ArtPacks || {}; window.Code00ArtPacks.cards = { id: 'cards', version: 1, name: '...', CARD_W: 62, CARD_H: 88, init, drawCard, drawCardBack, drawChainSlot, drawCarveBadge, drawSealIcon, drawLootBadge };
   - 核心美术品质要求：
     * 7 色宝石牌彻底弃用大号黑体字「红/黄/紫」，牌面中央精绘 7 种独特切面多面体像素宝石（菱尖/八角盾/祖母绿方柱/泪滴/风筝钻/双尖簇/六角白晶核），配复古金属像素牌框与顶部 3 颗三原色晶孔（按色环混色点亮红/绿/蓝圆晶，0.2 秒一眼认出颜色与可破盾色）；
     * 8 张秘术牌（spring, ward, shatter, surge, resonance, refract, prism, keep）每张都有独立可辨识的像素插画与专属框（瞬发银紫框 vs 入链带色金纹框），牌底写精简 4 字卡名；
     * 缠藤废牌(junk)与遮蔽牌背(masked)质感鲜明；牌背(drawCardBack)带六色罗盘暗纹；施法链槽(drawChainSlot)做成石刻法阵镶嵌槽；
     * 4 种雕琢角标、10 个秘宝印记、6 种战利品角标全部为独立精绘像素徽章，绝不偷懒画单色圆点加首字母；
   - 性能与合规死红线（verify.mjs 逐条查杀）：
     * 绝不出现 ctx.filter 或 .filter =；
     * 绝不出现 shadowBlur；
     * 绝不加载外部图片/字体/网络 URL（全靠 Canvas 2D 像素预烘焙到小型离屏画布）；
     * 离屏画布总占用 <= 3 MB，init 耗时 <= 60 ms；
     * 全部字符串零禁用字（正则见 verify.mjs）；
     * 绘制后完整 save()/restore()，关平滑保持像素清晰锐利。

2. ./bundle/manifest.json：列出全部卡牌、印记、雕琢、战利品图标清单与离屏内存字节数。
3. ./bundle/交付说明.md：记录设计说明、verify.mjs 校验结果与 preview.html 视觉目检确认。
