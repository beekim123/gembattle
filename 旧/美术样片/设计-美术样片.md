# 设计 · 异能卡牌：迷雾森林

> 现在的设计。设计改了就直接改这里，别让它跟游戏对不上。数值是起点，做的时候用模拟器调。

## 一句话
你是个用牌的异能者，三颗宝石绕着你转，替你照亮脚下。你走进了这片起雾的林子——里头分三段：砍柴坡、老林子、蛤蟆塘，每段尽头有个「看门的」守着石门；最里头的空场子上，站着一个高个儿。林子里走丢的人，都是它领走的。打倒它，雾就散了。半路倒下，就带着铜板回石碑，下回走得更远。

## 取名的规矩
名字像林子边上村里的小孩给东西起的外号：具体、土、有点好笑，越平常越瘆人（跟「提可」一个味儿）。**不用**灯、烬、影、夜、魂、噬、幽、渊、星、光这类词，不用「守×者」「×之×」这种套路。新加的东西照这个来。

## 改方向：一片一片地走（2026-11-22 定的方向，细节待定）
> 用户定了：美术风格（第 1~4 步 + 优化一轮）先这样，接下来改核心玩法——学哈迪斯那种「一间一间」的肉鸽：每片林子只有一两团鬼火，地图做宽敞，**战斗、地图探索、构筑分开设计**。下面是大方向，细节一条条跟用户对过再写死；对完以后，底下旧的「整局流程」「核心循环」照这个改掉。

**一局怎么走**
- 一局还是三段（砍柴坡 → 老林子 → 蛤蟆塘）+ 空场子的高个儿。每段拆成 **5~7 片**林子，一片一片往北走（片数按一仗几分钟反推，一局 40~60 分钟上下）。
- **一片** = 一块宽敞的空地，南边进、北边出。里面 **1 团鬼火**（偶尔 2 团或一团红的精英），外加一两样能碰的小东西（树洞、石头底下、岔路尽头、一个小事件），东西少，但每样都有用。
- 打完这片的鬼火，北边亮起 **2~3 个出口**，每个出口上挂一个记号，**写明下一片给什么**：新牌、零碎、强化、回心、删牌、铜板、事件……「往哪走」就是构筑的选择（哈迪斯真正好玩的是这个，不是房间本身）。
- 片的种类：普通仗、精英仗（奖励更好、更难）、歇脚（石碑，没有仗）、事件（选一选，可能有仗）、货郎（拿铜板买，每段最多一次）、看门的（每段最后一片）。

**三块分开做**
- **战斗**：保留现在的底子（宝石链、接上 / 合白 / 彩虹的倍率、点数 100 起的大数字、怪的倒计时、每只怪一个克制特性），单独迭代。要补的维度：防守和操纵倒计时（参考 Wildfrost：倒计时是双方都能拨的资源），让每一仗不只是「攒够了一把打死」。
- **地图探索**：只管「这片长什么样、有什么能碰、出口怎么选」。没有动作战斗；鬼火还是会慢慢飘过来。每片是宽敞的手摆 + 随机的空地，有地标（大树、水塘、倒木、石碑），路不用再特意修。
- **构筑**：零碎和带词的牌按**「是谁落下的」分家**——都是以前在林子里走丢的人（放牛娃、采药的、货郎、唱戏的、砍柴的……名字照规矩起）。每家一种打法（比如攒牌、多发小伤害、颜色 / 彩虹、单发重击、铜板），出口记号上看得出是哪家的；同时拿到两家的东西，会出「两家合用」的件。让人一局里能说出「我这把玩的是 ×× 流」。

**局外**
- 死了 / 回去带着铜板回大厅，换永久的好处、往池子里加牌和零碎。
- 跟分家连起来：把某家的东西带出林子，那个走丢的人就「回来了」，站在大厅里，能说话、能解锁他家的东西。卡册改成碰到过才亮。

**还没定、要跟用户对的**：一段几片；鬼火能不能绕开（现在倾向：必须打完才开出口，跟哈迪斯一样）；分几家、各家打法；货郎和事件做多少；心是一局里不回满的资源还是每段回一点。

## 整局流程（旧，按上面的新方向改）
大厅（石碑空地）→ 砍柴坡 → 老林子 → 蛤蟆塘 → 空场子（高个儿）→ 结局：雾散了，天亮了

- 每段是一块有边的林子（约 7×7 区块，走穿二十来秒），四周是走不过去的密林和浓雾。南边进，北边是石门，门前站着这一段看门的。
- 段里散着：鬼火 4~5 团（普通怪，可以绕开）、红鬼火 1 团（精英，摆在后半段）、石碑 1 块（歇脚，在主路边上）、树洞 1~2 个（躲在离路远的地方，洞口飘着金色光点；里面是以前走丢的人落下的东西）。石碑和树洞走过去碰一下就打开。小地图走过的地方才亮；看门的一开始就标着，永远知道往哪走。
- 打倒看门的 → 石门打开 → 下一段：林子更暗、雾更浓、怪更凶。
- 心打光 = 这一局结束；Esc 也能主动回大厅（同样算结束）。两种都把铜板带回去。
- 一局 30~40 分钟，15~20 仗。

## 核心循环（旧，按上面的新方向改）
走 → 碰鬼火开打 → 赢了：三选一拿牌、宝石涨经验（精英和看门的先掉三件零碎挑一件）→ 石碑歇脚（回 2 颗心 / 强化一张牌 / 删一张牌，三选一，用一次就暗）→ 往里走。
局外：铜板丢进大厅石碑前的破碗里，换永久的好处、解锁新牌，下一局走得更远。

## 战斗
**一回合**：摸牌 → 把牌按顺序排进「链」→ 施法，一张张打出去 → 怪的倒计时减一，到 0 就出手。

- **摸牌由少到多**：第 1 回合摸 2 张，之后每回合多摸 1 张（2、3、4、5、6 封顶）。没打的牌留在手里，手牌上限 10。所以每一仗都是先慢热、后爆发。
- **出牌不限张数**，也可以一张不打直接「攒着」。点一下牌就排进链（也能拖），空格施法。
- **伤害**：每张宝石牌按身上的宝石（红 / 绿 / 蓝）打出 1~3 发，从绕身的同色宝石射出去。
  每发伤害 = 牌的点数（起步 100）× 链倍率 × 宝石等级加成 × 零碎加成；10% 暴击 ×2。

**接链**（色环：红-黄-绿-青-蓝-紫-红；黄 = 红+绿，青 = 绿+蓝，紫 = 红+蓝，白 = 红绿蓝）

| 跟上一张比 | 叫法 | 效果 |
|---|---|---|
| 有同一种宝石（同色、邻色） | 接上 | 倍率 ×2 |
| 合起来正好红绿蓝齐全（补色） | 合白 | 倍率 ×2，再补一发白光（三色各一发） |
| 什么都不沾 | 断 | 倍率回到 ×1 |

- 白牌跟谁都接；无色牌（法术）不算接也不算断。
- **彩虹**：一次施法里，一条没断的链凑齐六种颜色 → 从此每接一张 ×3（本来 ×2）。
- **攒牌还是出手**：倍率每次施法都从 ×1 开始，所以手里攒的牌越多、链越长，伤害翻得越狠——第 1 回合只有 2 张，攒到第 3 回合能排七八张、×100 以上。怪的倒计时逼你在「再攒一回合」和「现在就打」之间选；有的怪专门惩罚攒牌，有的专门惩罚小打小闹。（倍率留到下一回合是后期零碎「保温杯」的事，不是默认规则——模拟过，默认就跨回合的话第 5 回合就破百万倍，整局数值会崩。）

**怪**：头上显示血量、倒计时、下一招。倒计时到 0 出手，打掉半颗到两颗心。每只怪带一个特性，逼你换打法（见下表）。
**主角**：心起手 4 颗（半颗为单位），跨仗不回，靠石碑、零碎回。「挡一下」能挡一次攻击。普通怪可以逃（丢半颗心，怪留在原地）；看门的和高个儿不能逃。

**数字**：每发一个数字，越大字越大；暴击金色、合白白色大字、彩虹七彩；施法时正中滚着这一次的总伤害。一万以上写成「1.28万」「3.6亿」。

## 成长
**局内**（每局从起手牌组重新开始）
- 牌：每仗赢了三选一（可跳过）；石碑可以强化（点数大涨或效果加强）或删牌。
- 宝石：红绿蓝各自按打出去的发数涨经验，每升一级该色伤害 ×1.5。
- 零碎：树洞里摸一件、精英和看门的掉三件挑一件，被动加成，一局十件左右。

**局外**
- 铜板：普通怪 1~3、精英 5、看门的 10、通关 30，死了也带回去。
- 大厅石碑前有只破碗，丢铜板换永久的好处：多一颗心（三次）、第一回合多摸一张、宝石起步高一级（三次）、新牌进奖励池（三批）、带一件零碎进林子。
- 记录：最远到哪、最高一击、最高一次施法、通关次数。

## 数值曲线（目标）

| | 每次施法打出 | 普通怪血量 | 精英 | 看门的 |
|---|---|---|---|---|
| 砍柴坡 | 几百 → 几万（攒满一把近十万） | 1500 ~ 7200 | 1.2 万 ~ 2 万 | 老墩 15 万（根须每回合 9000） |
| 老林子 | 几万 → 几百万 | 5 万 ~ 20 万 | 35 万 ~ 65 万 | 大眼珠 500 万（盯着的颜色减半） |
| 蛤蟆塘 | 几百万 → 几亿 | 200 万 ~ 800 万 | 3000 万 | 蛤蟆娘娘 2 亿 |
| 空场子 | 几亿 → 几百亿 | | | 高个儿 50 亿 |

- 一仗之内靠链倍率指数涨：起手牌组粗算，每回合都打是 300 → 2 万多；攒到七八张一把打是 5 万~10 万（`node tools/sim.js`）。
- 一局之内靠强化、宝石等级、零碎把底数抬一千倍以上；彩虹（每接 ×3）、多摸牌、加手牌上限、保温杯让后期指数更陡。
- 普通怪 2~3 回合打死，精英 3~4，看门的 4~6。
- 普通怪的血 = 这一段的底数 ×（1 + 3 × 离入口多深，0~1）× 各怪的血厚系数（提可 1、打伞的 1.2、扑棱 1.1、木木 0.9）；精英再 ×3。老墩的根须 = 血的 6%。一段里几种怪轮着摆，每种都碰得到。

## 怪（全部原创，像素堆叠，代码生成）
都是林子里长出来的**魔物**：书、木偶、眼珠子、泥人这类「本来不该会动的东西」活过来，身上带一点发光的符和法阵；不用猫头鹰、鹿这种普通动物。

| 在哪 | 怪 | 长相 | 特性 |
|---|---|---|---|
| 砍柴坡 | 提可 | 四片暗红翅膀的小飞虫（已有） | 扑闪：每次施法的第一发躲开 |
| 砍柴坡 | 打伞的 | 远看像个穿浅色长褂、扛着伞的人；近看是驼背的菌子，伞往后仰，伞沿上一排白眼 | 抖伞：每回合往你牌堆里抖一张「孢子」（没用、占位置） |
| 砍柴坡·看门的 | 老墩 | 活过来的老树墩，正面树洞里两点光，两截断枝像胳膊 | 扎根：每回合长满一圈根须先挡伤害（血的 6%），一次施法打不穿就伤不到它 |
| 老林子 | 扑棱 | 一本自己会飞的旧书：包金角的封皮，两扇书页当翅膀扑棱，页上画着发青光的符阵，书缝里睁着一只竖瞳的眼，夹一根红书签 | 撕页：每回合撕下一页纸糊住你一张手牌（牌背是一页黄纸、一个红圈问号；照样能打，打出去才翻开；链里有糊住的牌，预计伤害就算不出来）。专治攒牌 |
| 老林子 | 木木 | 没刻脸的提线木偶：蛋形木头脑袋裂了一道缝，红褂子胸口一个发光的符，小臂上绑着镰刀；头顶几根发光的线通到雾里，猛一扯就挥镰刀（凶的眼睛发红） | 急性子：倒计时只有 2，没法慢慢攒 |
| 老林子·看门的 | 大眼珠 | 老树根窝里长出来的一颗磨盘大的眼珠子，满是血丝，树皮眼皮会眨；十来条根须撑着它，身边绕着三块刻符的小石头；眼仁发它正盯着的那种宝石色 | 盯着：它盯着的颜色（头上写着、眼仁和石头上的符也是那个色）每发减半，合白的白光也按颜色算；每回合换一种 |
| 蛤蟆塘 | 泥娃娃 | 塘泥捏的小人，头上插着芦苇，掉了泥自己会捏回去 | 捏回去：每回合回 15% 血 |
| 蛤蟆塘 | 钓鱼的 | 水草缠成的驼背东西，一根手指长得像钓竿，竿头吊着一颗亮饵 | 滑溜：你手里每攒一张牌，它受的伤害少 8% |
| 蛤蟆塘·看门的 | 蛤蟆娘娘 | 巨大的蛤蟆，背上一片会亮的卵 | 孵蛋：每两回合攻击 +半颗心 |
| 空场子 | 高个儿 | 戴斗笠、腿和胳膊长得过分的人形，站着不动时像棵树 | 三段：伸手抓走你一颗宝石（那色只剩一成伤害，合白能打下来）；血到 2/3、1/3 时跺脚，震掉你一半手牌；最后一段倒计时 1 |

- 精英（红鬼火）= 这一段的普通怪加个「凶」字（血 ×3，攻击 +半颗心），眼睛发红、身上一圈红光（不放大：非整数倍放大像素会不齐）。
- 高个儿一路上就在：探索时偶尔能看见远处树中间站着一个特别高的影子，走近就没了。
- 不血腥：怪死了散成光点；主角挨打是心碎、屏幕抖、冷色一闪。
- **林子里看得见真身**：远处只有一团鬼火；走近（看门的约 150 步、别的约 100 步内）鬼火底下慢慢显出它的样子，鬼火缩到它胸口 / 眼睛里，照亮它一圈。
- **卡册**（大厅）：每种怪一格，点开看大图、在哪、特性、血 / 倒计时 / 打几颗心、一句来历，记着碰到几次、打倒几只；精英能切着看。现在还在测试，全部摊开（`album.js` 的 `ALBUM_ALL`），以后改成碰到过才亮。

## 牌
**起手 12 张**：红、绿、蓝各 2，黄、青、紫各 1，白 1，挡一下 2。

**宝石牌**（有颜色，进链）：红、黄、绿、青、蓝、紫、白七种，加带词的变体（奖励里随机配色，比如「青·垫脚」）——
双响（打两遍）、垫脚（下一张接上时 ×4）、开花（每发再炸出 3 发小的）、稳（断链时不回 ×1，只减半）。

**无色牌**（法术，不影响链）——
挡一下（挡下怪的下一次攻击）、放大镜（倍率 ×3）、学舌（把上一张再打一遍）、唱反调（变成上一张的补色，一定合白；接在白牌后面就当白）、跟屁虫（变成上一张宝石牌的颜色，一定接上）、撒豆（打 8 发豆子，每发 25 点 × 倍率）、摸牌（马上摸 2 张）、打岔（怪的倒计时 +1）、叠罗汉（稀有，这次施法后面每接一次多乘 1：×2 变 ×3）、全家福（稀有，马上凑齐六色）。
怪塞进来的：孢子（没用，打出去就没了）。

每张牌能强化一次（+）：点数 ×2.5，或效果加强。

**牌面**（44×62 像素，整数倍放大：手里 ×2、链里 ×1.5、奖励 ×3）：金属边框（宝石牌按宝石色、法术钢色、立刻牌铜色、稀有和强化过的金色），中间一个拱形小窗，窗里一圈法阵和星点，放着切面宝石（1 / 2 / 3 颗）或法术的图；左上角点数牌、右上角宝石小点，底下名牌；稀有一颗星、强化一圈闪光。

**零碎**（被动，都是以前走丢的人落下的东西；每件带一句话说它什么样，比如毛线手套「只有左手那只，还潮乎乎的」。已经做了 13 件：毛线手套、慢表、白瓷片、红头绳、绿玻璃、蓝墨水、胶布、灌铅骰子、水果糖、厚棉袄、哨子、万花筒、大口袋；保温杯、存钱罐以后做）——
毛线手套（每回合多摸 1）、慢表（怪开局倒计时 +1）、白瓷片（合白那一发 ×5）、红头绳 / 绿玻璃 / 蓝墨水（该色 ×2）、胶布（断链只减半）、灌铅骰子（暴击率 +15%）、哨子（每次施法倍率从 ×3 起，断了也只回到 ×3）、厚棉袄（心的上限 +1）、水果糖（赢一仗回半颗心）、万花筒（彩虹后每接一张 ×4）、大口袋（手牌上限 +2、开局多摸 1）、保温杯（施法完倍率留一半到下次施法）、存钱罐（铜板 +50%）。

## 画面
- **一套调色板**：林子沿用 neo-1（画师那版）；新的怪和道具用代码按 neo-1 的颜色表、同一种打光（顶上冷光边、底下暖光边）逐体素生成，不混两种画风。`?art=0` 的代码版树和提可不再维护。
- **每段地貌不一样**（`world.js` 的 `FLOORS[i].look`）：砍柴坡疏、亮一点、树墩多；老林子更暗更绿、树挤成片、雾浓、倒木横在路上挡路；蛤蟆塘水多、枯树多（第 5 步细做）。
- **主次**：林子整体压暗压灰，只有能互动的东西（鬼火、石碑、树洞、石门、看门的）发光、颜色最饱和；挡住主角的树冠自动变透明，永远看得见自己。
- **像素**：世界层整数倍放大；镜头停下时切片对齐直角；界面框也按像素画。
- **暗、偏恐怖、不血腥**：越往里越暗、雾越浓；黑暗里一闪一闪的眼睛、远处站着的高个子、慢慢靠过来的鬼火制造紧张；不出现血。
- **战斗**：排牌时看手牌和链，施法时看怪和数字，一次只有一个焦点。
- **像素字**：伤害数字、施法总数、倍率、倒计时、血量这些「数」都用点阵字（`pixfont.js`，数字手画 6×8，带深色描边、顶亮底暗）；暴击金色、彩虹七彩、躲开灰色。文字说明还是系统字。
- **路要看得清**：主路是一条宽的浅色土路，两边的树让开（南边让得多，免得树冠盖住路）；拐弯处插着系红布条的木桩，路边隔一段一丛发光的菌子；主角跟前盖住主路的树冠变半透明。

## 分步做（每步做完都能玩）
1. **战斗重做**：新摸牌（2 张起、手牌留着）、链规则（接上 / 合白 / 断 / 彩虹）、点数 100 起、新的数字显示、怪的意图、新的牌；每局从起手牌组开始；先只有提可。
2. **一局的骨架**：有边的一段林子、南进北出、石门 + 看门的、固定的鬼火、小地图迷雾、心跨仗、死亡 / 回大厅结算。
3. **砍柴坡做完整**：打伞的、老墩、精英、第一批零碎、石碑歇脚、树洞、宝石等级。
4. **老林子**：地貌；扑棱、木木、大眼珠；更多牌和零碎。
5. **蛤蟆塘**：地貌；泥娃娃、钓鱼的、蛤蟆娘娘。
6. **空场子**：高个儿三段战 + 结局（雾散了，天亮了）。
7. **局外成长**：铜板、石碑的破碗、解锁、记录。
8. **打磨**：画面主次、音效（WebAudio 现合成）、模拟器调数值、从头到尾试玩。

**暂不做**：一局中途存档、商店和随机事件、一次打多只怪。
