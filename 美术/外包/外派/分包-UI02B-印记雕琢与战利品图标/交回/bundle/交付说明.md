# UI-02B 交付说明：印记、雕琢与战利品图标（轻量包）

## 一、包体概览
- **挂载契约**：通过 `Object.assign` 合并挂载到 `window.Code00ArtPacks.cards`，保留既有字段，与 `UI-02A` 卡牌包加载顺序无关、互不覆盖。
- **离屏烘焙**：`initIcons(makeCanvas)` 一次性预烘焙 20 枚正式像素徽章与 3 枚未知 ID 兜底徽章（统一 `24×24` 像素缓冲 + 自动 1px 深色轮廓），幂等防重复分配；运行期每帧仅做 `imageSmoothingEnabled = false` 像素贴图绘制。
- **合规指标**：零 `ctx.filter`、零 `shadowBlur`、零外部资源请求、零禁用字。
