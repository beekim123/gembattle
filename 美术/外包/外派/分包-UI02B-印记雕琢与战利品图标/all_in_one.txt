# 外包分包 UI-02B：印记、雕琢与战利品图标（轻量包）

> **拆分说明**：本包是从原 `UI-02` 拆出的**后半轻包**，专攻 **20 枚高频小图标 / 徽章**（10 枚印记 + 6 枚战利品 + 4 枚雕琢），不含卡牌牌面。与 `UI-02A`（卡牌牌面）完全解耦，可并行外派，两者通过 `Object.assign` 无缝合并到同一个 `window.Code00ArtPacks.cards` 契约对象上，加载顺序不限。

## 本包只交付什么
解压后放入本目录 `bundle/`，共 3 个文件：
1. `bundle/pack_icons.js`（核心绘制脚本，合并挂载到 `window.Code00ArtPacks.cards`）
2. `bundle/manifest.json`（包元信息：id、version、iconsCount、author 等）
3. `bundle/交付说明.md`（20 枚图标配色与造型要点说明）

## 怎么发给网页端 AI
1. 双击 **`打包发给网页AI.command`**，生成本目录下的 `all_in_one.txt`；
2. 把 `all_in_one.txt` 拖进网页端 AI，发送口令：
   > 严格按附件末尾的 `开工提示词.md` 开发。务必用单个脚本一次性生成 3 个文件、自检并打包出可下载的 `bundle_ui02b_icons.zip`；正文严禁贴任何代码、JSON 或文档内容，若未打包完成直接停下汇报进度。

## 收包后怎么验收
1. 将收回的 `bundle_ui02b_icons.zip` 解压到 `交回/` 并把里面的 `bundle/` 覆盖到本目录 `bundle/`；
2. 双击 **`预览验收.command`** —— 自动先跑 `node verify.mjs`（校验合并挂载安全性、全部 20 枚图标、零 `ctx.filter`、零 `shadowBlur`、零禁用字、离屏 ≤ 1 MB、初始化 ≤ 30 ms），再自动打开浏览器 `preview.html` 实机目检。

# 设计文档：UI-02B 印记、雕琢与战利品图标

## 1. 美术定位与画风
- **主题**：奇幻森林与秘宝探险 · 高辨识度**几何块面像素图标**（16×16 / 24×24 / 32×32 清晰轮廓，像《杀戮尖塔》《死亡细胞》的徽章清晰度）。
- **核心原则**：
  - 所有图标均在 `14px ~ 36px` 尺寸下高频出现（状态栏、奖励三选一、卡牌角落），**轮廓必须剪影清晰、高对比、一眼能区分**；
  - 用 **1~2px 深褐/深靛像素外框 + 2~3 阶明暗像素块 + 1 像素白/暖黄高光点**，拒绝模糊渐变；
  - 全部图标在 `initIcons(makeCanvas)` 阶段一次性烘焙为小尺寸离屏画布缓存（`24×24` 或 `32×32`），战斗每帧只做 `ctx.drawImage(..., x, y, size, size)`（开启 `imageSmoothingEnabled = false`），零每帧路径重算！

## 2. 强制代码契约（必须与 UI-02A 合并兼容！）
> **最关键约束**：本包（UI-02B）与卡牌包（UI-02A）共同挂在 `window.Code00ArtPacks.cards` 上，**谁先加载、谁后加载都不能互相覆盖**！

必须用 `Object.assign` 合并挂载：
```js
(function () {
  window.Code00ArtPacks = window.Code00ArtPacks || {};
  const host = (window.Code00ArtPacks.cards = window.Code00ArtPacks.cards || {});
  Object.assign(host, {
    iconsVersion: 1,
    iconsName: '像素印记与战利品图标包',
    initIcons,
    drawSealIcon,
    drawLootBadge,
    drawCarveBadge
  });
})();
```
**严禁**写成 `window.Code00ArtPacks.cards = { ... }`（这会抹掉 UI-02A 的 `drawCard` 等方法，`verify.mjs` 会直接报错拦截）。

## 3. 必需接口与 20 枚图标精确清单

### 3.1 `initIcons(makeCanvas)`
- 参数 `makeCanvas(w, h)`：可选工厂函数（若未传则内部 `document.createElement('canvas')`）；
- 一次性烘焙全部 20 枚图标到离屏画布，幂等（重复调用不重复分配）；
- 性能红线：**耗时 ≤ 30 ms**，**全部离屏画布总显存 ≤ 1.00 MB**（20 张 `32×32` 仅约 0.08 MB，极宽裕）。

### 3.2 10 枚印记图标：`drawSealIcon(ctx, sealId, cx, cy, size = 24, opts = {})`
- 绘制中心在 `(cx, cy)`、边长 `size` 的像素徽章；
- 可选 `opts`：`{ active?: boolean, dim?: boolean, count?: number, t?: number }`（`dim` 时降低不透明度；`active` 时在徽章四角点 4 颗像素高光；`count > 1` 时右下角可画小角标）；
- 未知 `sealId` 时兜底画一枚通用古铜像素圆章，不得抛错。

必须逐一精准设计的 10 个 `sealId`（5 个流派色，每派 2 枚，剪影互不雷同）：

| 流派 | 主色 | `sealId` | 含义与像素剪影建议 |
|---|---|---|---|
| 破盾 | `#8ff0ff` | `shatter_tide` | **碎甲白潮**：裂开两半的青白小盾 + 中间一道斜劈白缝 |
| 破盾 | `#8ff0ff` | `desperate` | **孤注破防**：向上突刺的尖锥短矛 + 两侧小碎甲片 |
| 合白 | `#ffffff` | `double_white` | **双重合白**：两枚交叠的菱形白晶（左微偏、右亮白） |
| 合白 | `#ffffff` | `white_echo` | **白潮余韵**：中心纯白晶核 + 外圈两层同心像素圆环 |
| 彩虹 | `#ffb0f0` | `rainbow_bridge` | **五彩虹桥**：红橙黄绿蓝五色像素拱桥 |
| 彩虹 | `#ffb0f0` | `ring_keep` | **彩环常驻**：闭环六色像素圆环 + 中心金色小扣 |
| 留牌 | `#ffd24a` | `wide_bag` | **宽裕行囊**：暖棕束口布袋 + 金色袋扣与鼓囊轮廓 |
| 留牌 | `#ffd24a` | `hold_edge` | **蓄锋待发**：斜放的金色剑刃 + 剑格蓄力像素亮块 |
| 长链 | `#9aff9a` | `leap` | **越隙相连**：两节翠绿锁链中间带一道跨越弧线箭头 |

### 3.3 6 枚战利品徽章：`drawLootBadge(ctx, lootKind, cx, cy, size = 17)`
- 绘制中心在 `(cx, cy)`、边长 `size` 的战利品奖励图标（用于奖励三选一、节点掉落标签）；
- 未知 `lootKind` 兜底画通用金星像素小袋，不得抛错。

必须逐一精准设计的 6 个 `lootKind`：

| `lootKind` | 主色 | 含义与像素剪影建议 |
|---|---|---|
| `carve` | `#6ad8ff` | **宝石雕琢**：倾斜像素刻刀 + 切面蓝晶 |
| `seal` | `#c490ff` | **秘宝印记**：紫金火漆蜡印圆章 + 中心菱纹 |
| `arcana` | `#ffd24a` | **秘术牌**：金边古卷牌面 + 中心暖黄符纹 |
| `hand` | `#7ae07a` | **手牌扩容**：三张错开扇形绿边卡牌剪影 |
| `heal` | `#ff6a78` | **疗伤果泉**：饱满红浆果配两片嫩绿小叶（或红心果） |
| `attr` | `#ff9a3a` | **属性提升**：暖橙向上双箭头 + 底座铁砧/菱石 |

### 3.4 4 枚雕琢角标：`drawCarveBadge(ctx, kind, cx, cy, size = 14)`
- 绘制中心在 `(cx, cy)`、边长 `size` 的小角标（直接叠在宝石牌右上/右下角，**14px 依然清晰可读**！）；
- 未知 `kind` 兜底画通用白灰小菱标，不得抛错。

必须逐一精准设计的 4 个 `kind`：

| `kind` | 主色 | 含义与像素剪影建议 |
|---|---|---|
| `sharp` | `#ffb04a` | **锐切**：斜向暖橙利刃斜切角标 |
| `twin` | `#7ad8ff` | **双晶**：左右并排两颗亮青小菱晶 |
| `pierce` | `#ff7a7a` | **碎甲**：红橙裂盾破口小标 |
| `overflow` | `#d49aff` | **溢彩**：紫粉四角溅射像素星芒 |

## 4. 铁律红线（`verify.mjs` 自动拦截）
1. **绝对禁止** `ctx.filter`（或 `.filter =`）与 `ctx.shadowBlur`（无论源码还是运行期）；
2. **绝对禁止**外部图片/字体/URL（`new Image`、`http://`、`https://`、`fetch(`）；
3. **绝对禁止**套路禁用字出现在任何字符串字面量里：`灯、烬、影、夜、魂、噬、幽、渊、星、光` 及 `守×者`、`×之×`（注意：连「星芒」里的那个字也别写进代码字符串，可用「亮芒」「彩簇」「晶徽」等替代）；
4. **单文件精炼**：推荐用轻量辅助函数（`px` / `rect` / `frame` / `diamond` / `ring`）画几何像素块，**全文件控制在 350 ~ 650 行以内**，确保结构干净、执行极快、一次成型不超时。

import fs from 'node:fs';
import vm from 'node:vm';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const ROOT = path.dirname(fileURLToPath(import.meta.url));
const TARGET = path.join(ROOT, 'bundle', 'pack_icons.js');
const BUDGET_BYTES = 1 * 1024 * 1024; // 1 MB 硬红线

if (!fs.existsSync(TARGET)) {
  console.error('❌ 未找到交付文件：./bundle/pack_icons.js');
  process.exit(1);
}

const canvases = [];
function makeCtx() {
  const grad = { addColorStop() {} };
  const state = {
    filter: 'none', shadowBlur: 0, globalAlpha: 1, imageSmoothingEnabled: true,
    fillStyle: '#000', strokeStyle: '#000', lineWidth: 1,
    font: '12px sans-serif', textAlign: 'left', textBaseline: 'alphabetic'
  };
  let runtimeFilterSet = false, runtimeShadowSet = false;
  return new Proxy(state, {
    get(o, k) {
      if (k === '__flags') return { runtimeFilterSet, runtimeShadowSet };
      if (k in o) return o[k];
      if (k === 'createLinearGradient' || k === 'createRadialGradient') return () => grad;
      if (k === 'createImageData') return (w, h) => ({ width: w, height: h, data: new Uint8ClampedArray(Math.max(1, w) * Math.max(1, h) * 4) });
      if (k === 'measureText') return (s) => ({ width: String(s || '').length * 8 });
      return () => {};
    },
    set(o, k, v) {
      if (k === 'filter' && v && v !== 'none') runtimeFilterSet = true;
      if (k === 'shadowBlur' && Number(v) > 0) runtimeShadowSet = true;
      o[k] = v;
      return true;
    }
  });
}
function makeCanvas(w = 1, h = 1) {
  const c = {
    width: Math.max(1, Math.round(w)),
    height: Math.max(1, Math.round(h)),
    _ctx: null,
    getContext() { if (!this._ctx) this._ctx = makeCtx(); return this._ctx; }
  };
  canvases.push(c);
  return c;
}

};
sandbox.Code00ArtPacks = sandbox.window.Code00ArtPacks;
