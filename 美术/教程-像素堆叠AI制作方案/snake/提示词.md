### 一、造型、体素特点与场景要求
注意：文案、皮肤名、技能名严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。正面统一朝向 `+Y`，`z = 0` 贴地。

1. **主体造型**（推荐体素盒约 `42 × 44 × 38`）
   - 底部是厚实盘绕成一圈半的螺旋蛇躯（用变半径 3D 样条 `polyDist` 流畅盘卷，贴地扎实，带背脊斑纹色带与浅色腹鳞分层）；
   - 中上段为高高昂起的 S 形蛇颈，两侧带标志性的**可微张眼镜蛇式宽颈褶兜帽**（与主躯干分 `partId`，Crease AO 切出锐利轮廓，胸口带花纹图案）；
   - 三角形棱角蛇头微微前倾，额侧嵌一对高对比竖瞳蛇眼（独立亮色瞳仁，0.6 俯视绝不遮挡），吻端间歇伸出一截分叉红信子（截面宽厚 ≥ 2 格避免旋转消失）；
   - **待机循环（8 帧）**：立起的上半身随相位左右优雅小幅摇摆、颈褶轻微张合、尾尖轻轻拍打地面、每轮循环伸吐一次红信子。
   - **可选额外姿态帧**：可预建 1 帧「张口宽兜帽喷吐态」和 1 帧「盘紧压低蓄力态」，让攻击动作张力翻倍。

2. **场景与受击靶**
   - 圆形荒原岩土/遗迹石砖底座（周期纹理 + 固定石边环），前方 `+Y` 方向放置像素堆叠训练靶桩（受击抖动、地面冒泡液池、破土泥块等反馈）。

### 二、4 套色系（零重建模一键换色，快捷键 `C` 或 HUD 按钮切换）
必须基于 `Uint8Array` 索引网格实现 `recolorAsset(skin)`（`< 2ms` 按索引重刷长条图集并清空精灵缓存回收至对象池，**严禁重跑 SDF 建模**），同时联动毒液柱、地面冒泡池、旋风尘沙与破土飞石的配色：
1. **翠绿毒斑（森林毒蛇）**：翠绿鳞甲 + 深墨绿背斑 + 浅黄腹鳞 + 亮黄蛇眼 + 翠绿冒泡毒液池特效；
2. **黑红环纹（赤练）**：炭黑底鳞 + 醒目猩红环纹与颈褶边 + 浅灰腹鳞 + 橘红炽眼 + 赤红烈焰毒液特效；
3. **沙金荒漠（响尾）**：黄沙金鳞甲 + 焦棕菱形背纹 + 米白腹鳞 + 琥珀眼 + 沙金飞沙旋风与黄酸液特效；
4. **冰蓝白鳞（寒霜）**：冰蓝鳞甲 + 雪白颈褶与腹鳞 + 冰青亮眼 + 寒霜白青冰雾液池特效。

### 三、4 个技能演出（按钮或快捷键 `1~4` 触发）
所有技能突出蛇类的弹性突袭、喷毒与游走钻地特征，包含完整 **前摇 → 释放与特效 → 靶桩反馈 → 回位**：
1. **盘身直扑（1）**：上半身先向后盘紧压低蓄力 0.35 秒 → 瞬间如弹簧般向前猛蹿拉长，张大毒牙巨口狠咬靶桩（留一对对称毒牙咬痕与溅射液点），靶桩剧烈后仰，随即快速弹回原位。
2. **毒液喷射（2）**：上半身高高竖起、宽大颈褶完全张开，仰颈蓄力后朝靶桩方向喷出一道弧形高压像素液柱，持续 1.1 秒；液柱落点处地面实时铺开一滩咕嘟冒泡的腐蚀液池（持续数秒后渐隐）。
3. **盘旋尾扫（3）**：整条魔蛇压低身躯，贴地原地高速旋转一圈并猛抡长尾，四周卷起一圈由像素风带、碎石与泥沙构成的环形旋风，吹得靶桩大幅摇晃。
4. **钻地突袭（4）**：魔蛇昂首一扎垂直钻入石台地底（主体向下沉入裁切并溅起像素泥土块）→ 地表出现一条急速冲向靶桩的翻土凸起与碎石轨迹 → 到达靶桩脚下时瞬间垂直破土窜出猛咬一口、炸飞大片土石，随即缩回地底再从原位钻出归位。

### 四、工程性能与强制自检闭环（对照 `README.md` v2）
1. **第 0 步先写空间坐标预算表**，确保盘绕蛇身各圈之间平滑不穿帮、颈褶厚度 ≥ 2.2 格、双蛇眼与口部前端在 0.6 俯视下零遮挡。
2. **极速建模与旋转满帧架构**：
   - `Uint8Array` + 部件级 `fillAABB` + `despeckle()` + 垂直 3 档色阶 / 腔体 AO / 白名单 Crease AO + 单张长条图集（保留 `grid` 供 `recolorAsset` 换色），8 帧建模耗时目标 `< 120ms`；
   - 定倍角度烘焙缓存 `BAKE_SCALE = 2.5`（精确 `step = 2`、`1px` 半步压实、`3°` 量化 + 对象池 + 滚轮缩放不清空缓存）；
   - 预渲染天空 `bgc` + `2×` 小地表缓冲集成双层投影/冒泡液池/翻土轨迹 + 缓存模式精灵直绘 `dctx` + 内外发光 `destination-out` 裁切（从 `minGlowZ` 起）+ `1/4` 独立小画布 `ebctx` 真降采样模糊；
   - HUD 支持：4 套色系一键切换 (`C`)、4 个技能 (`1~4`)、自动旋转、单体描边、模式切换（游戏缓存 / 高清逐层 / 复古低分）、导出带色系名长条 PNG、最短角路径重置视角、实时性能栏（建模耗时 / FPS / 单帧 ms / 绘制次数 / 色数 / 缓存）。
3. **强制验收闭环**：
   - 跑 Node 自动化脚本校验：色数 ≤ 48、无重色、无未着色、无孤立碎点、双眼正面 `+Y` 与 0.6 俯视射线遮挡 = 0、切换 4 套色系耗时 < 5ms；
   - 本地静态服务 + 浏览器实机验收：零 Console 报错；旋转 360° 检查盘躯圆润度与颈褶层次；测试 4 套色系与 4 个技能演出（尤其钻地沉浮与冒泡液池）；连续拖拽/自动旋转稳跑 60~120fps（单帧 < 2ms）；亲自审片并至少迭代打磨 1 轮后收尾清理临时服务。
