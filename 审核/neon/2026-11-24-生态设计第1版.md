# 审核：异世界生态设计第 1 版（neon，2026-11-24）

- **审的是什么**：`美术/像素堆叠生物工坊/文档/生态设计数据.js`（2026-11-24 第 1 版，21 个生境、21 条连接、42 种吃食、38 条模板、73 只生物），对照 `文档/异世界生物类型扩展草案-M18至M35.md`、`文档/生物图鉴与逐只精制规划.md`、`文档/全品类模板规划与参考.md`、`core/renderer.js` 与 `scenes/habitats.js`。
- **总体评价**：骨架很稳。动作照地球生物力学、材料/角色/关系放开编的规矩落得很实，`火1 + 火2 + 特8`（造冷石板 → 滚球上板舔苔 → 空中盯板扑击）、`树4 + 树5`（冷火逼虫 → 弯竹弹射抢食）、`地8`（宿主背上开花蹭树）、`海5`（退潮散开涨潮扣合）、`泽4`（三头分工）和 `沙6`（假水洼）都有极强的异世界记忆点。29 个 `made` 生物的 `impl` 脚本全部精确对应，数据里零禁用字，新设计全部守住了「不取正式名」的规矩。
- **主要短板**：
  1. 几处数据引用/生境前后矛盾与技术 `note` 写错（不改方向的 **10 处已直接改掉**，下表标「已改」）；
  2. 新增 3 个生境薄弱或偏科（`T20 盐壳湖`、`T21 热泉梯田` 各仅 2 只且盐壳湖两条链互不相干、`T19 巨兽遗骸` 3 只全挤在分解、缺伏击和寄生）；
  3. 地理连通有断口：`T12 翠绿竹林` 是全图唯一孤岛（0 连线），干地 3 块（`T13/T14/T20`）与世界其余 18 块完全断联，且 `T03`/`T16` 规矩明写了地下温水渗出却未连线；
  4. 少数新提案偏向地球动物放大或同生境撞车（`地5` 像骨白巨蜈蚣、`沙8` 像粉色大螃蟹、`海6` 与 `海7` 在环礁生态位和共生完全重合），以及 `天4`/`特4` 的生态位归类有误。

## 三、以后再说（中期结构与工程排期参考）

1. **多个原有生境「内部零生物间捕食边」**：`T04 石缝河湾`（2 只）、`T10 花丛草甸`（4 只）、`T13 戈壁沙丘`（6 只）、`T14 沙漠绿洲`（2 只）、`T16 苔藓古石遗迹`（5 只）、`T17 沼泽泥潭`（5 只）当前所有生物都只连向 `foods` 基底，生物之间没有直接捕食箭头（比如 `沙6` 和 `沙5` 只吃抽象的 `p_drinker`，`特6` 只吃抽象的 `p_ruincritter`）。现阶段优先把新增 3 个生境补扎实，后续做中后期扩展批次时，再给这些生境补一两只被具象捕食的中小型猎物种（或把部分 `p_*` 小动物具象化），食物网就会真正立体起来。
2. **`天3`（中）捕食 `天5`（大）的幼体标记**：目前 `life` 写了「只抓幼体」，数据结构 `eats: ['天5']` 无法体现仅吃幼体，后续如果食物网需要更细，可支持 `{ target: '天5', note: '幼体' }`。
3. **生产者显式标注**：`树2`、`树3` 是植物类生产者，`eats: []` 是合理的，不是漏填；可以在后续数据结构里加 `producer: true` 标记，免得自动化检查每次误判为「无吃食」。
4. **core 扩展能力依赖清单（按排期批次核对）**：
   - **地表痕迹层（第 1 批）**：`沙1`、`沙3`、`沙7`、`沙8`、`天8`、`遗1`、`火1`、`洞5`，加旧怪重构 `泽1`、`树3`（共 **10 只**）。
   - **跨个体挂点（第 1 批）**：`水4`、`地8`、`地10`、`水7`、`天5`，加旧怪停靠 `沙4`、`地4`、`海3`（共 **8 只**）。
   - **画线能力（第 2 批）**：`树1`、`天6`、`水7`，可选 `泽6`（共 **3~4 只**）。
   - **单部件不描边开关（第 2 批）**：`海6`（海水圆盘+散粒）、`洞5`（菌网格子件+散粒）（共 **2 只**）。
