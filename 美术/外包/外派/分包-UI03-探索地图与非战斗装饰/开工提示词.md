# 开工提示词（UI-03 探索地图与非战斗装饰 · 给无上下文网页端 AI）

```text
你正在接手一个独立、自包含的像素奇幻地图卷轴与非战斗装饰外包制作任务（UI-03）。你只需要阅读本外包目录内的文件，严禁虚构外部依赖，也不要改动已有验收文件。

请先依次阅读本目录内的以下文件：
1. ./README.md
2. ./设计文档-探索地图与非战斗装饰.md（羊皮卷地图底、青苔界门分界带、6 种节点×4 态徽章、标题招牌、卷轴标题条、11 种选项图标、结算 3 枚纹章与全部接口签名）
3. ./verify.mjs（自动化硬校验红线）
4. ./preview.html（独立滚动验收台）

【交付目标】
请用单个脚本一次性在 ./bundle/ 目录产出以下 3 个文件，并打包为可下载的 bundle_ui03_map.zip（内含 bundle/pack_map_panels.js、bundle/manifest.json、bundle/交付说明.md）：

1. ./bundle/pack_map_panels.js：
   - 登记到 window.Code00ArtPacks = window.Code00ArtPacks || {}; window.Code00ArtPacks.mapPanels = { id: 'mapPanels', version: 1, name: '...', init, drawMapScrollBg, drawMapGateDivider, drawMapNode, drawTitleEmblem, drawSceneRibbon, drawChoiceIcon, drawSummaryCrest };
   - 核心美术品质要求：
     * 探索路线图底卷(drawMapScrollBg) 必须做出「冒险家手绘像素羊皮卷」质感，支持任意纵向深度无缝滚动，两侧有手绘卷边与按段区分的林缘/界门/腹地/树冠淡雅地标暗纹，且底色克制、绝不抢路径与节点焦点；
     * 6 种节点(battle/elite/event/shop/camp/boss) × 4 种状态(visited/avail/future/dim) 均为精绘像素徽章，可走节点带无 shadowBlur 的像素动态金环；
     * 标题招牌(drawTitleEmblem) 与非战斗卷轴条(drawSceneRibbon) 彻底取代 PPT 大黑框；
     * 11 种非战斗选项图标(drawChoiceIcon) 与结算 3 枚纹章(drawSummaryCrest) 全部为手工像素精绘（预烘焙到离屏小画布，关平滑锐利显示）；
   - 性能与合规死红线（verify.mjs 逐条查杀）：
     * 绝不出现 ctx.filter 或 .filter =；
     * 绝不出现 shadowBlur；
     * 绝不加载外部图片/字体/网络 URL；
     * 离屏画布总占用 <= 4 MB，init 耗时 <= 60 ms；
     * 全部字符串零禁用字（正则见 verify.mjs）；
     * 绘制结束必须 restore()，不污染调用方 ctx。

2. ./bundle/manifest.json：列出全部地图与装饰件清单、尺寸及离屏内存字节数。
3. ./bundle/交付说明.md：记录设计思路、verify.mjs 自检结果与 preview.html 目检确认。

【强制交付形式】
- 禁止在聊天正文中贴任何完整源码、JSON 或长文档；
- 用单个脚本一次性生成 3 个文件，跑通 node verify.mjs（无 Node 时用 Python 查语法/禁用字/filter/shadowBlur），直接输出可下载的 bundle_ui03_map.zip；未打包完成请直接停下汇报。
```
