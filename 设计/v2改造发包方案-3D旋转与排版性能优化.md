# code00 v2 本地改造方案（伪 3D 可旋转舞台 · 120fps 性能优化 · 全页面排版与四包美术挂载）

> **用途**：本文件给**本地开发窗口的 AI** 直接在仓库 `原型/v2/` 里改代码用（不走外部打包，直接跑本地 `node tools/test.js` 和本地服务验收）。
> 界面与场景的正式像素美术则拆成 **4 个独立自包含美术制作包** 放在 `美术/外包/外派/`，直接外派给网页端 AI 并行制作；两边共享同一套 `window.Code00ArtPacks` 接口契约，交回后拷入即可热插拔合入。

## 一、实机审核确认的三大核心问题与改造目标

### 1. 性能问题（实机压测已锁定头号元凶，必须从 25~46fps 飙回 120fps+）
本机 Chrome GPU 同步压测（与工坊 `tools/bench.js` 同款 1×1 探针法）结果：
- 4K Retina（`3840×2160`）：现状 **36.12ms / 28fps**；仅关掉 `ctx.filter` 后直降至 **4.06ms / 246fps**（单看环境摆件从 `35.48ms` 暴降至 `1.23ms`，提速 **28.8 倍**）。
- MacBook 常见窗口（`2880×1620`）：现状 **22.69ms / 44fps**（低于 `main.js` 的 26ms 降分阈值，降分保险压根不会触发，永远锁死 44 帧）；关掉 `ctx.filter` 后直降至 **2.76ms / 362fps**。
- **必须彻底根治的四处性能病灶**：
  1. **全代码严禁使用主画布 `ctx.filter`**（`workshop-adapter.js#L235,L246` 与 `scene-env.js#L195`）：
     - 摆件压暗 15% 改在实例化时通过调色板或统一轻量压边实现（0 滤镜开销）；
     - 受击闪白改用工坊图集已烘好的剪影格或局部小画布纯白叠加（`< 0.1ms`）；
     - 死亡淡出改用原生 `ctx.globalAlpha`。
  2. **恢复工坊 `StackRenderer` 两阶段批处理管线**：整场摆件 + 怪物 + 主角统一先进 `prepareActor`（集中烘焙不脏图集）→ 统一按世界深度排序 `drawPreparedActor` → 整帧最后只做 **1 次** `flushGlow`。
  3. **取消 `1920×1080`（8.3MB）整屏离屏地面画布**：改为紧凑可旋转像素地砖缓冲（`384×384` ~ `512×512`，单生态 `≤ 1MB` 且跨场缓存复用），严守 Chrome 32MB 贴图断崖红线。
  4. **清除 UI / 弹丸 / 路线图里的实时 `ctx.shadowBlur`**：用双层半透明描边或预绘贴图替代。取消 `main.js` 自降画质的降分保险，改为按 `P` 键可切换的轻量性能浮层（FPS / 帧耗时 / 图集 MB）。

### 2. 伪 3D 可旋转视角与穿帮问题（最严重）
- **根因**：旧 `workshop-adapter.js` 锁死 `R.th = 0`、把所有模型放在 `(0,0)` 再手加 2D 屏幕偏移，变成 2D 贴纸；`env-ground.js` 忘了关闭 2D 假摆件，导致 3D 树/帐篷/石门/树洞背后全叠着 2D 简笔重影；Boss 体量过小且 `0°` 正脸平拍失去堆叠厚度。
- **改造标准（用户已拍板按倾向 A）**：
  1. **建立统一 3D 像素世界舞台（`modules/render/world-stage.js`）**：地面、生态摆件、怪物、主角、脚底暗斑、选中环、3D 粒子与技能弹道全部活在同一个 3D 世界坐标 `(wx, wy, wz)` 中，共享唯一 `StackRenderer` 与镜头角 `th`（保持工坊 `TILT = 0.6`、`HS = 0.8`、`BAKE_SCALE = 2.5`、整数倍 `artPx`）。
  2. **无缝可旋转像素地面（不要圆形展示台，删光 2D 假摆件）**：`env-ground.js` 在 `workshop` 模式下彻底移除 2D 假树/假帐篷/假石门/假树洞，改为随 `th` 同步做 `(c, s, TILT)` 旋转压扁的像素地面 + 四周林缘柔和暗晕。
  3. **可旋转视角交互（用户拍板方案 A）**：
     - **非战斗场景（标题 / 营火 / 行商 / 青苔界门）**：开放 **360° 自由拖拽旋转**（标题页慢速缓转直接亮出伪 3D 招牌）；
     - **战斗场景**：默认采用立体微斜机位（`th0 ≈ 0.28 rad ≈ 16°`），允许在 **`±45°` 扇形角内自由旋转**（右键拖动或左键拖动战区空白地面、`Q/E` 步进、顶栏「回正 `R`」钮），非拖牌时附带极轻柔的 **鼠标 `±4°` 阻尼视差**；另配一个顶栏小开关 **「自由 360°」** 满足随时环看模型。
  4. **3D 投影锚定与体量分级**：血条/盾条/倒计时/飘字/弹道起终点/点选命中框全部经 `world.proj(wx, wy, wz)` 实时计算；对怪头顶 UI 施加顶栏安全下界夹紧（`y >= 58`）；放大首领「千丈古树精」视觉体量至主角约 1.8 倍。

### 3. 全 8 页 UI 排版重做与 `window.Code00ArtPacks` 四包热插拔挂载
- **硬 Bug 清零**：修复 Boss 血条压死顶栏、路线图第 4 步节点被提示条切半与文字叠压、底部手牌贴边轻裁、行商「离开营帐」紧贴卡片。
- **告别 PPT 感**：
  - 统一基调（用户拍板方案 A）：**复古奇幻精绘像素风（暗木 / 暖羊皮纸 / 苔石 / 黄铜镶边）**；
  - 战斗砍掉右上角常驻开发者教学大黑框（仅留简洁生态名签 + 印记图标排；首战引导改为轻量化可关闭底条）；
  - 路线图移除右侧占 20% 屏宽的常驻巨型图例框，改为右上角折叠式「图例 `?`」徽章，地图居中舒展；
  - 营火 / 行商 / 界门 / 偶遇 / 标题 / 结算页全部改为「中上部 55%~60% 通透展示可旋转 3D 场景 + 顶部无厚黑框标题条 + 底部紧凑充实的图标选项卡（杜绝 70% 死黑空白）」。
- **建立热插拔皮肤层**：`modules/ui/skin.js` 自动检测 `window.Code00ArtPacks`，有外包脚本即无缝调用外包精绘，没有时走内置简洁像素底稿，业务场景零改动。

## 三、给本地接手 AI 的两段开工提示词（直接复制到本地窗口）

> **说明**：两段均在**本地仓库**里直接改 `原型/v2/`，**绝不修改 `美术/`、`原型/neon/`、`设计/设计.md`**；每段完成后直接在本机跑通 `node 原型/v2/tools/test.js`（全绿，含零禁用字扫描与导出包单测）及浏览器实机目检。

### 本地开发第 1 段：120fps 性能优化 + 统一伪 3D 可旋转世界舞台

```text
请先阅读 设计/v2改造发包方案-3D旋转与排版性能优化.md 第一、二节，以及 原型/v2/modules/render/ 全部文件、原型/v2/app/main.js、原型/v2/app/scenes/battle-scene.js、原型/v2/app/scenes/panel-scene.js 和 美术/像素堆叠生物工坊/core/renderer.js（只读 美术/，绝不修改 美术/）。

本次只改造 原型/v2/ 的【渲染管线、性能与伪 3D 可旋转世界舞台】，保留全部玩法规则与现有单测（并补齐新单测），必须守住 原型/v2/modules/battle-rules/tests/text.test.js 的零禁用字红线（包括注释与文档）：

1. 【彻底根治帧率（目标 4K DPR=2 稳跑 120fps+，单帧 < 3ms）】
   - 全代码彻底禁止在主画布上设置 ctx.filter（删除 workshop-adapter.js 的 filterFor 与 d.filter）：
     * 摆件压暗 15% 改在摆件实例化时做调色板降亮或无滤镜轻量压暗，每帧 0 滤镜开销；
     * 受击闪白改用图集剪影格或局部小 scratch 叠加，耗时 < 0.1ms；
     * 死亡淡出改用原生 ctx.globalAlpha；
   - 恢复工坊 StackRenderer 两阶段批处理：同场景所有摆件、怪物、主角、3D 粒子统一先批量 prepareActor → 按深度排序 drawPreparedActor → 整帧最后仅做 1 次 flushGlow；
   - 删除 1920×1080（8.3MB）整屏离屏地面画布，改用紧凑缓存的像素地面纹理（384×384 或 512×512，<= 1MB）随镜头角 th 旋转压扁铺满视口；
   - 清除 battle-scene.js、cards.js、ring.js、map-scene.js 中的实时 ctx.shadowBlur；
   - 删除 main.js 中治标不治本的 26ms 自动降分逻辑，改为按 P 键可切换的轻量性能浮层（显示 FPS、帧耗时、图集 MB、渲染模式）。

2. 【真正可旋转的伪 3D 像素堆叠世界舞台（新建 modules/render/world-stage.js，保持 workshop-adapter.js 对外兼容导出）】
   - 严禁再画 env-ground.js 里的 2D 扁平假树、假帐篷、假石门、假树洞与假水洼（仅 ?art=blocks 模式保留简化色块底）；
   - 建立统一 3D 世界坐标系 (wx, wy, wz)，共享唯一 StackRenderer 与镜头角 th（TILT=0.6, HS=0.8, BAKE_SCALE=2.5, 整数倍 artPx）：
     * 生态摆件、怪物、主角、脚底暗斑、选中光环、3D 粒子全部用真实世界坐标排布并按 ry 深度统一排序；
     * 若挂载了 window.Code00ArtPacks?.groundVfx，自动调用其 buildGroundTile / drawGroundAmbient3D / drawSpellBolt3D / drawImpactWave3D / drawAttackFx3D，未挂载时使用清晰像素风内置兜底；
   - 视角旋转控制：
     * 非战斗场景（标题 / 营火 / 行商 / 青苔界门）：默认微斜角，开放 360° 左键/右键拖动旋转与 Q/E 旋转，标题页慢速缓转；
     * 战斗场景：默认立体微斜角（th0 ≈ 0.28 rad），默认在 ±45° 扇形内支持右键拖动、左键拖战区空白地面与 Q/E 旋转，非拖牌时叠 ±4° 鼠标阻尼视差（拖牌时暂停），并提供「解锁 360°」与「回正（R）」控制；
   - 战斗场景（battle-scene.js）的怪物血条/盾条/倒计时、点击命中框、受击飘字、弹道起终点全部改由 world.proj(wx, wy, wz) 动态投影，并对血条顶部加安全区夹紧（绝不压进顶栏）；校准首领千丈古树精体量至主角约 1.8 倍。

3. 【验收】
   - 运行 node 原型/v2/tools/test.js 全部通过（补齐 world-stage 投影、夹角、无 ctx.filter 静态红线单测）；
   - 实机在 Chrome 1920×1080 与 3840×2160（DPR=2）验证：所有 8 个场景无 2D/3D 穿帮重影、可丝滑拖拽/按键旋转、4K DPR=2 下 GPU 同步单帧 < 4ms（>= 240fps 理论能力，稳跑 120Hz 满帧）、0 控制台报错。
```

### 本地开发第 2 段：全 8 页 UI 排版重构 + `skin.js` 复古像素换皮接口

```text
请先阅读 设计/v2改造发包方案-3D旋转与排版性能优化.md 第一、二节，以及 原型/v2/modules/ui/、原型/v2/app/scenes/battle-scene.js、map-scene.js、panel-scene.js 和 app/index.html、tools/export-web.js。

本次在 原型/v2/ 中完成【全 8 页 UI 排版重构 + 复古奇幻像素皮肤换皮层（modules/ui/skin.js）】，严格守住零禁用字红线（text.test.js）、最小字号 24px（12 布局单位）、严禁 ctx.filter 与 shadowBlur、且不改核心战斗与探索规则：

1. 【建立统一 UI 换皮层 modules/ui/skin.js（自动兼容 window.Code00ArtPacks 四包）】
   - 统一封装面板（暗木铜边/羊皮卷/青苔石框/深色浮窗/顶栏）、3 态按钮、心形、金币、血条、色盾、倒计时印章、六色法环、宝石等级条、像素艺术数字、卡牌、施法链槽、印记/雕琢/战利品图标、地图卷轴与节点、非战斗标题条与选项图标、结算纹章；
   - 优先调用 window.Code00ArtPacks.uiSkin / .cards / .mapPanels 中已注册的对应方法；未加载外包脚本时，走内置干净利落的「复古奇幻精绘像素初版皮肤」（暗木/暖羊皮/苔石/黄铜镶边 + 像素描边，彻底告别单调黑底细白边 PPT 框）；
   - 在 app/index.html 预留可选外包皮肤脚本槽位注释，更新 tools/export-web.js 若 modules/art-packs/ 下存在已启用的包脚本一并收入外测 zip（并确保现有 31 个工坊脚本单测全绿）。

2. 【彻底修复全 8 页排版硬伤与视觉层级】
   - 战斗页（battle-scene.js）：
     * 顶栏固定高 32，左（心+金币）/ 中（步数+回合+抽牌堆胶囊）/ 右（视角回正+解锁360°+牌组+音量+重开）三段齐整，绝不与怪血条重叠；
     * 怪头顶血条/名字/倒计时严格位于安全区 y >= 58；
     * 砍掉右上角常驻开发者教学大黑框：右上角改为紧凑生态名签 + 印记图标排（悬停看详情）；教学提示仅在第 1 战以可关闭单行轻条呈现；
     * 左侧「集色环 + 宝石等级」收紧为器物式竖条仪表；底部弧形手牌上提 16 布局单位完整露底不裁切；施法链槽与按钮区紧凑统一。
   - 路线图页（map-scene.js）：
     * 顶部设独立安全头区（y = 0..64），滚动视口从 y = 66 开始裁切，彻底杜绝节点被提示条切半与青苔界门文字外漏；
     * 移除常驻右侧 20% 屏宽的巨型图例框，改为右上角折叠式「图例 ?」按钮（悬停/点击展开），整张卷轴路线图居中舒展；「往上/下拖」提示放固定安全槽不压节点。
   - 标题 / 营火 / 行商 / 青苔界门 / 林中偶遇 / 战利品 / 结算页（panel-scene.js）：
     * 中上部 55%~60% 敞亮展示可自由旋转的 3D 像素场景，顶部用无厚黑框的卷轴/木牌标题条替代臃肿黑框；
     * 标题页去掉底部两行说明书文案，只留精致林地纹章标题 + 主次按钮；
     * 营火、界门、偶遇、战利品选项卡收紧高度消除 70% 死黑空白，采用「图标徽章 + 标题 + 精炼正文 + 底部状态铭条」标准排版；
```
