### 一、造型、体素特点与场景要求
注意：文案、皮肤名、技能名严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。正面统一朝向 `+Y`，`z = 0` 为最低有效层，通过 `lift = 9~12` 表现灵活空中盘旋感。

1. **主体造型**（推荐体素盒约 `48 × 32 × 30`，悬空 `lift = 10`）
   - 紧凑毛茸茸的圆躯干 + 醒目的**一对大尖耳**（外耳与浅色内耳槽分 `partId` 切出清晰耳廓，厚度 ≥ 2 格防旋转破碎）；
   - 微咧的小嘴露出两颗醒目的洁白小尖牙，额前嵌一对高对比亮色大眼（0.6 俯视下绝不遮挡）；
   - **宽大锯齿弧边膜翼**：翼展宽于身长，**翼骨与翼膜分开记录 `partId`** 用白名单 Crease AO 勾勒翼指骨结构，翼膜厚度务必 `≥ 2.2` 格，翼根 `t = 0` 处稳固锚入身体永不断裂；
   - 腹下收拢一对小巧弯爪；
   - **高频悬空待机（8 帧）**：宽大双翼快速大幅上下拍打、机身随振翅上下起伏、大尖耳轻微抖动，地面保持缩小偏淡的双层投影体现高空悬浮。

2. **场景与受击靶**
   - 圆形洞窟青石板底座（周期纹理 + 散落碎岩边环），前方 `+Y` 方向放置像素堆叠训练靶桩（受击抖动、三爪划痕、声波震颤反馈）。

### 二、4 套色系（零重建模一键换色，快捷键 `C` 或 HUD 按钮切换）
必须基于 `Uint8Array` 索引网格实现 `recolorAsset(skin)`（`< 2ms` 按索引重刷长条图集并清空精灵缓存回收至对象池，**严禁重跑 SDF 建模**），同时联动声波环、爪痕、召唤小蝠群与旋风气流的配色：
1. **深紫褐（洞窟原版）**：暗紫褐绒毛 + 粉灰内耳与紫灰翼膜 + 亮黄眼 + 淡紫锯齿声波与白紫气流；
2. **猩红（精锐）**：黑褐躯干 + 醒目猩红翼膜与红内耳 + 炽红眼 + 猩红爪痕与红黑小蝠群；
3. **冰蓝白耳**：霜蓝灰绒毛 + 雪白内耳与冰青翼膜 + 亮青眼 + 冰白寒风旋涡与青蓝声波；
4. **墨青毒绿**：深墨绿绒毛 + 毒绿斑纹翼膜 + 酸黄眼 + 毒绿声波与绿雾小蝠群。

### 三、4 个技能演出（按钮或快捷键 `1~4` 触发）
所有技能轻快凌厉，包含完整 **蓄力前摇 → 释放与特效 → 靶桩反馈 → 归位**：
1. **声波尖啸（1）**：蝙蝠双翼后收、昂头张大尖牙嘴蓄力 0.25 秒 → 朝靶桩方向连续喷出 3 道逐层扩张的锯齿状像素环形声波，声波横扫过靶桩令其持续高频抖动。
2. **高空俯冲爪击（2）**：先急剧拉升悬空高度 `lift`（地面投影变小）→ 压低双翼沿高速斜线俯冲掠过靶桩上方，在靶桩身前瞬间划出 3 道平行的锐利像素爪痕与溅射碎火/碎屑（按当前色系变色），随即盘旋拉起回原位。
3. **唤出小蝠群（3）**：原地猛拍双翼，身周凭空旋出 5 只迷你像素小蝙蝠（小型体素/双翼剪影），排成螺旋队形先后扑撞向靶桩，把靶桩打得连连晃动后四散飞离。
4. **旋风盘旋（4）**：原地高速打转振翅，从脚下石台卷起一圈旋转上升的像素气流环，连同地面碎石与尘叶一同向外旋推，吹得靶桩摇晃不已。

### 四、工程性能与强制自检闭环（对照 `README.md` v2）
1. **第 0 步先写空间坐标预算表**，重点保证宽膜翼厚度 ≥ 2.2 格、翼骨翼膜连接严密、大尖耳与双尖牙清晰且绝不挡眼。
2. **极速建模与旋转满帧架构**：
   - `Uint8Array` + 部件级 `fillAABB` + `despeckle()` + 垂直 3 档色阶 / 腔体 AO / 白名单 Crease AO + 单张长条图集（保留 `grid` 供 `recolorAsset` 换色），8 帧建模耗时目标 `< 100ms`；
   - 定倍角度烘焙缓存 `BAKE_SCALE = 2.5`（精确 `step = 2`、`1px` 半步压实、`3°` 量化 + 对象池 + 滚轮缩放不清空缓存）；
   - 预渲染天空 `bgc` + `2×` 小地表缓冲集成悬空投影与气流波纹 + 缓存模式精灵直绘 `dctx` + 内外发光 `destination-out` 裁切（从 `minGlowZ` 起）+ `1/4` 独立小画布 `ebctx` 真降采样模糊；
   - HUD 支持：4 套色系一键切换 (`C`)、4 个技能 (`1~4`)、自动旋转、单体描边、模式切换（游戏缓存 / 高清逐层 / 复古低分）、导出带色系名长条 PNG、最短角路径重置视角、实时性能栏（建模耗时 / FPS / 单帧 ms / 绘制次数 / 色数 / 缓存）。
3. **强制验收闭环**：
   - 跑 Node 自动化脚本校验：色数 ≤ 48、无重色、无未着色、无孤立碎点、双眼正面 `+Y` 与 0.6 俯视射线遮挡 = 0、切换 4 套色系耗时 < 5ms；
   - 本地静态服务 + 浏览器实机验收：零 Console 报错；旋转 360° 检查宽翼翼根不裂、尖耳不碎；测试 4 套色系与 4 个技能演出；连续拖拽/自动旋转稳跑 60~120fps（单帧 < 2ms）；亲自审片并至少迭代打磨 1 轮后收尾清理临时服务。
