# 场景环境

- `habitats.js`：21 种野外生境地台（`T01~T21`）+ 即将新增的 `T00` 冒险家酒馆地台，工坊左栏「场景环境」页就是它，点一下换地台。地台的格子、颜色、水面都在这里。
- 以后的**场景摆件**（树、石头、水草、篝火、各生态标志地貌……）也放这个目录，一个一个脚本，写法跟建筑一样（见 `../buildings/README.md`），登记用 `PixelWorkshop.Assets.register(Def, 'scene')`，`../index.html` 里加在 `habitats.js` 下面。
- 会动的摆件（摇的草、流的水）动作写在 `update()` 里；大块的照建筑的规矩拆开。
- **全 21 生态场景制作清单与同步生成提示词**：见 `../文档/酒馆NPC与生态场景制作清单.md` 与 `../文档/提示词-生态场景/README.md`（共 11 档，100% 覆盖 `T01~T21` 全部生态与探索通用摆件，可直接多窗口并行开跑）。
