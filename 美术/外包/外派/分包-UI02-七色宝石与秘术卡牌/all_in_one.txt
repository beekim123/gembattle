# 设计文档：UI-02 七色宝石牌、秘术牌与全套徽章图标（`Code00ArtPacks.cards`）

## 一、核心痛点与视觉目标

- **旧版问题**：现原型里的宝石牌只是纯色渐变方块 + 3 个平圆 + 一个巨大的系统黑体字「红 / 黄 / 紫」，像 PPT 占位贴片，完全没有卡牌游戏的质感与收藏欲。
- **重做目标（复古奇幻精绘像素风）**：
  - **7 色宝石牌彻底去掉大号「红/黄/紫」黑体字**！牌面中央是**手工精绘的多面体切面像素宝石立绘**（每色拥有独特的切割外形与内层晶面反射色阶），四周是锻铁/黄铜镶边像素牌框 + 细密纹饰，顶部固定 3 颗三原色宝石嵌孔（按色环混色规则点亮对应红/绿/蓝小晶珠，0.2 秒就能同时认出本牌颜色和能破哪几色盾！）；
  - **8 张秘术牌**每张拥有专属精绘像素法术插画 + 独立牌框（5 张瞬发无色秘术用银紫符纹框；3 张入链带色秘术用暖金镶边 + 颜色嵌底）；
  - **10 个秘宝印记**与 **6 种战利品角标**、**4 种雕琢徽记**全部做精绘像素徽章（`16×16`~`24×24` 像素原图预烘焙），放大清晰锐利。

## 二、完整资产清单与造型指导

### 1. 七色宝石牌（`color: 0..6`，牌面基准 `CARD_W = 62, CARD_H = 88`）
| `color` | 颜色名 | 含三原色点 `[红,绿,蓝]` | 主色 / 暗面 / 亮面 | 独特宝石切面造型（保证形+色双重辨识） |
|---|---|---|---|---|
| `0` | 红 | `[1, 0, 0]` | `#e2483c` / `#8e1f18` / `#ff9e8e` | 棱角锐利的**红曜菱尖晶**（竖长六角菱钻） |
| `1` | 黄（红+绿） | `[1, 1, 0]` | `#efc93f` / `#9a7a10` / `#fff6b0` | 饱满耀眼的**琥珀八角盾晶**（宽面八边形） |
| `2` | 绿 | `[0, 1, 0]` | `#4cb050` / `#1f6a24` / `#a6f2a0` | 阶梯切面的**祖母绿方柱晶**（祖母绿长方切面） |
| `3` | 青（绿+蓝） | `[0, 1, 1]` | `#3fbac4` / `#14727c` / `#aef6fa` | 灵动修长的**碧海泪滴晶**（水滴尖顶切面） |
| `4` | 蓝 | `[0, 0, 1]` | `#4474dd` / `#1f3f9a` / `#9cc4ff` | 沉稳厚重的**深蓝风筝钻**（上宽下尖盾钻） |

### 2. 八张秘术牌（`card.arcana`）+ 缠藤废牌（`card.junk`）+ 被遮蔽牌（`opts.masked`）
- **5 张瞬发秘术（无色，银紫深框 `#6a5ab8`/`#342a68` + 顶沿菱形瞬发徽记 + 清晰精简卡名）**：
  1. `spring`（涌泉抽牌）：蓝白涌动泉眼与飞出的两枚卡牌剪影
  2. `ward`（护身结界）：青白六边形晶盾结界与护符纹
  3. `shatter`（震裂破甲）：铁锤/晶锥击碎裂纹盾牌的爆发画面
  4. `surge`（魔力沸腾）：沸腾橘红晶焰与向上翻涌的能量棱晶
  5. `resonance`（双色共鸣）：两道弧形色环节点共振连线
- **3 张入链秘术（带色，按 `card.color` 着底色 + 华丽暖金边框 + 顶部三原色晶孔 + 清晰精简卡名）**：

  7. `prism`（倍增棱镜，红/绿/蓝）：双面嵌套菱镜映出 `×2` 折射叠影
  8. `keep`（凝色留存，黄/青/紫）：黄铜沙漏/琥珀封存着一颗稳固宝石
- **`junk`（缠藤废牌）**：枯褐破旧木牌缠满暗绿棘藤，无宝石孔，辨识度极强。

## 三、技术硬红线与精确导出接口

- **全局登记**：`window.Code00ArtPacks.cards = { id: 'cards', version: 1, name: '...', CARD_W: 62, CARD_H: 88, init, drawCard, drawCardBack, drawChainSlot, drawCarveBadge, drawSealIcon, drawLootBadge }`
- **零 `ctx.filter`、零 `shadowBlur`、零外部图片 URL、零禁用字**；
- **离屏贴图总预算 ≤ `3 MB`**（强烈建议把 7 色牌面底图、8 张秘术牌插画、10 个印记、6 个战利品预烘焙在离屏像素画布中，单帧绘制仅 `drawImage` + 动态高亮框，轻松跑 500fps+）；
- **状态隔离**：所有绘制函数必须 `save() / restore()` 干净复原，画像素件时设 `imageSmoothingEnabled = false`。

### 导出接口签名
1. `init(makeCanvas)`：可选幂等初始化（自动懒初始化，耗时 ≤ 60ms）。
2. `drawCard(ctx, card, opts = {})`：
   - 以 `(0, 0)` 为牌中心绘制 `62×88` 的卡牌；
   - `opts.frame`: `'near'`（翠绿像素亮框 `#6fe07a`）| `'comp'`（暖金双线合白框 `#ffd24a`）| `'wild'`（白金辉纹框 `#fff1b8`）| `'break'`（暗红虚线断色框 `#ff7a6a`）| `null`；
   - `opts.lit`: 施法亮起时外圈画明亮阶梯像素金白边（不用 `shadowBlur`！）；
   - `opts.dim`: 变暗遮罩（`rgba(8,10,8,0.52)`）；
   - `opts.masked`: 绘制遮蔽牌背；
   - `opts.tag` / `opts.tagColor`: 若传入，在牌顶上方绘制精简胶囊小标签（如「接上」「合白」「断色」「抵制」）。
3. `drawCardBack(ctx, x, y, scale = 1)`：精绘牌背（深靛蓝木纹底 + 黄铜四角饰 + 中央六色罗盘暗纹）。
4. `drawChainSlot(ctx, x, y, w, h, state = {})`：`state = { isNext, dragging, index, filled }`，以 `(x, y)` 为槽中心绘制石刻法阵镶嵌牌槽（替代粗糙虚线框；拖拽中 `isNext` 槽位亮起金色角标引导放入）。
5. `drawCarveBadge(ctx, kind, cx, cy, size = 14)`
6. `drawSealIcon(ctx, sealId, cx, cy, size = 24, opts = {})`（`opts = { hover, dim }`）
7. `drawLootBadge(ctx, lootKind, cx, cy, size = 17)`

const canvases = [];
function makeCtx() {
  const grad = { addColorStop() {} };
  const state = { filter: 'none', shadowBlur: 0, globalAlpha: 1, imageSmoothingEnabled: true, fillStyle: '#000', strokeStyle: '#000', lineWidth: 1, font: '12px sans-serif', textAlign: 'left', textBaseline: 'alphabetic' };
  let runtimeFilterSet = false, runtimeShadowSet = false;
  return new Proxy(state, {
    get(o, k) {
      if (k === '__flags') return { runtimeFilterSet, runtimeShadowSet };
      if (k in o) return o[k];
      if (k === 'createLinearGradient' || k === 'createRadialGradient') return () => grad;
      if (k === 'createImageData') return (w, h) => ({ width: w, height: h, data: new Uint8ClampedArray(Math.max(1, w) * Math.max(1, h) * 4) });
      if (k === 'measureText') return (s) => ({ width: String(s || '').length * 8 });
      return () => {};
    },
    set(o, k, v) {
      if (k === 'filter' && v && v !== 'none') runtimeFilterSet = true;
      if (k === 'shadowBlur' && Number(v) > 0) runtimeShadowSet = true;
      o[k] = v;
      return true;

}

}
