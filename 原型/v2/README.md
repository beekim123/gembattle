# code00 v2 原型（第 1~2 步：核心战斗 + 落果密林一趟）

照 `设计/重制开发方案-第一到第三步.md` 第一、二、三节做的全新独立原型。浏览器里跑：原生 JS（ES 模块）+ Canvas 2D，零依赖、零构建。

## 怎么玩

Mac 上双击 `启动.command`（会开本地小服务并自动打开浏览器），或者：

```bash
node tools/serve.js --open
```

然后打开 `http://localhost:8200/app/index.html`（8200 被占会自动换下一个口）。

打开是标题页：点「深入林地」走一趟——路线图上挑路（第 1 步到第 8 步）、打怪拿战利品、营火 / 行商 / 林中偶遇，第 4 步打完在青苔界门选「折返结算」或「深入腹地」，第 8 步是林地首领。点「核心试玩（4 场教学仗）」是第 1 步的 4 场递进仗。

网址参数：`?seed=数字` 固定一趟的随机种子；`?mode=tutorial` 直接进 4 场教学仗；`?auto=1&speed=8` 假玩家自动打（只用来测试，可加 `gate=retreat`、`heal=1`、`loop=1`）。

操作：
- 把手里的牌**拖**进链里（只能接在链尾；链里的牌不能拖、不能改顺序）。
- 「退回一张」（退格键）、「清空」（Esc）撤销；「施法」（空格）打出整条链；链空着时这个键变成「过回合」。
- 点怪切换目标；鼠标放到怪上看详情；「查看牌组」看牌组的去向。
- 紫色的瞬发秘术牌也是拖进链区，**松手立刻生效**，不占链位，自动补摸 1 张；废牌拖进来是直接丢掉。入链秘术（带色）照常拖进链尾。
- 鼠标放到手牌、印记上看说明。

## 怎么测

```bash
node tools/test.js
```

跑 `modules/` 里全部 `*.test.js`（色环、断色、合白、彩虹、跨回合、破盾、留牌上限、宝石等级、预览与实战一致、四场仗配置、8 张秘术牌、4 种雕琢、10 个印记、8 场遭遇、路线图连通性、成长与行商与偶遇、假玩家整趟跑通、禁用字扫描）。

## 目录

```
app/                 index.html、main.js（唯一组装处）、flow.js（场景切换）、autopilot.js（测试用假玩家）
app/scenes/          battle-scene（战斗）、map-scene（整屏路线图）、panel-scene（标题 / 战利品 / 营火 / 行商 / 偶遇 / 界门 / 结算）
modules/shared/      色环常量与关系、数值配置、可重放随机数
modules/content/     数据表：29 张牌、秘术牌、印记、雕琢、怪、8 场遭遇、4 个偶遇、8 套生态色板
modules/battle-rules/ 纯逻辑战斗（不碰 canvas，node 直接测）
modules/run-rules/   纯逻辑一趟：路线图生成、节点流程、成长、行商、偶遇、界门、结算
modules/render/      色块角色（blocks.js）+ 生态地面（env-ground.js）与微粒（scene-env.js）
modules/ui/          弧形手牌、血条盾格倒计时、集色环、按钮、飘字、牌组网格、路线图图标
tools/serve.js       本地小服务；/art/ 只读映射到 ../../美术/像素堆叠生物工坊/
tools/test.js        一键测试
```

## 三条工程底线

1. `battle-rules`、`run-rules` 不碰 `document` / `canvas`。
2. 战斗状态是一份纯数据对象；预览 = 深拷贝后空跑同一个 `resolveChain`，跑完丢弃，所以预览和实战不会不一致。
3. 角色和场景摆件只经 `modules/render/` 画，第 3 步换工坊的 3D 像素模型只改这里。

## 没做的

音效、工坊 3D 模型接入、外测包（第 3 步，用户没说开工）。不调平衡（用户 2026-11-24 说的）。
