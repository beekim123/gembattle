## 二、从 `snake` 与 `siren` 踩出来的 8 条实战经验（直接复用，少走弯路！）

1. **必须用 `actorBuf` 局部整体 1px 外轮廓（参考 `siren/index.html` 的 `composeSirenActor`）**
   - 只有鳞节感极强的蛇适合每节单独描边；其余 6 只魔物如果部件各自描边会满身黑线、像廉价拼装玩具。
   - 标准架构：所有小部件按 `wantOutline = false` 缓存在 `BAKE_SCALE = 2.5` 下 → 每帧在紧凑局部画布 `actorRaw`（如 `240×246`，大型成年飞龙可放大到 `300×280`）内按 `ry + lift * 0.08 + bias` 深度排序拼合 → 对 `actorRaw` 做 **1 次** `source-in` 1px 整体外轮廓得到 `actorOut` → 单次贴回 `dctx`。同时在 `actorGlow` 内同步做部件间 `destination-out` 遮挡！实测全程稳跑 `120fps`，单帧仅 `0.3~0.5ms`。
2. **用数学保证「零穿模」：净空预算 + 层序偏置 `bias` + Node 周期断言**
   - 凡有裙摆、披风、背鳍、装甲与四肢/尾巴交界的，先在体素盒里抬高/让出物理净空；
   - 对被包覆的根节加微负 `bias`（如 `-1.4`）、外罩件加微正 `bias`（如 `+0.8`）；
   - 写完部件立刻用 Node 脚本遍历完整动作周期，打印**最小带符号净空**（必须 `> 0`）和**颈/肩/翼根/手握武器接缝误差**（必须 `< 1.0` 格），再进浏览器看图！
3. **偏心旋转部件必须「锁死关节枢轴」（防 1~2px 挤捏缝）**
   - `siren` 曾出现大幅甩尾时尾尖与 `tailFin` 交界处有 1~2px 黑边内凹，根因是 `tailFin` 绕盒中心旋转而非绕鳍根 `pWr` 旋转。
   - **万能解法**：若部件真实关节位于局部 `(px, py)`，摆放世界坐标一律用 `localToWorldXY(jointX, jointY, partYaw, -px, -py)`。**翅膀翼根（飞龙/妖精/蝙蝠）、武器握柄（哥布林/鱼人/妖精）、尾鳍/长尾尖**全都要用这一招！
4. **绝对不要做成「浮空平移的僵硬物体」，必须体现真实生物运动学**
   - 美人鱼第 1 版被用户一针见血指出「像浮空移动的物体，没有鱼类特性」，改为「前倾 56° 流线泳姿 + 脉冲式摆尾加速滑行（Burst-and-Glide）+ 波浪潜浮 + V 形尾流 + 前景白沫破水弧」后一次过关！
   - 剩下 6 只魔物也必须各有鲜明的生物推进方式与 **双常驻生态（`S` 键切换）**：
     - **飞龙 (`feilong`)**：① **原地盘旋吐息待机**（强翼下拍 → 躯干滞后半拍被升力托起！多节龙颈 + 龙头独立环视，多节龙尾平衡波浪摆动，幼年呆萌轻扑高频、成年厚重慢拍更有压迫感）；② **空中盘旋巡航 (S)**（前倾俯冲流线态 + 盘旋时顺向心方向身体压弯、龙尾后拖、翼尖拉出气流涡丝，幼年/成年变身演出用骨骼连续缩放 + 火焰/元素漩涡无缝过渡！）。
     - **哥布林 (`goblin`)**：① **原地贼眉鼠眼警戒**（微蹲起伏呼吸、耳朵抖动、转头张望、不时掂量手里短刀/摸包袱）；② **矮身小碎步巡逻 (S)**（**低重心前倾俯冲躯干** + 高频双腿交替迈步 + 每一步落地瞬间产生脚底小尘土与身体轻弹 + 武器后甩随惯性摆动，绝不滑冰！）。
     - **鱼人怪 (`murloc`)**：滩涂水陆两栖特性！① **浅滩蹲踞警戒**（鳃鳍鼓动呼吸、青蛙/鱼人式低蹲微弹、骨叉轻点水面激出小涟漪）；② **蛙跳扑水巡游 (S)**（滩涂浅水池地台 + **冲刺蛙跳落水溅花 / 低身涉水拍浪前行**，落地/入水瞬间带出前景水花弧与涟漪，彻底区分于陆地小人！）。
     - **妖精仙子 (`fairy`)**：① **花丛悬停轻舞**（4 片蝶翼高频 8 字微振、纤细身躯与双腿轻盈垂摆、长发/裙摆飘带链随风起伏、不时挥法杖洒下微粒花粉）；② **花间穿梭巡飞 (S)**（**前倾轻盈穿梭姿态** + 8 字形/波浪高低穿飞轨道 + 停顿悬停再灵巧加速的昆虫/蜂鸟式节奏 + 身后拉出轻柔花粉拖尾，绝不匀速转铁圈！）。
     - **魔物蝙蝠 (`bat`)**：① **低空扑翼悬停**（宽大皮膜翼强力上下挥拍、**升沉相位滞后于翼下拍**体现真实拍击升力、大耳雷达般微转、利爪收放）；② **高空滑翔俯冲巡航 (S)**（**拍两下展翼滑翔（Flap-and-Glide）**的真实蝙蝠节律 + 大半径压坡度俯冲拉起 + 翼尖气流波纹 + 地面投影随高度显著缩放淡化！）。
     - **史莱姆 (`slime`)**：① **原地果冻呼吸颤动**（体积守恒三轴 Squash & Stretch：`sx * sy * sz ≈ 1`，半透胶质外层 + 内部独立漂浮的核心/气泡/皇冠用**二阶弹簧阻尼**滞后晃动！）；② **弹性蹦跳巡游 (S)**（**真实四阶段跳跃物理**：蓄力压扁贴地 → 向上拉长弹射离地 → 抛物线滞空微圆 → 砸地瞬间大幅压扁 + 二次衰减回弹 + 黏液水渍与飞溅液滴，内核滞后砸下再弹起！）。
5. **环境前景覆盖层，绝不让角色像“贴在背景上的纸片”**
   - 水体（鱼人滩涂）：池底保持干净深浅水色（别画杂乱白斑或平行直线），浸水部位按 3D 深度柔化透明，严禁对宽精灵用 2D `rect()` 水平硬裁；在**角色画完之后**往 `dctx` 叠加前景白沫弧。
   - 陆地/空中（哥布林/史莱姆/飞龙/妖精/蝙蝠）：落地/起跳瞬间画贴地前景扬尘/液花；飞行类严格按高度 `lift` 动态缩放并淡化地面投影，让高空/低空高度感一眼明确。
6. **保留全部原有皮肤、技能与核心特色（严禁缩水！）**
   - 改造前先完整读一遍原 `index.html` 的 `SKINS`、技能列表、快捷键与特效细节（特别是 `feilong` 的幼年/成年双形态、变身动画与 5 套色系），确保一个色系、一个技能都不丢，只是把僵硬的 8 帧翻页彻底升级为 120fps 连续骨骼演出！
7. **旋转满帧与零 GC 铁律一个别漏**
   - `BAKE_SCALE = 2.5`、`3°` 量化、全局复用 2 张 scratch + `canvasPool`、`minGlowZ` 剪枝、2× 小地表缓冲、真 1/4 `ebctx` 模糊、技能零重建模换色（`recolorAsset` + 只清角色缓存不误清靶桩）、最短角复位、HUD 紧凑（`max-width ≤ 420px`）不遮挡巡游轨道。
8. **必须跑通「Node 量化断言 → 浏览器实机多视角审片 + 亲自 `read_file` 看截图」**
   - 千万不要只看文字报告！每改完一只魔物，必须：① 跑 Node 脚本检语法、禁用词、色表、建模耗时、双眼/武器亮核 0 遮挡、关节对齐与净空；② 起本地 `python3 -m http.server` 用浏览器子代理实测多角度近景、巡游态、换色、技能、自动旋转帧率；③ **亲自用 `read_file` 打开 `BROWSER_HOST_FACTS` 的截图肉眼复查**，有问题当场修完复测，再关停本地服务、更新 `进度.md`、单独本地提交！
