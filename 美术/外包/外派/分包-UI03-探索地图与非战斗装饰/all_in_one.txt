# 设计文档：UI-03 探索路线图卷轴与非战斗页面装饰（`Code00ArtPacks.mapPanels`）

## 一、核心痛点与视觉目标

- **旧版问题**：
  - 探索路线图把普通扁平圆圈和虚线直接画在一张压黑的绿背景上，像简陋的 PPT 流程图；
  - 标题页「落果密林」只是裸露的居中无衬线大字；
  - 营火、行商、青苔界门、林中偶遇的顶部都是同一个厚黑矩形框，下面的选项卡片没有任何图标插画、大片死黑空白；
  - 结算页只有一个光秃秃的圆角黑框和两列纯文字表格。
- **重做目标（复古奇幻手绘像素卷轴风）**：
  - 路线图改为**冒险家手绘羊皮探险卷轴**（与暗林背景自然衔接，上下可随任意步数无缝延展，林缘/青苔界门/密林腹地/巨木树冠 4 段在卷轴边缘带淡雅手绘像素地标暗纹：嫩叶小树、青苔石柱、密林荆棘、巨冠古木，绝不抢中央路径和节点焦点！）；
  - 6 种地图节点改为**高辨识度像素探险印章/木石牌徽章**，清晰区分已走过、当前可走（动态金环与指针，禁用 `shadowBlur`）、未来可达、已错过压暗 4 种状态；
  - 标题页、非战斗标题卷轴条、11 种非战斗选项图标、结算页三枚荣誉纹章全部做复古精绘像素风，和 UI-01 皮肤及工坊 3D 堆叠世界浑然一体。

---

## 二、必须实现的 8 个导出接口（精确签名）

**全局登记**：
```js
window.Code00ArtPacks = window.Code00ArtPacks || {};
window.Code00ArtPacks.mapPanels = {
  id: 'mapPanels', version: 1, name: '...',
  init, drawMapScrollBg, drawMapGateDivider, drawMapNode,
  drawTitleEmblem, drawSceneRibbon, drawChoiceIcon, drawSummaryCrest
};
```

### 1. `init(makeCanvas)`
- 幂等预烘焙离屏像素图集（自动懒初始化），耗时 ≤ `60 ms`，总离屏内存严格 ≤ **`4 MB`**。

### 2. `drawMapScrollBg(ctx, x, y, w, h, camY, worldH, gateY, segments)`
- 在路线图滚动视口 `(x, y, w, h)` 内绘制手绘像素探险卷轴底景（屏幕坐标，内部按 `camY` 滚动纵向纹理与地标暗纹，**支持任意 `worldH` 深度无缝纵向平铺**！）：
  - 卷轴主体采用低对比度的**温润暗林羊皮 / 古旧牛皮纸**（建议偏深暖棕褐或灰青羊皮，确保浅金实线、流动暖金箭头、深红/琥珀/紫节点清晰跳出，不刺眼也不闷黑！）；
  - 卷轴左右边缘带精绘像素木轴/毛边卷角与细微经纬刻痕；
  - 沿 `segments`（如 `[{ name: '林缘', from: 1, to: 4 }, { name: '腹地', from: 5, to: 7 }, { name: '巨木树冠', from: 8, to: 8 }]`）的纵向范围，在卷轴边缘柔和绘出淡色手绘地形像素插画暗纹（小树、苔石、古藤、树冠），绝不遮挡中央节点区。

### 3. `drawMapGateDivider(ctx, x0, x1, y, passed, t)`
- 在地图世界坐标 `y`（水平范围 `x0..x1`）绘制**青苔界门横向装饰分界带**：
  - 像素石砖横梁纹 + 缠绕青苔藤蔓 + 居中微型像素青苔石门徽章；
  - `passed === false` 时带淡青苔晶脉微亮提示「前路界门」；`passed === true` 时门扉敞开、色调柔和退后。

### 4. `drawMapNode(ctx, type, cx, cy, r, state = {})`
- 6 种节点类型（`type`）：
  1. `'battle'`（遭遇战）：暗铁交叉双刃徽章
  2. `'elite'`（强敌战）：赤金双角兽首重型盾徽（比普通节点更厚重显眼）
  3. `'event'`（林中偶遇）：靛紫古石符文问号印
  4. `'shop'`（行商营帐）：暖黄条纹商帐与钱袋徽记
  5. `'camp'`（营火整备）：跃动橙红像素篝火徽记
  6. `'boss'`（林地首领）：大型古木金冠王徽（`r` 约 30，极具终战压迫感）
- 4 种节点状态（`state = { status: 'visited'|'avail'|'future'|'dim', hover: bool, t: number }`）：
  - `'visited'`：灰石沉底 + 醒目暖金像素对勾印章；
  - `'avail'`：明亮底座 + 动态双层像素金环呼吸（纯整数环/旋转四角星芒像素点，**禁用 `shadowBlur`**）；
  - `'future'`：清晰常规态，`hover` 时加亮白金像素外框；
  - `'dim'`：压低透明与饱和度（约 35% 对比度），退居背景。

### 5. `drawTitleEmblem(ctx, cx, cy, title, sub, t)`
- 标题页正中招牌（如 `title = '落果密林'`, `sub = '第 1 步 → 第 8 步 · 深入林地探险'`）：
  - 复古像素木牌/铜框纹章底座 + 两侧缠绕嫩绿藤蔓与几颗赤红落果点缀 + 顶部三原色小宝石镶饰；
  - 醒目厚重的主标题字（暖金渐层 + 硬朗 `#0c121a` 描边）与精简副标题带。

### 6. `drawSceneRibbon(ctx, cx, y, w, title, sub)`
- 取代 camp / shop / gate / event / loot 顶部笨重黑盒子的**通透复古卷轴/木牌标题条**：
  - 两侧带内折燕尾丝带或铜钉木梁端头，中间窄而精致，完全不遮挡下方 3D 像素舞台！

### 7. `drawChoiceIcon(ctx, kind, cx, cy, size = 34)`
- 为非战斗界面的每张选项卡片提供**高辨识度像素插画图标**（`24×24`~`32×32` 像素原图预烘焙，彻底消除卡片 70% 空黑！），必须覆盖全部 11 种 `kind`：
  - 营火 3 种：`'camp_heal'`（暖火烤果与红心）、`'camp_carve'`（刻刀与发光蓝晶）、`'camp_purge'`（烧毁旧牌的火焰与行囊）
  - 行商 2 种：`'shop_potion'`（红果玻璃药瓶）、`'shop_carve'`（精工雕琢台）
  - 界门 2 种：`'gate_retreat'`（满载金币的返程布袋与指路标）、`'gate_advance'`（推开青苔石门的利剑与树冠剪影）
  - 林中偶遇 4 种：`'event_wood'`（渗出红浆的空心老木）、`'event_stele'`（嵌晶青苔古石碑）、`'event_pool'`（沉着旧币的林泉水洼）、`'event_bag'`（树根空腔里的旧皮袋）

### 8. `drawSummaryCrest(ctx, cx, cy, outcome, t)`
- 结算页顶部的三枚大号精绘像素纹章（尺寸约 `180×72`）：
  - `'victory'`：古木王冠 + 交错翠叶月桂 + 三原色宝石镶嵌金徽；
  - `'retreat'`：满囊金币布袋 + 铜色指南针返程徽章；
  - `'defeat'`：碎裂红心 + 枯藤缠绕的裂纹石盾徽章。

---

## 三、技术硬红线（`verify.mjs` 自动查杀）

1. 零 `ctx.filter`、零 `shadowBlur`、零外部图片/字体 URL；
2. 离屏画布总占用内存 `<= 4 MB`，`init` 耗时 `<= 60 ms`；
3. 全部字符串零禁用字（正则见 `verify.mjs`）；
4. 每次绘制结束必须 `restore()`，像素图绘制关平滑（`imageSmoothingEnabled = false`）。

// 外包交付自动化校验脚本：UI-03 探索地图与非战斗装饰（运行：node verify.mjs）
import fs from 'node:fs';
import vm from 'node:vm';
import path from 'node:path';
import { fileURLToPath } from 'node:url';

const ROOT = path.dirname(fileURLToPath(import.meta.url));
const TARGET = path.join(ROOT, 'bundle', 'pack_map_panels.js');
const BUDGET_BYTES = 4 * 1024 * 1024; // 4 MB 硬红线

if (!fs.existsSync(TARGET)) {
  console.error('❌ 未找到交付文件：./bundle/pack_map_panels.js');
  process.exit(1);
}

const canvases = [];
function makeCtx() {
  const grad = { addColorStop() {} };
  const state = { filter: 'none', shadowBlur: 0, globalAlpha: 1, imageSmoothingEnabled: true, fillStyle: '#000', strokeStyle: '#000', lineWidth: 1, font: '12px sans-serif', textAlign: 'left', textBaseline: 'alphabetic' };
  let runtimeFilterSet = false, runtimeShadowSet = false;
  return new Proxy(state, {
    get(o, k) {
      if (k === '__flags') return { runtimeFilterSet, runtimeShadowSet };
      if (k in o) return o[k];
      if (k === 'createLinearGradient' || k === 'createRadialGradient') return () => grad;
      if (k === 'createImageData') return (w, h) => ({ width: w, height: h, data: new Uint8ClampedArray(Math.max(1, w) * Math.max(1, h) * 4) });
      if (k === 'measureText') return (s) => ({ width: String(s || '').length * 8 });
      return () => {};
    },
    set(o, k, v) {
      if (k === 'filter' && v && v !== 'none') runtimeFilterSet = true;
      if (k === 'shadowBlur' && Number(v) > 0) runtimeShadowSet = true;
      o[k] = v;
      return true;
    }
  });
}
function makeCanvas(w = 1, h = 1) {
  const c = { width: Math.max(1, Math.round(w)), height: Math.max(1, Math.round(h)), _ctx: null, getContext() { if (!this._ctx) this._ctx = makeCtx(); return this._ctx; } };
  canvases.push(c);
  return c;
}

const sandbox = {
  window: {},
  document: { createElement: (tag) => (tag === 'canvas' ? makeCanvas(1, 1) : {}) },
  performance: { now: () => Number(process.hrtime.bigint()) / 1e6 },
  console, Math, Array, Object, Number, String, Boolean, Set, Map, WeakMap,
  Uint8Array, Uint8ClampedArray, Int32Array, Float32Array, Error, TypeError, RangeError
};
sandbox.window = sandbox;
sandbox.globalThis = sandbox;
vm.createContext(sandbox);

const src = fs.readFileSync(TARGET, 'utf8');
const errors = [];

check(!/\.filter\s*=/.test(src), '源码禁止设置 ctx.filter');
check(!/shadowBlur/.test(src), '源码禁止使用 shadowBlur');
check(!/\bnew\s+Image\b|https?:\/\/|fetch\s*\(/i.test(src), '源码禁止外部图片或网络加载');

const BAD = /[\u706f\u70ec\u5f71\u591c\u9b42\u566c\u5e7d\u6e0a\u661f\u5149]|\u5b88.\u8005|\u4e4b/;
const lits = src.match(/(['"`])(?:\\.|(?!\1).)*\1/g) || [];
const badHits = [];
for (const lit of lits) { const m = lit.match(BAD); if (m) badHits.push(`${m[0]} in ${lit.slice(0, 24)}`); }
check(badHits.length === 0, `字符串含禁用字：${badHits.slice(0, 5).join('；')}`);

vm.runInContext(src, sandbox, { filename: 'bundle/pack_map_panels.js' });
const pack = sandbox.Code00ArtPacks && sandbox.Code00ArtPacks.mapPanels;
check(!!pack, '未注册 window.Code00ArtPacks.mapPanels');

if (pack) {
  check(pack.id === 'mapPanels', `pack.id 应为 "mapPanels"`);
  check(pack.version === 1, `pack.version 应为 1`);
  const reqFns = [
    'init', 'drawMapScrollBg', 'drawMapGateDivider', 'drawMapNode',
    'drawTitleEmblem', 'drawSceneRibbon', 'drawChoiceIcon', 'drawSummaryCrest'
  ];
  for (const fn of reqFns) check(typeof pack[fn] === 'function', `缺少必需方法：${fn}`);

  const t0 = sandbox.performance.now();
  if (typeof pack.init === 'function') pack.init(makeCanvas);
  const initMs = sandbox.performance.now() - t0;
  check(initMs <= 60, `init 预烘焙耗时过长：${initMs.toFixed(1)}ms（上限 60ms）`);

  const ctx = makeCtx();
  try {
    const segs = [{ name: '林缘', from: 1, to: 4 }, { name: '腹地', from: 5, to: 7 }, { name: '巨木树冠', from: 8, to: 8 }];
    pack.drawMapScrollBg(ctx, 140, 64, 680, 476, 120, 960, 480, segs);
    pack.drawMapGateDivider(ctx, 160, 800, 480, false, 1.0);
    pack.drawMapGateDivider(ctx, 160, 800, 480, true, 1.0);
    for (const tp of ['battle', 'elite', 'event', 'shop', 'camp', 'boss']) {

    const kinds = ['camp_heal', 'camp_carve', 'camp_purge', 'shop_potion', 'shop_carve', 'gate_retreat', 'gate_advance', 'event_wood', 'event_stele', 'event_pool', 'event_bag'];
    for (const k of kinds) pack.drawChoiceIcon(ctx, k, 200, 300, 34);

}
