# 开工提示词（UI-01 像素皮肤与通用控件 · 给无上下文网页端 AI）

```text
你正在接手一个独立、自包含的像素奇幻 UI 皮肤外包制作任务（UI-01）。你只需要阅读本外包目录内的文件，严禁虚构外部依赖，也不要改动已有验收文件。

请先依次阅读本目录内的以下文件：
1. ./README.md（包内结构、交付规范与验收流程）
2. ./设计文档-UI像素皮肤与控件.md（复古奇幻像素风视觉方向、完整色板、硬红线与全部 11 个导出接口精确签名）
3. ./verify.mjs（自动化硬性校验标准，你的产物必须 100% 跑通它）
4. ./preview.html（独立可视化验收台，你会清楚看到所有接口如何被调用和展示）

【交付目标】
请用单个自动化脚本一次性在 ./bundle/ 目录产出以下 3 个文件，并直接打包成可下载的 bundle_ui01_skin.zip（内部包含 bundle/pack_ui_skin.js、bundle/manifest.json、bundle/交付说明.md）：

1. ./bundle/pack_ui_skin.js（核心 UI 皮肤脚本）：
   - 通过 window.Code00ArtPacks = window.Code00ArtPacks || {}; window.Code00ArtPacks.uiSkin = { ... }; 登记，id 严格为 'uiSkin'，version 为 1；
   - 完整实现设计文档第四节全部 11 个导出接口：init, drawPanel, drawButton, drawHeart, drawCoin, drawHpBar, drawShield, drawCountdown, drawColorRing, drawGemLevelBar, drawPixelNumber；
   - 视觉品质硬要求：
     * 走「复古奇幻精绘像素风」：暗胡桃木纹+黄铜折角铆钉(wood)、暖羊皮纸+折痕微斑(parchment)、青苔石砖+缺角(stone)、深色镶金浮窗(tooltip)、暗木铜边顶栏(bar)，彻底告别单调黑底白边 PPT 矩形！
     * 面板与按钮全部采用预烘焙 9-slice（九宫格切片）绘制，任意尺寸拉伸四角铆钉/边框绝不变形；
     * 红心、金币、多面体色盾晶格、倒计时青铜/朱红印章、六色法环器物底座、三原色小宝石全部采用手工像素点阵/块面精绘（带硬描边 #0c121a、明暗三色阶与左上高点），关闭平滑保持像素锐利；
     * drawPixelNumber 必须自绘手工 5×7 或 6×8 像素位图字形（支持 0-9 + - − × / % ! . ,），完整支持普通、暴击金橙梯度(crit)、逐字七彩(rainbow) 样式；
   - 性能与合规死红线（verify.mjs 会逐条硬查）：
     * 源码中绝不允许出现 ctx.filter 或 .filter =；
     * 源码中绝不允许出现 shadowBlur；
     * 严禁加载任何外部图片/字体/网络 URL（全靠 Canvas 2D 离屏预烘焙）；
     * 所有离屏画布总占用内存 <= 2 MB（2,097,152 字节），init 耗时 <= 40 ms；
     * 全部中文字符串严禁出现禁用字（正则见 verify.mjs，禁止 10 个禁用字以及 守×者、×之×）；
     * 每次绘制结束必须完整 restore()，不污染外部 ctx 状态。

2. ./bundle/manifest.json：
   - 列出 id、version、name、色板表、预烘焙离屏画布清单与总字节数、以及 11 个导出接口说明。

3. ./bundle/交付说明.md：
   - 记录设计思路、verify.mjs 自检结果、离屏内存占用和 preview.html 目检确认项。

【强制交付形式（硬性要求）】
- 禁止在聊天正文中贴出任何完整源码、JSON 或长文档内容；
- 务必用脚本一次性生成 ./bundle/ 下 3 个文件，运行 node verify.mjs（若环境无 Node 则用 Python 静态检查禁用字、filter、shadowBlur、语法完整性），全部通过后直接打包输出可下载的 bundle_ui01_skin.zip；
- 若未打包完成请直接停下汇报进度，不要空谈或分段贴代码。
```
