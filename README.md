# 异能卡牌 · 像素堆叠原型

俯视第三人称、像素堆叠（sprite stacking）画法的原型。Electron + 原生 JS + Canvas 2D，没有别的依赖。

- 启动：双击根目录的 `启动.command`（第一次会自动装 Electron）。或者 `npm install` 一次再 `npm start`；也可以用任意静态服务器打开 `index.html`。
- 流程：大厅 → 进入迷雾森林 → 碰鬼火开打 → 打赢选牌 → 接着走；随时 Esc / 右上“回大厅”（这一趟结束，牌留着）；心打光也回大厅。牌组存在本机（localStorage）。
- 操作：WASD 走（Shift 跑），Q / E 或拖鼠标转镜头；碰到鬼火进战斗；战斗里把牌从手里拖到上面排进序列，按“施法”。

## 文件
| 文件 | 管什么 |
|---|---|
| `src/engine.js` | 噪声、随机数、体素建模 `build()`、镜头投影 `proj()`、切片叠画 `drawStack()` |
| `src/models.js` | 所有模型（枯树、树桩、荆棘、石头、菌子、枯苇、主角、提可），代码逐体素生成 |
| `src/world.js` | 无限林子：64×64 区块按种子生成、碰撞、鬼火刷新 |
| `src/scene.js` | 画林子：地面 → 物件按远近排 → 黑暗（只亮宝石周围一圈）→ 冷雾、黑暗里的眼睛 |
| `src/rules.js` | 一仗规则，照搬 `card-web/src/rules.js`（色环接链、倍率、色灯、彩虹、合白、暴击、宝石等级、心、倒计时、躲光） |
| `src/cards.js` | 像素牌面 |
| `src/battle.js` | 俯视战斗：拖牌、序列、施法播放、怪攻击、战利品、逃跑 |
| `src/lobby.js` | 大厅：林边石碑空地、菜单（进入迷雾森林 / 牌组 / 退出游戏）、存档 |
| `src/main.js` | 主循环、输入、大厅 ↔ 探索 ↔ 战斗切换、小地图 |

调试：控制台里 `NOLIGHT = true` 关掉黑暗看整片林子。

## 美术
- 画师交的像素堆叠美术放 `art/<版本>/`（现在是 `art/neo-1/`，Neo 第 1 次）。改了 png 以后跑 `python3 art/打包美术.py neo-1` 重新生成 `art-data.js`。
- `src/art.js` 读它，换掉代码生成的树、草、石头、石碑、主角、提可和地面。网址加 `?art=0` 就回到代码生成的。
