# 交付说明 · 第三大 Boss：妖精王（`boss_fairy_king`）

## 一、交付清单

- `bundle/boss_fairy_king.js`：纯原生像素堆叠资产脚本，严格通过 `window.PixelWorkshop` 与 `PW.Creatures.push` 登记，100% 复用主工坊 `./core/`（`PW.Math`、`PW.Voxel`、`PW.Solvers`、`PW.Renderer`、`PW.Assets`），零外部依赖。
- `bundle/manifest.json`：完整资产清单（18 个体素部件盒尺寸、4 套四季换色方案、7 个动作时序与战斗机制、3 个正向运动学挂点说明）。
- `bundle/交付说明.md`：本文件。

## 二、核心规格与防糊红线自检

1. **体素预算与建模开销**：
   - 共 18 个体素部件资产，最大单盒尺寸为 `24×8×22`（上对巨翼）与 `10×10×32`（古藤权杖），**全部严格 `<= 40` 格**。
   - 全部 18 个体素盒累计仅约 **36,600 体素**；6 片蝶翼按上/中/下 3 套对称资产左右镜像复用，双臂共用 1 套资产，3 束长发共用 2 节资产，晶瓣刃与 3 只伴生花灵各自单资产复用，极大压低初始化与图集烘焙占用。
   - 每帧 `buildPartList()` 输出 **22 ~ 31 个**渲染部件（常态 22 个，技能期间叠加最多 9 枚晶瓣刃或 3 只伴生花灵），满足 `>= 14` 要求。
2. **色表与自亮隔离**：
   - `SPEC.pal` 合计 **39 色**（`<= 42` 上限、远低于 `48` 硬限），**0 重色**。
   - `glowKeys` 严格仅包含 `['emissiveMid', 'emissiveHot', 'emissiveCore']`，**`eyeGlint` 与 `wingTrimHi` 严禁进入 `glowKeys`**，保证 0.6 俯视角下五官与金边锐利不糊。
   - 全程 1:1 整数像素绘制，常态无小数 `scaleX` / `scaleY` 拉伸。
3. **骨骼化与零穿模机制**：
   - **六片巨翼与双臂/权杖枢轴锁死**：全部使用 `PW.Math.pivotToWorldXY` 将真实关节锁在后背与手心枢轴，消除旋转挤捏缝；六翼呈 `0` / `-0.45` / `-0.90 rad` 三级相位滞后羽浪。
   - **3 束长发局部坐标背面解算**：严格在机身局部背面外法向（`ly <= -4.0`）叠加限幅转弯侧摆计算，高速 8 字穿飞与转向零穿肩穿背。
   - **双腿防背视角穿裙**：腿根收拢在 8 瓣王者长裙内侧且设置 `bias: -2.20`，360° 无穿模。
   - **五官 0.6 俯视 0 遮挡**：刘海抬高至 `z >= hz + 2.8`，表面扫描精雕 `2×2` 大眼。
4. **4 套四季零重建模换色**：
   - `spring_bloom`（春华翠金）、`summer_crimson`（盛夏绯樱）、`autumn_amber`（深秋枫琥）、`winter_frost`（凛冬冰莲）全部通过 `recolorAsset` 实时刷新图集索引，并保留三色花苞法核鲜明红/绿/蓝辨识度。
   - `applySkin(idx)` 兼容整数索引与无参/非数轮询，适配 `preview.html` 按钮点击与 `C` 键快捷换色。
5. **7 个连续动作与 4 大 Boss 技能**：
   - 已登记并实现 `patrol`、`idle`、`stagger`、`skill_pollen_veil`、`skill_petal_lance`、`skill_sprite_waltz`、`skill_prism_tempest`。
   - 所有部件坐标、弹道落点与浮空高度均严格控制在安全范围内（`|x|, |y| <= 70`，`lift` 处于 `[0, 75]`），零 `NaN`、零越界。
6. **命名与字符串规范**：
   - 已对全部交付文件（代码、JSON、说明文档）执行正则校验，确认零禁用字。
