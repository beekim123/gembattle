## 一、实机审核确认的三大核心问题与改造目标

### 1. 性能问题（实机压测已锁定头号元凶，必须从 25~46fps 飙回 120fps+）
本机 Chrome GPU 同步压测（与工坊 `tools/bench.js` 同款 1×1 探针法）结果：
- 4K Retina（`3840×2160`）：现状 **36.12ms / 28fps**；仅关掉 `ctx.filter` 后直降至 **4.06ms / 246fps**（单看环境摆件从 `35.48ms` 暴降至 `1.23ms`，提速 **28.8 倍**）。
- MacBook 常见窗口（`2880×1620`）：现状 **22.69ms / 44fps**；关掉 `ctx.filter` 后直降至 **2.76ms / 362fps**。
- **必须彻底根治的四处性能病灶**：
  1. **全代码严禁使用主画布 `ctx.filter`**（`workshop-adapter.js#L235,L246` 与 `scene-env.js#L195`）：
     - 摆件压暗 15% 改在实例化时通过调色板或无滤镜轻量压暗实现（每帧 0 滤镜开销）；
     - 受击闪白改用工坊图集已烘好的剪影格或局部小画布纯白叠加（`< 0.1ms`）；
     - 死亡淡出改用原生 `ctx.globalAlpha`。
  2. **恢复工坊 `StackRenderer` 两阶段批处理管线**：整场摆件 + 怪物 + 主角统一先进 `prepareActor`（集中烘焙不脏图集）→ 统一按世界深度排序 `drawPreparedActor` → 整帧最后只做 **1 次** `flushGlow`。
  3. **取消 `1920×1080`（8.3MB）整屏离屏地面画布**：改接 `UI-04` 的 `buildGroundTile(biomeId, makeCanvas, size)`，**按需懒构建单生态地砖并跨场缓存复用**（建议传 `size = 384`，单张仅 `0.56MB`，既避开 8 套一次性全建造成的启动卡顿，又严守 Chrome 32MB 贴图断崖红线）。
  4. **清除 UI / 弹丸 / 路线图里的实时 `ctx.shadowBlur`**：用双层半透明描边或预绘贴图替代。取消 `main.js` 自降画质的降分保险，改为按 `P` 键可切换的轻量性能浮层（FPS / 帧耗时 / 图集 MB / 已加载美术包）。

### 2. 伪 3D 可旋转视角 + 回合制怪物动作接入
- **根因**：旧 `workshop-adapter.js` 锁死 `R.th = 0`、把所有模型放在 `(0,0)` 再手加 2D 屏幕偏移，变成 2D 贴纸；`env-ground.js` 忘了关闭 2D 假摆件，导致 3D 树/帐篷/石门/树洞背后全叠着 2D 简笔重影；Boss 体量过小且 `0°` 正脸平拍失去堆叠厚度。
- **改造标准（用户已拍板按倾向 A）**：
  1. **统一从 `美术/游戏实装美术库/` 取资源**：将 `tools/serve.js` 的 `/art/` 映射与 `tools/export-web.js` 的资源源指向 `美术/游戏实装美术库/`（包含 31 个 3D 资产 + `art-packs/` 全部 5 个 UI/特效包）。
  2. **建立统一 3D 像素世界舞台（`modules/render/world-stage.js`）**：地面、生态摆件、怪物、主角、脚底暗斑、选中环、3D 粒子与 `UI-04` 技能弹道全部活在同一个 3D 世界坐标 `(wx, wy, wz)` 中，共享唯一 `StackRenderer` 与镜头角 `th`（保持工坊 `TILT = 0.6`、`HS = 0.8`、`BAKE_SCALE = 2.5`、整数倍 `artPx`）。
  3. **无缝可旋转像素地面（不要圆形展示台，删光 2D 假摆件）**：`env-ground.js` 在 `workshop` 模式下彻底移除 2D 假树/假帐篷/假石门/假树洞，用 `UI-04` 地面纹理随 `th` 同步做 `(c, s, TILT)` 旋转压扁铺满 + 四周林缘柔和暗晕。
  4. **可旋转视角交互**：
     - **非战斗场景（标题 / 营火 / 行商 / 青苔界门）**：开放 **360° 自由拖拽旋转**（标题页慢速缓转直接亮出伪 3D 招牌）；
     - **战斗场景**：默认立体微斜机位（`th0 ≈ 0.28 rad ≈ 16°`），允许在 **`±45°` 扇形角内自由旋转**（右键拖动或左键拖动战区空白地面、`Q/E` 步进、顶栏「回正 `R`」钮），非拖牌时附带极轻柔的 **鼠标 `±4°` 阻尼视差**；另配顶栏小开关 **「自由 360°」**。
  5. **接入回合制怪物 4 动作**：战斗中正式驱动 `美术/游戏实装美术库/creatures/` 的 8 只怪新增回合制动作状态（`battle_attack`、`battle_special`、`battle_stagger`、`battle_hurt`），攻击与特殊技时传入 `eco.targetPos` 指向主角世界坐标，破盾切 `battle_stagger`，受击切 `battle_hurt`，并与 `UI-04` 的 `drawAttackFx3D` / `drawImpactWave3D` 精准合拍。
  6. **3D 投影锚定与体量分级**：血条/盾条/倒计时/飘字/弹道起终点/点选命中框全部经 `world.proj(wx, wy, wz)` 实时计算；怪头顶 UI 施加顶栏安全下界夹紧（`y >= 58`）；校准首领「千丈古树精」视觉体量至主角约 1.8 倍。

### 3. 全 8 页 UI 排版重构 + 5 个外派美术包正式接入 + 战斗去拥挤与无缝大 Tilemap 地面重装（第 1 步实机后增补）
- **战斗画面去拥挤（用户实机提出）**：拉开主角与怪物纵深距离；未拖牌且链为空时隐藏排序槽，拖牌或链非空才浮现；「退回一张 / 清空 / 施法」移至右下侧边；删掉常驻长篇操作说明文案；缩小怪头顶名字/意图/血条字体使其精致清爽。
- **地面 Tilemap 分层与现有 3D 摆件重装（零新美术资源）**：保留 `UI-04` 的 3D 弹道、波纹、8 怪出手特效与环境微粒，但弃用其带断头路/重复炭坑的 384 小砖直接平铺——改由本地「多变体无缝像素 Tilemap 底纹 + 世界坐标唯一地标层（单火塘 / 单石道 / 林间空地）」合成大尺度无缝旋转地面；现有 3D 摆件不重做模型，只在 `biomes.js` / `scene-env.js` 中按**非对称林缘簇**重排、脚底补接地暗斑、并关闭静态树/石碑的多余动态。
- **硬 Bug 清零与全 5 包正式启用**：修复 Boss 血条压顶栏、路线图第 4 步节点裁切叠字、手牌贴边轻裁、行商按钮紧贴；`app/index.html` 直接加载 `/art/art-packs/` 全部 5 个包脚本，`modules/ui/skin.js` 统一预烘焙初始化（同时保留 `?art=blocks` 兜底），全 8 页实机联调消灭 PPT 黑框。
