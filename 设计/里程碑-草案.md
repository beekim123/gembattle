# 里程碑（草案第三版，2026-11-25，claude）

**状态：等用户点头。** 用户看了第二版，说「看着就是乱的」，又说了自己玩杀戮尖塔的感受，让重新想方向。所以这一版是整个重排，不是在第二版上修。第二版在提交 `dd75f99`，第一版在 `95f22f0`。用户点头以后：
- 并进设计稿 10.4「做的顺序」，替掉第 7 版那句「先打完一仗牌组怎么变，再功能牌、加成，最后工会、装备、任务」；
- 这份标成「已并进设计稿」。

## 一、为什么重排

**用户玩杀戮尖塔的感受**（2026-11-25）：
- 进游戏不讲世界观，直接开打。
- 第一仗很简单：一只史莱姆加一个小怪，血少，手里就几张牌，有伤害牌、有防御牌。
- 靠费用出牌，没出完的回牌库，下回合重摸。每回合都要看着手牌想怎么出。
- 主线很清楚：一条路线从下往上，有奖励、商店、boss、事件。
- 内容简单，可看得出后面设计的点很多。

**拿这几条对照我们**：

| 尖塔 | 我们现在 | 怎么办 |
|---|---|---|
| 进游戏直接开打 | 原型打开就是打仗 | 一样 |
| 第一仗很简单 | 第一仗就有七种颜色、合白、集色、双色盾 | 偏难。先改怪出场的先后，第 2 站做 |
| 主线一眼看得到 | 设计稿第 6、7 节有一样的主线：出口挂奖励、精英、歇脚、事件、商人、看门的。可原型里这些都关着，第二版又把它排到 M5 | **是计划排错了**，这一版提到第 2 站 |
| 每回合都要想怎么出 | 每回合都在找最长的链。假玩家量出来，答案几乎只有一个；出牌又不限张数，手里的基本都打出去，没有要放弃的 | **设计上差得最远的一处**，第 3 站正面解决，要你定 |
| 内容简单，看得出后面有东西 | 只有宝石牌，看不出后面有什么 | 主线做出来、出口上挂着奖励，就看得出了 |

**第二版错在哪**（claude 的错）：
1. **把三种东西排成了一串**：游戏的部件（牌组会变、加成、走一趟、大厅）、找人试玩、检查（美术探针、止损）。所以从里面看不出游戏长什么样。
2. **主线来得太晚**：每一层都放在「连打 10 只」这个试验场里加，主线（出口、看门的）排到 M5。可这种游戏的骨架就是主线，别的东西都挂在它上面。
3. **跟设计稿打架**：M1 举的例子「加一张宝石、删一张、换个颜色」，跟用户定的「宝石牌固定 29 张，不当奖励，一趟里不加不删」（5.2、6.2）冲突。一仗打完牌组怎么变，设计稿早就定好了：出口上挂奖励（6.2）。
4. **文档写得比游戏做得快**：核心试玩做出来以后两天里，写了插件草案、两轮审核、开发调查、两版里程碑；能玩的东西只补了「宝石等级连着带」一处。

**没错、不改的**：
- 先确认核心、一次加一样、现在不调平衡。
- 游戏本身的方向：宝石接链打怪、一趟里攒打法、回大厅再出发。跟尖塔、小丑牌、哈迪斯是一路的。

  - 第 3 站：三五个人闭门试玩；

### 第 2 站　走完一趟（下一个）

**玩家能做什么**
- 打开游戏就在外头区第 1 层。打完一仗，眼前有两三个出口，每个写着下一片是什么（普通、精英、歇脚、看门的），打完给什么。
- 第 2 层最后是看门的。打赢了就算走完这一趟；心掉完就是死了。结束页点一下再来。
- 心和宝石等级一趟里一直带着（照现在）。

**新做的**（全照设计稿第 6、7 节，不另想）
1. 挑出口那一屏（7.3）。
2. 奖励先只放不用改战斗规则的几样：
   - 强化一张宝石牌（6.3，战斗引擎已经认得）；
   - 回心；
   - 属性；
   - 补牌 +1。
3. 精英走红框的出口，多给一次奖励（加成要到第 3 站才有）。
4. 歇脚照 7.2 三选一，没有能删的牌就换成别的。
5. 角上写着第几层、这层第几片、离看门的还有几片。
6. 第一仗简单，往后一只比一只难。只排怪出场的先后，不调数。
7. 留一个「只打核心」的临时开关，方便对比（10.7）。

**这站不做**：大厅、金币、任务、撤离、走路、加成、功能牌、队友、事件、商人。

**要你定的**：只有一样，路线怎么给你看。
- **A** 照设计稿，只看眼前的出口，加一条进度条，画出这一区两层各有几片、看门的在哪。**我倾向 A**：
  - 一层只有两三片，画成路线图也没几条岔路；
  - 看门的在哪、还剩几片，进度条就看得清；
  - 看不全，才有「下一片是什么」的好奇，第 4 站赌撤离也靠这个。
- **B** 像尖塔，每一层一张小路线图，开层就看得到每片是什么、精英和歇脚在哪。

**你玩完要能说**：「主线清楚了，想看下一片是什么」。

**顺便留意**：每回合你是在想「这回合放弃哪个」，还是只在找最长的链？第 3 站要用。

**找人**：一两个身边的人，坐旁边看他玩十分钟，一句不教，看他卡在哪：
- 色环怎么接链；
- 合白；
- 青牌能破哪两色盾；
- 拖牌和撤销；
- 挑出口。

卡住的地方改提示，不改规则。

### 第 3 站　攒出打法

**玩家能做什么**
- 出口上开始挂加成和功能牌。拿过一条路子的加成，后面更容易碰到同一路子的（6.2）。
- 精英多给一次加成。
- 有几只怪专门出题，逼你换排法。

**新做的**
- 照 10.7，在战斗里给效果开口子；
- 一小批加成和功能牌；
- 两三只会出题的怪。

**要你定的**（一次定一样，到时候再出候选）
1. **每回合的取舍从哪来**。这是我们跟尖塔差得最远的一处。大方向有三种：
   - **像小丑牌**：每回合还是排最好的链，靠加成改「什么样的链最好」。不改核心规则。
   - **像尖塔**：每回合加一个「打还是守」，比如有的牌可以不进链，拿去拨倒计时。要改核心规则。
   - **靠怪出题**：有的怪专罚最长的链，逼你换排法。不改规则，靠内容。
2. 先放哪两三条路子、哪几个加成和功能牌。以前冻着的那批只当参考，不照搬；两个照倾向改的加成、长链路子怎么喂，也在这里定。
3. 怪怎么出题。可以从你工坊的生态里挑。

**你玩完要能说**：「这把成了」，而且每回合要想一下。

**找人**：
- 打一个网页包，你传到 itch.io 的私密页，发给三五个人。
- 试玩记录多记三样：总共玩了多久、重开了几次、打到哪只不玩了。
- 看他们会不会不用催，自己再开一把。

**停手**
- 一样东西改两轮还不对，就换掉或删掉。
- 这站做完要是还「每回合排最长的就对」，就停下来跟你商量改核心规则，不往第 4 站走。

### 第 4 站　回家再出发

- **撤离**：每层最后多一个「回去」出口，撤还是继续（7.3）。身上的金币和任务物品，死了会丢（8.2、8.3）。
- **大厅先做最小的**：
  - 工会：任务板、点「提交」、商店买会磨损的装备；
  - 出发；
  - 存档；
  - 先做两三个 C 级任务。
- **要你定的**：
  - 开新游戏是先进大厅，还是像尖塔那样直接开打、第一次回来才见到大厅（我倾向后者）；
  - 先付代价的出口：要不要做，付什么换什么。
- **你玩完要能说**：「死了也想马上再去一趟」。
- **找人**：换一批新的三五个人，打整圈。

### 第 5 站　像正式游戏

- 从开游戏到第一次回家这一段，做成上线的样子：你工坊的怪放进战斗、音效、出手的动画、名字（跟你一起取）。
- 要不要走路、走多少，在这站定。
- **你玩完要能说**：「给不认识的人玩也不丢人」。
- **找人**：不认识的人。
- **提前做的半天**：随时都能插。
  - 把工坊里做好的怪放进 1920×1080 的战斗画面：一只大的，再加一群三只小的。
  - 看四样：尺寸、角度、血条和数字挡不挡、帧数。
  - 只读 `美术/`，不改、不提交。

### 第 6 站　第十趟还新鲜

- **要做的内容**：
  - 中间区、深处区；
  - 六条路子都喂齐；
  - 更多怪、加成、功能牌、事件、商人；
  - 队友；
  - 冒险家等级 C → SSS 和每一级的解锁；
  - 8 种任务；
  - 卡册；
  - 遗迹。
- 到这站才调平衡。
- **你玩完要能说**：「打了十趟还有没见过的东西」。

### 第 7 站　做完上线

- 剧情放多少、最终目标；
- 到了 SSS 以后靠什么再来一把；
- 整体平衡；
- 套上 Electron 的壳；
- 做试玩版。

上架、发链接由你来做。

## 三、你怎么做

1. **玩，然后说感受**。每站做完，我给你一个能直接玩的版本，加两三个问题。你玩二三十分钟，像这次说尖塔那样说就行，不用看文档。
2. **只拍两种板**：两三个候选里挑一个；这一站过不过。
3. **接着玩尖塔**：打到第一个 boss，多死几次。有的话也玩玩小丑牌、哈迪斯，我们的一句话体验就是照这三个写的。玩的时候留意三种时候，告诉我：
   - 什么时候觉得「这把成了」；
   - 在哪个选择前犹豫了；
   - 什么时候想「再来一把」。
4. **看到我又在写流程文档，直接叫停**。第 3 站做出来以前，不写调查，也不送审。
5. 美术那条线照常做，不卡这边。第 5 站用得上。

## 四、我怎么做

1. 每站结束都是从开始页能玩到底的版本，不再往试验场里加东西。
2. 设计稿里定了的照着做，不另想。比如第 2 站的出口、奖励、看门的，第 6、7 节都写好了。
3. 每站开工前写一张卡：玩家能做什么、新做什么、不做什么、你定什么、怎么算过。做完照 10.7 的三条验收，再拿第 2 节的三条支柱比一遍。
4. 一样东西改两轮还不对，就换候选，或者删掉。
5. 现在不调平衡。坏到没法玩了（比如一回合就打死，或者怎么都打不死），先问你再动。
