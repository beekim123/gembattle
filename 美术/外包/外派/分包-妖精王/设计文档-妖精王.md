# 设计文档：第三个大 Boss · 妖精王（`boss_fairy_king`）

- **资产 ID**：`boss_fairy_king`
- **定位**：花甸与树冠的凌空大 Boss（归属 `T10 花丛草甸` / `T11 巨木树冠`），与普通「林间妖精」同宗同源，但体型更修长威严、展开**六片金边叠彩巨翼**、头戴**枝杈鹿角花冠**、身旁环绕**红/绿/蓝三色悬浮花苞法核**，兼具空灵优雅与掌控全场的王者压迫感。
- **技术底座**：纯原生 JS + Canvas 2D，100% 调用本包自带 `./core/`（`PW.Math`、`PW.Voxel`、`PW.Solvers`、`PW.Behaviors`、`PW.Renderer`、`PW.Assets`），严禁修改 `./core/`。
- **坐标约定**：`+Y` 为正前方，`z = 0` 为地面，渲染器常数 `TILT = 0.6`、`HS = 0.8`、`BAKE_SCALE = 2.5`。

## 一、外观与四大华丽记忆点（0.6 俯视角一眼惊艳）

必须严格执行**「体貌特征放大 + 高对比 3 档色阶 + 独立 `partId` 切暗缝」**：

1. **六片金边叠彩巨型蝶翼（`wingTop` / `wingMid` / `wingBot` 左右复用）**：
   - 相比普通林间妖精的四片小蝶翅，妖精王背后展开**上、中、下三对巨大弧边蝶翼**，翼缘带清晰扇贝弧线与金色翅脉镶边；
   - 全部 6 片翅根用 `pivotToWorldXY` 严格锁死在后背枢轴（零脱节、零挤捏缝），扇动时**上→中→下依次保持 `0.45 rad` 相位滞后**，呈现丝滑柔美的羽浪律动！
2. **枝杈鹿角花冠 + 高辨识精雕五官 + 3 束零穿模长发链**：
   - 继承 `./references/fairy.js` 干净清秀的头身比例与大眼（`eyeGlint` **绝不进 `glowKeys`**，0.6 俯视角 0 遮挡）；
   - 头顶一对优雅分叉的**金边鹿角枝冠**，枝桠点缀盛放花苞；
   - 身后 3 束长发链必须按 `./references/骨骼化改造交接与经验.md` 铁律在**机身局部坐标系背面外法向**解算，高速转弯与穿飞绝不穿肩！
3. **8 瓣绽放王者长裙 + 环绕三色悬浮花苞（`orbitBud` ×3）**：
   - 凌空悬浮于离地 `z ≈ 8~11` 格，脚下长瓣战袍分内外两层呈花萼状舒展，严格遮盖双腿上沿（防俯冲背视角腿部穿模，参考 `fairy.js` 经验）；
   - 身周半空匀速环绕 **3 枚对应红、绿、蓝三原色的立体悬浮花苞法核**（呼应游戏三色宝石核心！），施法蓄力时加速盘旋升空。
4. **右手修长古藤花冠权杖（`scepter`）**：
   - 杖身缠绕青藤与金环，杖顶托起一朵盛开的立体自亮花冠核（`glowKeys` 严格仅限花核与三色法核极少量亮芯），挥杖施法时从杖顶正向运动学世界坐标喷出花粉与花瓣弹道。

## 四、动作清单与 4 大 Boss 技能演出 + 战斗机制设计

在 `Def.actions` 中登记全部 7 个动作，由 `eco.action` 与 `eco.actionTime` 连续驱动，`loop: false` 播完自动平滑归位：

```js
actions: [
  { id: 'patrol',              name: '凌空巡舞',   loop: true,  status: 'done' },
  { id: 'idle',                name: '花环悬停',   loop: true,  status: 'done' },
  { id: 'stagger',             name: '折翼失衡',   loop: false, duration: 1.5, status: 'done' },
  { id: 'skill_pollen_veil',   name: '迷彩花粉',   loop: false, duration: 2.4, status: 'done' },
  { id: 'skill_petal_lance',   name: '晶瓣穿刺',   loop: false, duration: 2.4, status: 'done' },
  { id: 'skill_sprite_waltz',  name: '唤灵花舞',   loop: false, duration: 3.0, status: 'done' },
  { id: 'skill_prism_tempest', name: '六翼彩岚',   loop: false, duration: 3.4, status: 'done' }
]
```

### 技能 1：`skill_pollen_veil` · 迷彩花粉（时长 `2.4s`）
- **视觉演出**：
  - `0.0s ~ 0.6s`（展翼聚粉）：六片巨翼大幅向后展开、三枚环绕花苞加速旋转聚拢；
  - `0.6s ~ 1.8s`（彩粉席卷）：六翼高频猛振朝前方扇形吹出大片彩粉像素粒子雾，同时前方地面调用 `vfx.addDecal` 铺开柔和花粉圈痕；
  - `1.8s ~ 2.4s`（轻盈回稳）：双臂舒展收势，恢复优雅悬停。
- **对应 code00 战斗机制**：遮蔽玩家手牌中 2 张牌的颜色（只标「已遮蔽」），并指定本回合 1 种「抵制色」令该色伤害减半。

### 技能 2：`skill_petal_lance` · 晶瓣穿刺（时长 `2.4s`）
- **视觉演出**：
  - `0.0s ~ 0.7s`（升空举杖）：悬空高度轻升 `+3` 格，右手古藤权杖高举斜指前方，杖顶花核高频闪烁；
  - `0.7s ~ 1.8s`（五连晶瓣齐射）：从杖顶挂点依次高速射出 **5 枚旋转立体 `petalBlade` 晶瓣刃**，沿直线飞向前方目标点，拖出细碎彩粉尾迹并在落点爆出花瓣碎屑；
  - `1.8s ~ 2.4s`（收杖降落）：权杖轻挽回身侧，平稳降回常态悬空高度。
- **对应 code00 战斗机制**：精准重击扣主角 1 颗心（若玩家上回合触发过断色，本次攻击提前 1 回合出手）。

### 技能 3：`skill_sprite_waltz` · 唤灵花舞（时长 `3.0s`）
- **视觉演出**：
  - `0.0s ~ 0.7s`（划圆唤灵）：右手权杖在头顶优雅划圈轻点，下方地面绽开翠绿涟漪环；
  - `0.7s ~ 2.5s`（三小花灵穿飞）：身旁浮现 **3 只复用 `miniSprite` 迷你伴生花灵**，以 8 字航线绕着妖精王灵巧穿飞并持续洒下治愈金绿微粒，妖精王周身浮起上升回春粒子；
  - `2.5s ~ 3.0s`（轻盈消散）：小花灵盘旋升高化作花瓣粒消散。
- **对应 code00 战斗机制**：召唤 2 只伴生花灵为 Boss 持续补充护盾与回血，逼玩家用**补色合白**或**彩虹**一波清场！

### 技能 4：`skill_prism_tempest` · 六翼彩岚（时长 `3.4s`）
- **视觉演出**：
  - `0.0s ~ 1.05s`（凌空竖翼三连蓄力）：六片巨翼完全竖展至最大张角，躯干缓缓拔升 `+5` 格，三枚环绕花苞飞至头顶上方高速旋转并爆发 3 次三色亮脉冲；
  - `1.05s ~ 2.45s`（九瓣彩岚倾泻）：权杖猛然下指，从空中不同方位连续倾泻 **9 枚三色抛物线 `petalBlade` 晶弹** 覆盖前方战场；
  - `2.45s ~ 3.0s`（花环连锁爆裂）：晶弹依次砸落地面爆出缤纷花瓣粒子喷泉与多重地面花纹痕迹；
  - `3.0s ~ 3.4s`（优雅归位）：三花苞落回身周轨道，躯干轻缓降回常态高度。
- **对应 code00 战斗机制**：蓄力 2 回合的终极大招（亮出**红+绿+蓝三色护盾各 3 格**！），击破全部三色盾即可打断大招并触发 **`stagger`（折翼失衡）**！

### 通用硬直：`stagger` · 折翼失衡（时长 `1.5s`）
- 六片巨翼瞬间无力下垂乱扑、悬空高度骤降 `5` 格险些坠地、古藤权杖斜垂、三枚环绕花苞散乱偏轨并冒出晕眩碎粒，`1.5s` 后振翼优雅重新凌空归位。
