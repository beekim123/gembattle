### 一、造型、体素特点与场景要求
注意：文案、皮肤名、技能名严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。正面统一朝向 `+Y`，`z = 0` 贴地。

1. **主体造型**（推荐体素盒约 `36 × 38 × 36`）
   - 壮实微驼背的经典两栖鱼人轮廓：宽大的青蛙/鱼类扁圆脑袋、两颗向外微凸的大圆鱼眼（0.6 俯视超高辨识度）、腮部带分层鳃裂与尖齿阔嘴、腹部浅色软皮与健壮腿部 + 一对宽大扁平的**大蹼足**；
   - 从头顶沿后背直延伸到短尾的**锯齿状彩色背鳍**（与躯干分 `partId` 用 Crease AO 切出锐利轮廓，厚度 ≥ 2 格）；
   - 右手斜握一柄粗实的**海兽骨叉/鱼叉**（长度略超身高，柄与叉齿半径 ≥ 1.05 防旋转断裂），左手臂挂一块绑着海草的**扇形贝壳小盾**；
   - **好斗待机与迈步（8 帧）**：双腿交替轻踩湿滑碎步、大背鳍与腮部起伏呼吸、骨叉前后轻晃挑衅。

2. **场景与受击靶**
   - 圆形滩涂湿地与礁石底座（浅水洼 + 潮湿沙石周期纹理 + 零散小贝壳 + 固定石边环），前方 `+Y` 方向放置像素堆叠训练靶桩（受击抖动、骨叉钉入晃动、水花与碎贝壳飞溅反馈）。

### 二、4 套色系（零重建模一键换色，快捷键 `C` 或 HUD 按钮切换）
必须基于 `Uint8Array` 索引网格实现 `recolorAsset(skin)`（`< 2ms` 按索引重刷长条图集并清空精灵缓存回收至对象池，**严禁重跑 SDF 建模**），同时联动突刺水痕、砸地水浪与连吐水弹的配色：
1. **浅海青绿（经典滩涂）**：青绿鱼皮 + 橘红锯齿背鳍 + 浅米黄肚皮 + 骨白鱼叉 + 清澈蓝白水浪水弹；
2. **橙红斑纹（礁岩斗士）**：赤橘鱼皮 + 明黄斑纹背鳍 + 暗礁红贝壳盾 + 暖橘沸腾水汽与热浪水弹；
3. **深蓝墨黑（深水猎手）**：深蓝墨黑鳞皮 + 亮青绿背鳍与亮黄鱼眼 + 寒铁灰叉 + 靛蓝激浪与青白水弹；
4. **金黄锦鲤（稀有首领）**：醒目金黄与朱红锦鲤花纹鱼皮 + 洁白红边大背鳍 + 烫金贝壳盾 + 金白水花与彩沫特效。

### 三、4 个技能演出（按钮或快捷键 `1~4` 触发）
所有技能干脆利落、带点蛮横凶萌的打击感，包含完整 **前摇 → 释放与特效 → 靶桩反馈 → 回位**：
1. **骨叉三连刺（1）**：鱼人压低重心迈开大蹼足冲到靶桩前，拖着骨叉连续极速向前直刺三下，每一刺都在叉尖前方带出锐利的像素水痕与飞溅水滴，靶桩连续三段后仰抖动，随后后跳回位。
2. **投掷骨叉（2）**：鱼人右臂大幅后仰拉满蓄力，猛地将手中骨叉高速掷出（期间鱼人切换为短暂空手姿态），骨叉笔直飞出稳稳钉在靶桩正面剧烈颤动 0.7 秒，随即化作一缕水花拉丝咻地召回鱼人手中。
3. **拍浪重砸（3）**：双手高举骨叉跃至半空重重砸向地面（触发轻震屏），向前方 90° 扇形猛拍出一大片翻涌飞溅的像素水浪、水滴与弹跳的小贝壳碎块，靶桩被浪头冲得大幅摇晃。
4. **连吐水弹（4）**：原地扎稳马步、双颊猛地鼓胀起来，哒哒哒快速连吐 5 颗饱满的高速像素水弹直线砸向靶桩，每颗命中溅开一朵小水花并在地面留短暂潮湿水渍。

### 四、工程性能与强制自检闭环（对照 `README.md` v2）
1. **第 0 步先写空间坐标预算表**，确保背鳍、大蹼足、骨叉、贝壳小盾之间互不穿模且厚度 ≥ 2 格，两颗大圆鱼眼在正面 `+Y` 与 0.6 俯视下零遮挡。
2. **极速建模与旋转满帧架构**：
   - `Uint8Array` + 部件级 `fillAABB` + `despeckle()` + 垂直 3 档色阶 / 腔体 AO / 白名单 Crease AO + 单张长条图集（保留 `grid` 供 `recolorAsset` 换色），8 帧建模耗时目标 `< 100ms`；
   - 定倍角度烘焙缓存 `BAKE_SCALE = 2.5`（精确 `step = 2`、`1px` 半步压实、`3°` 量化 + 对象池 + 滚轮缩放不清空缓存）；
   - 预渲染天空 `bgc` + `2×` 小地表缓冲集成双层投影/水浪渍 + 缓存模式精灵直绘 `dctx` + 内外发光 `destination-out` 裁切（从 `minGlowZ` 起）+ `1/4` 独立小画布 `ebctx` 真降采样模糊；
   - HUD 支持：4 套色系一键切换 (`C`)、4 个技能 (`1~4`)、自动旋转、单体描边、模式切换（游戏缓存 / 高清逐层 / 复古低分）、导出带色系名长条 PNG、最短角路径重置视角、实时性能栏（建模耗时 / FPS / 单帧 ms / 绘制次数 / 色数 / 缓存）。
3. **强制验收闭环**：
   - 跑 Node 自动化脚本校验：色数 ≤ 48、无重色、无未着色、无孤立碎点、双鱼眼正面 `+Y` 及 0.6 俯视射线遮挡 = 0、切换 4 套色系耗时 < 5ms；
   - 本地静态服务 + 浏览器实机验收：零 Console 报错；旋转 360° 检查背鳍、贝壳盾与骨叉无断裂穿模；测试 4 套色系与 4 个技能演出（含投掷骨叉脱手与召回）；连续拖拽/自动旋转稳跑 60~120fps（单帧 < 2ms）；亲自审片并至少迭代打磨 1 轮后收尾清理临时服务。
