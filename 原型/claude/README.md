## 怎么打开

原型不用 Electron，在浏览器里跑（设计稿第 10 节）。模块之间用 `import` / `export`，浏览器不让直接双击 html 打开，所以要先开一个本地小服务。三种开法，效果一样：

- **双击 `启动.command`**（Mac）：会弹出一个终端窗口，浏览器自动打开原型。关掉那个终端窗口，就停了。
- 终端里在这个目录跑：

  ```bash
  npm start
  ```

- 或者不用 npm：

  ```bash
  node tools/serve.js --open
  ```

地址是 `http://localhost:8000/app/`。8000 被占了，就自动往后找一个空的端口，终端里会打出实际的地址。要指定端口：`node tools/serve.js --port 9000`。

只需要装 Node.js，不用装别的依赖。小服务只让本机连，别的电脑连不上。

## 目录

| 位置 | 是什么 |
|---|---|
| `启动.command` | Mac 上双击启动 |
| `package.json` | 只为两件事：`npm start`；让 node 把 `.js` 当 ES 模块，以后规则模块的单测能直接跑。没有依赖 |
| `tools/serve.js` | 本地小服务 |
| `app/index.html` | 游戏的入口。现在是一个确认页，显示「模块加载好了」就说明启动脚本好使 |
| `app/check.js` | 确认页用的，阶段 0 开工时删掉 |

以后的 `modules/`、`tools/` 里的其他工具，照设计稿第 10 节建。
