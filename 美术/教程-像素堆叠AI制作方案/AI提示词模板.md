# 给其他 AI 的像素堆叠（Sprite Stacking）制作提示词模板（v2）

将下方模板复制给具备代码执行与图片查看能力的 AI，替换方括号 `[...]` 中的具体主题即可稳定产出工业级、高性能、经实机验收的像素堆叠美术资产。

> 如用于 **code00** 项目的正式美术，请另附上当前设计稿中已拍板的世界观、造型方向与命名禁用词规范，不要直接套用案例配色。

## 一、任务指令模板（可直接复用）

```markdown
你要用“像素堆叠（Sprite Stacking）”方式为我制作：[填写主题，如：海滨鹈鹕骑自行车 / 俯视角遗迹机关与角色]。

请严格按以下工程与美术规范执行，不要跳步：

### 第 0 步：先写「部件空间坐标预算表」
在写任何体素代码前，先确定画布单层尺寸 W × D 与高度 H（原点在水平中心，正面朝向 +Y，z = 0 贴地），列一张所有部件的 X / Y / Z 坐标范围表，明确每个附件（灯、眼睛、武器、配饰）位于主体或容器的外侧还是上方，确认不会互相埋死或触碰非法边界后再动工。

### 1. 投影、格式与渲染管线规范
- 俯视角像素堆叠参数：地面沿 Y 轴压扁 TILT = 0.6，每层抬高 HS = 0.8，严禁平滑（imageSmoothingEnabled = false）。
- 资产存储格式：统一打包为**单张长条图集**（宽 = W × H，高 = D，从左到右为 z = 0..H-1；alpha 严格仅允许 0 或 255；统一色表 ≤ 48 色；发光色键与普通色键禁止共用同一十六进制色值），严禁为每层单独创建 <canvas>。记录 activeLayers / glowLayers 跳过空层。
- 若输出交互网页或游戏渲染器，优先采用**定倍角度烘焙缓存模式（Sprite Cache，保证旋转也满帧）**：
  1. 烘焙倍率与窗口物理缩放解耦：固定采用黄金倍率 BAKE_SCALE = 2.5（0.8 × 2.5 = 2.0 精确整数步进、1px 半步压实防漏缝），按 3° 量化 + LRU 缓存，滚轮缩放不清空缓存；对称物体声明 symDeg（如 90°）共享缓存；
  2. 零 GC 分配：全局复用 2 张 scratch 临时画布合成切片与单体独立 1px 描边，淘汰精灵回收至 canvasPool 对象池；
  3. 消除全屏 Overdraw：静态天空预渲染；地面/阴影/光锥全合成进 2× 小地表缓冲后再 1 次贴图；烘焙精灵直接画到主画布 dctx，不经过全屏中间层；
  4. 发光 Z 遮挡 + 真 1/4 降采样模糊：物体内仅从 minGlowZ 起对发光层做 destination-out，物体间远→近抠除；模糊必须在 1/4 尺寸独立小画布 ebctx 上执行 filter=blur，严禁在全屏主画布 dctx 上设 filter；
  5. 若支持多昼夜/开关氛围，白天自动使用熄灯替代表长条并关闭光晕，地面光斑/光锥使用 clip() 严格限制在地面边界内。

### 2. 高性能体素建模与美术规范
- 性能铁律：网格必须使用 Uint8Array 存色表索引与 partId；每个部件通过局部 AABB 包围盒写入，严禁对 95% 空气体素全盒暴力跑 SDF（目标：8 帧中等模型构建耗时 < 100ms）。
- 光影只分上下，严禁左右方向光：单材质采用 3 档高对比色阶（暗面 / 主色 / 露边亮色），组合「露边提亮 + 上方 3×3 腔体 AO + 白名单过滤的部件接缝暗缝（Crease AO，对眼睛/灯芯/细金属配对免压暗）+ 部件局部归一化高度」。
- 形状圆润厚实：细结构（枝干、车架、辐条、四肢、触须）半径 ≥ 1.05~1.25（截面 ≥ 2×2）；部件有机衔接用平滑并集 smin(a, b, k)；完成后执行 despeckle() 清理孤立单像素。
- 落地阴影：必须给物体加双层接地阴影（贴地深色接触影 + 基于底面轮廓足迹的浅色投射影），杜绝漂浮感。
- 动画与物理同步：肢体/踩踏优先用精确 2-Bone 平面解析 IK（余弦定理保持骨长恒定）；车轮/移动场景须保证地速与轮速严格同步（v = 2πR · freq），地面与景物无缝同速滚动。
- 若作为游戏资产，同步输出元数据：footRadius、headZ、centerZ、lift、glowKeys 与 tintSlots。

### 3. 强制「量化校验 → 渲染看图 → 迭代打磨」零依赖闭环
1. 先跑 Node 自动化校验脚本，确保全部通过：
   - 色表 ≤ 48 色、无重色、无未着色残留、零半透明、零 3D 孤立碎点、不越界；
   - **关键锚点可见性射线断言**：对眼睛、车灯、武器等关键部位沿 +Y 和斜前俯视射线扫描，断言遮挡数为 0；
   - 记录构建耗时与 IK 骨长误差（< 0.01）。
2. 零依赖看图自检（双轨任选其一，不硬依赖外部原生编译包）：
   - 优先：本地起静态服务用浏览器 / Electron 实机截正（0°）、斜 45°、侧（90°）、背（180°）及各光照模式截图，并核查 Console 零报错、帧率与 DrawCalls；
   - 无浏览器环境兜底：用 ~60 行纯 JS 软件光栅器 + 内置 zlib 输出 PNG 预览图后直接查看。
3. 至少完成 1 轮视觉审片打磨，逐项打勾：
   - [ ] 1:1 尺寸下能否一眼认出主体、朝向与核心道具，细节互不粘连？
   - [ ] 旋转 360° 与斜 45° 是否扎实无层间黑缝、无左右穿帮光、无重置视角乱转？
   - [ ] 眼睛/正面关键配件在 0.6 俯视倾角下是否 100% 未被遮挡？
   - [ ] 发光部分是否只出现在预期外露面、无穿墙透视，白天模式是否正常熄灯？
   - [ ] 地面投影是否扎实接地、移动动画是否与地面/轮速零打滑同步？
```

## 二、高发踩坑速查表（供 AI 审核与自检）

| 现象 | 根因 | 修复方式 |
|---|---|---|
| 前车灯/配饰看不见或埋进容器里 | 没列部件空间坐标表，世界坐标落进邻近容器内部 | 动工前写部件 `X/Y/Z` 坐标预算表，并用 `+Y` 与俯视射线脚本自动断言遮挡数 = 0 |
| 被墙/篮子/前景挡住的发光透出来（X 光穿墙） | 发光层独立画在 `ec` 并直接 `screen` 叠在最顶，没做深度裁切 | 物体内逐层烘焙与物体间按远→近合成时，先用不透明实体剪影对发光层执行 `destination-out` |
| 角色打开/加载卡顿 1 秒以上 | 用字符串数组且对 95% 空气体素全盒暴力跑 SDF，每层建独立 `<canvas>` | 改 `Uint8Array` + 部件级 `fillAABB` 局部遍历 + 单张长条图集（可提速 10~20 倍） |
| 高分屏帧率暴跌 / 静止 120fps 一转视角就掉到 30~40fps | ① 按 Retina 物理 `SCALE` 烘焙巨图并每帧新建 `<canvas>`；② 在全屏主画布 `dctx` 上设 `filter=blur` 触发全屏模糊；③ 每帧拷贝全屏 `gc`/`mc`；④ 底层无发光层白跑 `destination-out` | ① 固定 `BAKE_SCALE=2.5` + 全局复用 2 张 scratch 与对象池 + `3°` 量化 + 对称共享 + `minGlowZ` 剪枝；② 在 `1/4` 独立小画布 `ebctx` 上执行 `blur`；③ 地面/投影/光锥全进 2× 小地表缓冲、精灵直绘 `dctx` |
| 斜角下车架斜管/辐条/草尖现层间黑缝 | `HS (0.8) > TILT (0.6)`，错位层之间露出 `0.2 × SCALE` 空隙 | 烘焙时启用双子步压实绘制（在 `yy + Math.round(step / 2)` 补画一次） |
| 前后物体重叠时轮廓黏成一团 | 全场景画到一张 `mc` 后做全局描边 | 改为单物体烘焙时自带独立轮廓描边，前景天然压住背景边界 |
| 旋转到背面时明暗反转 | 切片里画了左亮右暗的方向光 | 改为纯垂直光影（`z` 高度 + `topEmpty` 露边 + 腔体 AO + `botEmpty` 底沿） |
| 细小部件或眼眶周围一圈发黑 | Crease AO 6 邻域一刀切，细部件每像素都挨着别的部件 | 给 Crease AO 加 `NO_CREASE_PAIRS` 白名单，并与上方 3×3 腔体 AO 分离 |
| 球顶出现同心圆白条纹 / 长柱体死平 | 球顶每层 `topEmpty` 全涂最亮白；长柱无局部高度变化与结构分段 | 球顶仅最高 1~2 层外圈点亮；长柱加局部高度过渡与底座/箍环等几何细节 |
| 物体像贴纸漂浮在地面上 | 只有底层 `z <= 1` 压暗，地面阴影太淡或仅用粗糙椭圆 | 加「贴地深色接触影 + 离线足迹剪影投射影」双层接地阴影 |
| 骑行/奔跑时路灯滑冰、轮子空转 | 地面纹理静止，或路旁景物移动速度与车轮周长不匹配 | 用周期无缝纹理同步滚动地面，速度严格锁定 `v = 2πR · freq` |
| 踩踏/行走腿部忽长忽短变形 | 用简单 `lerp` 近似膝盖坐标 | 换 6 行余弦定理精确 2-Bone 平面解析 IK |
| 白天场景路灯依然发光 / 光锥溢出地图外 | 白天未切换熄灯切片；地面光锥未裁切 | 预生成 `stripDay` 熄灯替代表；地面光斑/光锥绘制前按有效边界 `clip()` |
| 多张无缝地面混拼出现接缝 | 每张图各自周期无缝，但彼此边界色不一致 | 让所有底图四边外圈收敛到同一份共享周期边界场，仅内部各异 |
| 转了好几圈后点重置视角疯狂倒转 | 直接把累积角 `th` 往 `thTarget` 线性插值 | 重置前把 `th` 规整到 `[thTarget - π, thTarget + π]` 最短角区间 |
