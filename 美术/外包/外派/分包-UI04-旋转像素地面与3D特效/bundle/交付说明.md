# UI-04 交付说明：六生态可旋转像素地面与 3D 战斗特效（`groundVfx`）

## 一、交付清单

- `bundle/pack_ground_vfx.js`：完整注册 `window.Code00ArtPacks.groundVfx`（`id: 'groundVfx'`, `version: 1`），实现全部 6 个必需导出方法与 `BIOME_IDS` 常量。
- `bundle/manifest.json`：记录 8 套 `384×384` 像素地面配置、色板、3D 微粒与全套战斗特效清单及离屏显存占用。
- `bundle/交付说明.md`：本说明文档。

## 二、核心美术与架构设计

1. **8 套无缝可旋转像素地面（`buildGroundTile`）**
   - 统一采用 `384×384` 离屏像素图，按 `${biomeId}_${size}` 做引用级缓存复用，8 套离屏画布总计占用 **4,718,592 bytes（4.50 MB）**，低于 6.00 MB 上限。
   - 预计算周期值噪声查找表（`192×192` 宏观噪声与 3 组 `128×128` 细部噪声，`lcm(128, 192) = 384`），结合 Bayer 4×4 有序像素抖动与直接 `ImageData` 像素盖章，避免逐像素重复哈希与额外画布开销。
   - 色板直接对齐 `./core/habitats.js`；严格消除圆形台面边框与任何 2D 假摆件（无 2D 树、帐篷、石门、石碑、火堆），四缘地貌过渡自然，适配 `preview.html` 360° 仿射旋转全屏铺陈。
2. **全 3D 世界坐标硬像素微粒与战斗特效**
   - 所有粒子、弹道、爆发波与 8 只怪出手动作均经调用方传入的 `proj(wx, wy, wz) -> [sx, sy, depth]` 映射到屏幕，并按 `depth` 远→近排序绘制，视角任意旋转时透视、遮挡与体量保持物理同步。
   - 根据 `proj(0,0,0)` 与 `proj(0,0,10)` 动态估算像素基元尺寸，全部使用整数像素矩形、阶梯像素线段与多面体像素菱晶构成，彻底告别 2D 矢量圆球与柔边模糊。
   - 覆盖 8 生态 3D 微粒、5 种主角弹道（`red` / `green` / `blue` / `white` / `rainbow`）、4 种爆发与格挡波（`white_wave` / `rainbow_burst` / `shield_shatter` / `ward_block`）及 8 只怪专属出手特效（`spit` / `puff` / `club` / `petals` / `fruit` / `claw` / `bite` / `roots`）。
