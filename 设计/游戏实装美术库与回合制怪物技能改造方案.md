## 二、回合制怪物战斗动作统一规范（与 RPG 走位技能彻底区分）

### 1. 五条设计铁律
1. **100% 保留原有 `idle` 与 `patrol` 不动**：工坊和未来游戏内的「图鉴 / 卡册」继续原样播放待机与巡游，绝不破坏原有生态动作。
2. **站桩定点 + 短促干脆（总时长严格 `0.70 ~ 1.15 秒`）**：
   - 不做即时 RPG 式的满场走位、大范围地面陷阱圈或召唤巡游小怪；
   - 统一按三拍节奏：**蓄力预告（0.25~0.30s）→ 干脆出手命中（0.20~0.25s）→ 弹回原位（0.25~0.40s）**。
3. **统一 4 个标准战斗动作 id**（全部追加进 `Def.actions`，由 `eco.action` 与 `eco.actionTime` 驱动）：
   - `battle_attack`（`loop: false`，时长 `0.85~1.05s`）：**必有**。常规/重击出手，向目标发射或短距前扑。
   - `battle_special`（`loop: false`，时长 `0.85~1.15s`）：**有特殊机制的怪必有**（抵制换色、塞废牌、集色威压、遮蔽手牌等原地施法演出）。
   - `battle_stagger`（`loop: false`，时长 `0.85s`）：**必有**。破盾硬直——明显踉跄、低伏瘫软、部件微散抖动并迸出青白破盾像素碎屑。
   - `battle_hurt`（`loop: false`，时长 `0.35s`）：**必有**。受击短促后仰与微震。
4. **3D 目标坐标指向（`eco.targetPos`）**：
   - 脚本 `update(dt, time, params, habitat, vfx, eco)` 优先读取 `eco.targetPos`（形如 `[tx, ty, tz]`，默认沿自身正前方 46 格处）；
   - 所有出手弹道、扑击方向、飞向主角的 3D 像素粒子均自动朝向 `targetPos`，确保**无论镜头 360° 怎么旋转，出手和技能都精准打向主角**！
5. **性能与规范铁律（与工坊完全一致）**：
   - 不改 `core/` 内核；单盒体素 `≤ 40×40×40`；色数 `≤ 48`、0 重色、`eyeGlint` 不进 `glowKeys`；
   - **严禁常态使用 `scaleX/scaleY` 小数拉伸**（蓄力压低与扑击一律用部件 `lift` / 相对位移 / 关节转角 / `vfx.spawnParticle` 实现）；
   - 全周期 0 `NaN`、零禁用字（`灯、烬、影、夜、魂、噬、幽、渊、星、光` 及 `守×者`、`×之×`）。

## 四、`美术/游戏实装美术库/` 目录结构与展示验收台规范

```text
美术/游戏实装美术库/
├── README.md                    # 游戏实装专库说明：与总工坊的区别、同步方法、如何预览
├── manifest.json                # 唯一实装资产清单（列出当前游戏已启用的全部脚本路径、分组、版本）
├── index.html                   # 独立展示验收页（支持「图鉴待机」+「回合制对阵演练」双模式，360° 可转）
├── 启动预览.command              # Mac 双击起本地静态服务并自动开浏览器预览 index.html
├── tools/
│   └── sync-from-workshop.js    # 零依赖 Node 脚本：按 manifest.json 从 ../像素堆叠生物工坊/ 单向同步资产
├── core/                        # 由 sync 脚本从总工坊只读同步（6 内核）
├── scenes/                      # 由 sync 脚本同步（habitats.js + 11 个已实装生态摆件）
├── buildings/                   # 由 sync 脚本同步（3 个已实装建筑）
├── npc/                         # 由 sync 脚本同步（npc_mage.js + npc_gear_smith.js）
├── creatures/                   # 由 sync 脚本同步（升级后的 8 只落果密林怪物）
└── art-packs/                   # 预留收口目录（将来 UI-01~04 外派包验收后放这里，README 写明用途）
```

### `index.html` 展示验收页必须具备的功能
1. **左侧「游戏实装资产目录」**：从 `manifest.json`（或已登记资产）分组列出 **主角与 NPC（2） / 怪物（8） / 生态摆件与建筑（14）**，一目了然看出目前游戏里到底用了哪些美术。
2. **顶部双模式一键切换**：
   - **模式一「图鉴待机」**：展示选中资产原本的 `idle` / `patrol`（与未来游戏图鉴一致），可 360° 拖动旋转、Q/E 旋转、滚轮缩放、切换 6 套生态地台、切换换色皮肤；
   - **模式二「回合制对阵演练」**：选中任意怪物时，上方站该怪、下方站主角 `npc_mage`（真实上下对阵距离），右侧列出该怪全部回合制动作按钮（`受击` / `破盾硬直` / `常规出手` / `机制技`）以及主角 `挥杖施法`，点击即刻把 `eco.targetPos` 传给模型播放真实 3D 指向演出，**同时支持 360° 拖动旋转查看各个角度下的动作和特效**！
3. **左上角轻量性能 HUD**：实时显示 FPS、单帧耗时、当前动作与计时、图集占用 MB（验证 120fps 满帧与 ≤ 28MB 红线）。
