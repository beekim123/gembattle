# 异世界生态生物 · 逐只制作清单（先立底座规范与新骨骼，后批量补齐）

> **核心原则（用户拍板纠正）**：**先啃硬骨头、先改底层立规范、先调需要大量微调的新骨骼模板，最轻巧的和纯照抄的放后面批量做！**
> 就像第一次做脊椎蛇类要先花精力调通所有细节，一旦把底层能力和模板规范立稳，后面所有同类就可以直接照模板一批一批快速补进来。
> **当前进度**：已做 **48 / 73**（基础模板 `M01 ~ M17` 17 类 + **第一梯队 8 只底座标杆 + 第二梯队 8 只复杂骨骼标杆 + 第四梯队批 C 3 只已完成**）；**待做 25 只** = **5 只第三梯队轻机制标杆** + **20 只第四梯队按模板批量照着补的同类**。
> **自动换装**：每做完 1 只，脚本放进 `creatures/`，在 `index.html` 与 `ecology.html` 各加一行 `<script>`，在 `文档/生态设计数据.js` 改 `status: 'made'` 并填 `impl`，生态总览页会自动把占位体素换成真模型。
