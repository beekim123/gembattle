## 二、核心视觉与结构设计

1. **探索路线图手绘羊皮卷（`drawMapScrollBg`）**
   - 预烘焙 `128×128` 周期无缝暗林暖棕羊皮底纹（低对比度、温润克制，突出浅金路线与各色节点），搭配左右 `28×128` 竖向无缝木轴包边、铜钉、毛边与标尺刻度，支持任意 `worldH` 深度平滑滚动。
   - 按 `segments` 自动自下而上映射各林段范围，在左右外侧留白区绘出淡雅复古墨色手绘地标暗纹（林缘嫩叶小树与蕨草、青苔界门残柱、密林腹地荆棘与石碑、巨木树冠古木垂藤、右下角手绘罗盘），完全不侵入中央路径与节点视野。
   - 视口上下带阶梯卷边压暗与世界首尾车床木轴铜饰端头，滚轮上下卷动时呈真实卷轴展开感。

2. **青苔界门横向装饰分界带（`drawMapGateDivider`）**
   - `32×16` 无缝青苔石砖横梁 + 左右石雕端头 + 垂挂青苔藤蔓 + 居中微型像素青苔石门徽章（闭合/敞开双版本）。
   - `passed === false` 时沿石缝与门心晶脉以纯整数像素做青碧微脉动提示；`passed === true` 时门扉敞开并柔和降对比退后。

3. **6 种地图节点 × 4 种状态像素徽章（`drawMapNode`）**
   - `battle`（暗铁交叉双刃）、`elite`（赤金双角兽首重盾）、`event`（靛紫古石符文问号印）、`shop`（暖黄红条纹商帐钱袋）、`camp`（双帧跃动像素篝火）、`boss`（`40×40` 古木三宝石金冠王徽）。
   - 四态分明：`visited` 灰石沉底 + 醒目暖金像素对勾印章；`avail` 纯像素双层呼吸金环、旋转四角亮芒与上方跳动金箭标（零 `shadowBlur`）；`future` 清晰常规态且 `hover` 亮起白金像素双框与四角括弧；`dim` 压低透明与饱和度退居背景。

4. **标题招牌与非战斗卷轴标题条（`drawTitleEmblem`、`drawSceneRibbon`）**
   - `drawTitleEmblem`：暗橡木拼接牌匾 + 锻铜斜角边框 + 两侧嫩叶藤蔓与赤红落果 + 顶部三原色宝石嵌饰 + 暖金渐层描边主标题 + 下沿精致副标题条。
   - `drawSceneRibbon`：通透修长的复古木牌与内折燕尾丝带标题条，两侧铜钉端头收束，彻底取代笨重黑盒，不遮挡下方舞台。

5. **11 种非战斗选项像素图标与 3 枚结算大纹章（`drawChoiceIcon`、`drawSummaryCrest`）**
   - 全部 11 种图标（`camp_heal` / `camp_carve` / `camp_purge` / `shop_potion` / `shop_carve` / `gate_retreat` / `gate_advance` / `event_wood` / `event_stele` / `event_pool` / `event_bag`）均按 `28×28` 手工像素精绘并配分系铜框。
   - 3 枚结算大纹章（`victory` / `retreat` / `defeat`）按 `90×36` 原生像素预烘焙，以整数 `2×`（`180×72`）锐利显示并带克制的整数像素微动效。

## 三、自动化校验与资源预算核验

> 注：本打包构建环境未内置 `node` 可执行文件，已按 `verify.mjs` 全部硬红线规则完成 1:1 等价静态与结构全量校验；交付到含 Node 的本地验收目录后，可直接双击 `预览验收.command` 或运行 `node verify.mjs` 复验。

- **导出登记与签名**：`window.Code00ArtPacks.mapPanels`（`id: 'mapPanels'`, `version: 1`），8/8 方法齐备。
- **性能与内存预算**：
  - 离屏画布总计：**41 张**，合计 **263,040 字节（0.25 MB）**，仅占 4.00 MB 红线的 **6.3%**。
  - 全部贴图采用直接 `ImageData` 像素填充预烘焙（共 65,760 像素），无矢量慢路径，初始化耗时远低于 60 ms 上限。
- **合规硬红线**：
  - 零 `.filter =` / `ctx.filter`：通过
  - 零 `shadowBlur`：通过
  - 零外部图片 / 字体 / 网络 URL（`new Image` / `http` / `fetch`）：通过
  - 全文件（含字符串字面量与注释）零禁用字：通过
  - JS 语法括号与引号平衡校验：通过
  - `ctx.save()` / `ctx.restore()` 严格成对平衡（11 对），像素绘制均关闭 `imageSmoothingEnabled`：通过

## 四、`preview.html` 目检要点确认

1. **标签页 1（卷轴路线图）**：滚轮在 `camY = 0..520` 间连续上下滚动时，羊皮底纹与两侧木轴包边无缝衔接、无接缝闪烁；林缘/腹地/巨木树冠暗纹仅居两侧留白，不遮挡中央节点；青苔界门在 `y = 525` 水平贯通且晶脉微亮；6 种节点 4 态（含 `boss` 悬停白金框与 `avail` 动态金环）清晰可辨。
2. **标签页 2（标题/图标/纹章）**：左上 `drawTitleEmblem` 与右上两条 `drawSceneRibbon` 间距充裕、互不重叠；11 枚非战斗选项图标按 6+5 两行锐利呈现、题材一眼可辨；底部 3 枚 `180×72` 结算大纹章（通关/折返/倒下）构图饱满、无裁剪。
