# 设计文档：蜘蛛大 Boss · 织茧棘蛛母（`boss_weaver_spider`）

- **资产 ID**：`boss_weaver_spider`
- **定位**：高阶章节大 Boss（可归属 `T16 苔藓古石遗迹` / `T15 地下暗河溶洞` / `T09 落果深林` 裂隙），在俯视 0.6 倾角下具备极强压迫感与清晰可辨的「八足高拱 + 巨型棘纹腹囊 + 六赤眼双毒螯」轮廓。
- **技术底座**：纯原生 JS + Canvas 2D，100% 使用本外包目录自带的 `./core/`（`PW.Math`、`PW.Voxel`、`PW.Solvers`、`PW.Behaviors`、`PW.Renderer`、`PW.Assets`），严禁修改 `./core/`。
- **坐标约定**：`+Y` 为正前方，`z = 0` 为地面，渲染器投影常数 `TILT = 0.6`、`HS = 0.8`、`BAKE_SCALE = 2.5`。

## 一、外观与体貌放大设计（俯视 0.6 视角一眼认出是大 Boss）

为避免俯视角下蜘蛛糊成一团黑球，必须严格执行**「体貌特征放大 + 高对比 3 档色阶 + 独立 `partId` 切结构暗缝」**：

1. **三段式威慑轮廓**：
   - **前段（头胸甲 + 6 颗赤红复眼 + 双镰毒螯 + 双须肢）**：扁阔玄青重甲，额缘前倾、上方无粗眉遮挡，6 颗赤红复眼呈「2 大居中 + 4 小弧排」表面精雕，确保 0.6 俯视角 0 遮挡；一对弯钩状大毒螯向前张开，平时微张蓄势，攻击时猛然合拢交叉劈砍。
   - **中后段（高耸巨型棘纹腹囊 + 尾端三瓣纺丝器）**：整只 Boss 的视觉重心！体积明显大于头胸部并向后上方抬起，背甲覆有 3 对对称的**猩红/亮色棘刺甲片**与深沟分缝；腹囊下侧嵌有少量半透明发光丝腺纹路（唯一进 `glowKeys` 的区域），蓄力技能时高频脉冲亮起；尾端三瓣纺丝器随吐丝张合。
   - **外围（8 条高拱棘刺长腿）**：沿头胸两侧扇形展开（前/中前/中后/后共 4 对，每对对称），**膝关节高高拱起超过头胸背甲高度**，脚尖呈锐利弯爪，俯视看像一座移动的钢铁荆棘笼。

## 四、8 足骨骼运动学（巡游与待机）

- **不修改主工坊 `core/solvers.js`**：直接在 `boss_weaver_spider.js` 内部实现轻量的 **8 足四相交替步态器（Octopod Gait）**，并直接调用 `PW.Solvers.solveIK2D` 逐腿解算高拱折角（`bendDir = +1` 保证膝节始终向上高拱）：
  - **分组**：A 组 `L1 / R2 / L3 / R4`（相位 `0`）、B 组 `R1 / L2 / R3 / L4`（相位 `π`）；
  - **占空比**：`β = 0.56`（交接期短暂 8 足全着地，绝不悬空飘移）；
  - **扇形落脚预算**：4 对脚沿体侧前后扇形大幅错开（前对前探 `+18`、中前 `+6`、中后 `-7`、后对 `-20`，横向外展 `±20~26` 格），确保相邻落脚间距 `≥ 11` 格 > 单步幅，彻底杜绝腿间穿插打架；
  - **抬脚高度**：`stepHeight = 3.5~4.5` 格，落地瞬间触发极轻接地扬尘粒子；
  - **躯干呼吸与跟随**：待机（`idle`）时 8 足钉地不动，头胸与腹囊做极轻的上下呼吸位移（`±0.5` 格，**禁用小数缩放**），双须肢交替轻点、腹囊缓慢起伏、双毒螯偶尔张合咔嗒。

## 五、动作清单与 4 大 Boss 技能演出 + 战斗机制设计

在 `Def.actions` 中登记全部 7 个动作，工坊右栏与 `preview.html` 均可一键触发；脚本从 `eco.action` 与 `eco.actionTime` 驱动完整连续状态机，`loop: false` 的技能播完自动平滑归位：

```js
actions: [
  { id: 'patrol',              name: '八足巡游',   loop: true,  status: 'done' },
  { id: 'idle',                name: '原地警戒',   loop: true,  status: 'done' },
  { id: 'stagger',             name: '破盾硬直',   loop: false, duration: 1.5, status: 'done' },
  { id: 'skill_web_snare',     name: '织网缚阵',   loop: false, duration: 2.6, status: 'done' },
  { id: 'skill_fang_lunge',    name: '毒螯扑杀',   loop: false, duration: 2.2, status: 'done' },
  { id: 'skill_brood_burst',   name: '裂茧群涌',   loop: false, duration: 3.0, status: 'done' },
  { id: 'skill_venom_barrage', name: '棘背毒雨',   loop: false, duration: 3.4, status: 'done' }
]
```

### 技能 1：`skill_web_snare` · 织网缚阵（时长 `2.6s`）
- **视觉演出分段**：
  - `0.0s ~ 0.6s`（压低蓄丝）：8 足外撑压低重心，腹囊微微后倾抬高尾端纺丝器，丝腺发出亮白脉冲；
  - `0.6s ~ 1.7s`（扇形喷网）：纺丝器朝前方 `-35° ~ +35°` 连续射出 **5 道白丝像素粒子束**，并在前方地面调用 `vfx.addDecal` 铺开白色放射状蛛网痕迹；
  - `1.7s ~ 2.6s`（前足拍地定网 & 复位）：前一对长腿高高抬起狠狠拍地震起白屑尘环，随后平滑回正。
- **对应 code00 战斗机制（写入 `manifest.json` 供游戏接入）**：往玩家弃牌堆塞入 2 张「缠丝废牌」，或锁定手牌中 1 张宝石牌 1 回合。

### 技能 2：`skill_fang_lunge` · 毒螯扑杀（时长 `2.2s`）
- **视觉演出分段**：
  - `0.0s ~ 0.65s`（立身蓄势）：后 4 腿压弯、前躯干大幅仰起，前 2 对长腿高高扬起张开，双毒螯外扩到最大角度、螯尖渗出毒色亮粒；
  - `0.65s ~ 1.25s`（爆发前扑 + 双螯交剪）：整只向前急冲 `+14` 格，落地瞬间双螯猛然向内交叉劈斩，沿螯尖世界坐标（正向运动学真源！）喷出扇形猩红/毒色斩击粒子 + 接地重震尘环；
  - `1.25s ~ 2.2s`（滑刹退回）：8 足碎步快速后撤回原位，双螯归位。
- **对应 code00 战斗机制**：重击扣主角 1 颗心（若处于未破盾态，下轮倒计时额外 -1）。

### 技能 3：`skill_brood_burst` · 裂茧群涌（时长 `3.0s`）
- **视觉演出分段**：
  - `0.0s ~ 0.8s`（腹囊剧颤）：巨型腹囊高频起伏、纺丝器大幅张开，发出亮脉动；
  - `0.8s ~ 1.45s`（甩出双茧）：腹尾左右先后甩出 **2 枚立体 `eggSac` 丝茧球**，沿清晰抛物线飞向前方左右两侧（距离约 18~24 格）砸地弹一下；
  - `1.45s ~ 2.6s`（破茧群涌）：丝茧在地面炸开白丝碎粒，立刻钻出 **3 只立体 `spiderling` 小蛛**（复用同一资产），快速扇形前冲并绕弧巡游；
  - `2.6s ~ 3.0s`（收束）：小蛛迅速缩退/散成尘粒离场，母蛛回正。
- **对应 code00 战斗机制**：场上召唤 2 只低血小蛛协助攻击，迫使玩家在「单点 Boss 破盾」与「补色合白 / 彩虹全体清场」之间做抉择！

### 技能 4：`skill_venom_barrage` · 棘背毒雨（时长 `3.4s`）
- **视觉演出分段**：
  - `0.0s ~ 1.0s`（扎地三连蓄力）：8 条长腿狠狠扎地撑起高耸躯干（`lift` 抬高 `+3` 格），棘背与丝腺连续 3 次亮脉冲蓄力，周围吸入向上飘浮的毒色粒子；
  - `1.0s ~ 2.3s`（连射抛物线毒囊）：从腹背棘缝每隔 `0.14s` 依次向上高抛射出 **8 枚立体 `venomOrb` 毒囊弹**，每枚画高抛物线飞向前方不同落点；
  - `2.3s ~ 3.0s`（连锁爆裂）：毒囊依次砸地炸出毒色像素粒子喷泉 + `vfx.addDecal` 腐蚀洼痕与涟漪；
  - `3.0s ~ 3.4s`（泄力回稳）：躯干沉落回常态高度。
- **对应 code00 战斗机制**：蓄力 2 回合的终极大招（亮出红+绿双色护盾 5+5 格）；玩家若在倒计时归 0 前击破双色盾，立即打断大招并触发 **`stagger`（破盾硬直）**！

### 通用硬直：`stagger` · 破盾硬直（时长 `1.5s`）
- 整只向后仰挫、8 足发软外撇下沉 `2.5` 格、头胸左右轻晃、双螯无力下垂并冒出晕眩碎粒，`1.5s` 后撑地起身恢复警戒。

## 六、量化校验标准（本包已自带 `./verify.mjs`）

外包方写完 `./bundle/boss_weaver_spider.js` 后，直接在本目录运行 `node verify.mjs` 即可自动校验以下全部硬性指标：
1. **资产与色表**：所有部件 `w, d, h <= 40`；总色数 `<= 48`、0 重色；`eyeGlint` 不在 `glowKeys` 中；4 套 `SKINS` 换色零报错；
2. **建模耗时**：`createInstance` 单次初始化耗时 `<= 60ms`；
3. **全动作闭环与零 NaN**：对 `patrol`、`idle`、`stagger` 及全部 4 个 `skill_*` 以 `dt = 1/60` 模拟完整周期，断言所有返回部件坐标 `x, y, lift, ro` 零 `NaN`、无脱离合理半径（如 `|x|,|y| < 90`）、非循环动作结束后干净复位；
4. **8 足关节与步态检查**：遍历巡游 3 秒，断言 8 条腿关节枢轴无脱节、膝节高度全程高于足端、每条腿均有正常抬脚摆动期（非瘫痪拖地）。
