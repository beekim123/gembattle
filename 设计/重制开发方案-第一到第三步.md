# code00 开发方案（第 1 步 → 第 3 步 · 完整重制版）

> **给谁看的**：这是可以直接交给其他 AI 分步写代码的独立开发文档，同时用清晰自然的中文写明全部玩法、命名、地图指引和场景生态美术方案，方便制作人（用户）直接核对与试玩。
>
> **这次方案的四个核心锚点**：
> 1. **100% 保留你自己的独创核心（不 1:1 抄《杀戮尖塔》）**：主角 **3 颗心**、怪用 **多重血条 + 颜色韧性盾 + 倒计时**、**29 张固定七色宝石牌循环**、**色环接链（×2 / 补色合白全体 / 集齐六色彩虹重放两遍 / 跨回合接色 / 宝石等级）**、**出牌不限张数、拖进链尾不能改序、发数不封顶纯数字**、**出口挂奖励 + 界门撤离抉择**。
> 2. **把开局做轻、把路线做清**：**起始手牌减少到 N = 3 张**，第一战简单直白；一趟探索采用 **「落果密林 · 第 1~8 步纵深」**，提供跟《杀戮尖塔》一样**从下往上、连线明确、一眼看穿整趟走向**的探索路线图。
> 3. **文案全面去 AI 味**：彻底弃用「外头区 2 层 × 每层 4 片」「看门的」「歇脚石碑」「疼/多」等生硬代号，全部换成简短自然的游戏名称，同时**严格零禁用字**（不含「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」）。
> 4. **每个场景配套生态环境美术，第 3 步直接接入工坊现成资产**：不仅接入主角和怪物模型，同时直接复用 `美术/像素堆叠生物工坊/` 里现成的古树、倒木赤果、花海、沼泽枯桩、古石碑、营火、商贩帐篷与青苔石门，让每场战斗都长在真实生境里。
>
> **第 1~3 步明确不做什么**：暂不做大厅、工会任务板、磨损装备、雇佣队友、冒险家等级、卡册、长篇剧情与 Electron 桌面壳。等带美术的完整第一趟玩上头了，第 4 步再决定把哪些局外系统接回来。

## 一、目录与工程硬规矩

### 1.1 独立目录与只读美术规则

- 新建全新独立目录：**`原型/v2/`**。
- **不改不动**现有的 `原型/neon/`、`原型/claude/`、`设计/设计.md` 与 `美术/`。
- `美术/像素堆叠生物工坊/` **严格只读不改**：开发时由 `tools/serve.js` 把 `/art/` 只读映射到 `../../美术/像素堆叠生物工坊/`；第 3 步导出网页试玩包时，由脚本只把用到的资产自动抽到 `dist/art/`。

### 1.2 技术与操作硬约束

- **纯 HTML + 原生 JS（浏览器自带 ES 模块）+ Canvas 2D**，零游戏引擎、零第三方库、零打包构建工具。
- **画面分辨率**：按 **1920×1080** 设计（代码用 960×540 布局单位，1 单位 = 2 像素；非 16:9 等比缩放留黑边），最小字号 **24px**（12 布局单位）。
- **拖拽操作硬规矩（绝不改成点击出牌）**：
  - 手牌排成**一道弧**；
  - 只能从手牌**拖入施法链尾**，不能插到链中间；
  - **链里的牌不能再拖、不能改顺序**；放错了点 **「退回一张」** 或 **「清空」**；
  - 点 **「施法」**（或空格）打出整条链：链收到画面**最左侧竖成一列**依次亮起，由**下方主角打向上方目标怪**，飘**纯数字**（不写「万」「亿」）；
  - 界面全中文；所有展示文案零禁用字。

### 1.3 目录结构（简洁解耦，只在 `app/` 组装）

3. 角色与场景摆件只经 `modules/render/` 绘制，玩法代码不碰具体美术实现。

## 二、第 1 步：核心战斗（保留你全部核心 + 起手瘦身到 3 张）

> **这步的目标**：打开浏览器直接进战斗，不讲世界观废话。**完整保留你的独创机制**，把起手手牌降到 **N = 3 张**，第一战简单干净，通过 4 场递进战斗验证「留牌攒 4 连 / 补色合白清场 / 破色盾推倒计时保心 / 避开敌方克制色」四类专属于 code00 的取舍。

### 2.1 核心规则清单

1. **主角与胜负**：
   - 主角 **3 颗心**（支持半颗心扣血，一趟内跨战保留，不自动回满）；
   - 基础属性起步：攻击 `35`、暴击率 `10%`、暴伤 `×1.5`；
   - 场上敌人全部击败即胜；心归 0 即败，可一键重开。

2. **固定 29 张宝石牌组 + 起始手牌 N = 3**：
   - **固定 29 张循环**（每战开打洗牌，打完进弃牌堆，摸空洗回；一趟内不加不删宝石牌）：
     * 红、绿、蓝：各 **5 张**（每张 1 颗对应色宝石）；
     * 黄（红+绿）、青（绿+蓝）、紫（红+蓝）：各 **4 张**（每张 2 颗宝石）；
     * 白（红+绿+蓝）：**2 张**（每张 3 颗宝石）。
     * **牌面直接画出对应红/绿/蓝宝石圆点**，一眼看懂组合色包含哪两色。
   - **摸牌与留牌（起手 3 张，清爽且自带留牌取舍）**：
     * 每回合开始：**先摸 2 张**，摸完手里不足 `N` 张则补至 `N` 张；**回合开始手牌上限 `N + 1` 张**（到达上限不再摸）；
     * **第 1 回合**空手起抓，拿 **N = 3 张**；
     * **回合结束**：未打出的牌**留在手里**带入下回合；**出牌不限张数**，每回合排 1 条施法链打出，也可少打留牌；
     * **起手 3 张的精妙处**：全打光下回合只摸 3 张；若本回合只出 1 张、**留 2 张关键牌**，下回合先摸 2 张就能凑齐 **4 张满上限手牌**，打出一波平时打不出的 4 连大爆发！一趟里拿到「手牌扩容（N +1）」升到 4、5 张时，成长爽感立竿见影。

3. **七色色环接链（完整沿用你的原型规则）**：
   - **色环**：`红 → 黄 → 绿 → 青 → 蓝 → 紫 → 红`，`白` 在圆心。
   - **接链关系**：
     | 关系 | 例子 | 效果 | 拖牌时手牌高亮 |
     |---|---|---|---|
     | 起色 | 本战第 1 张 | 倍率 `×1`，记下此色 | 默认 |
     | 同色 / 邻色 | 红→红、红→黄 | 接上！倍率 **×2**，沿链累乘 | 亮**绿框** |
     | 正对面（补色） | 红↔青、黄↔蓝、绿↔紫 | **合白**：倍率照样 **×2**，额外对**全体敌人**打一轮白色伤害（红绿蓝各 1 份），**清空已集颜色**，只留本色 | 亮**金框** |
     | 隔一格（断色） | 红→绿 | 断了：本张**不翻倍（倍率不掉）**；清空已集颜色，只留本色 | 牌面**变暗** |
     | 白牌 | 任意→白、白→任意 | 百搭接任何色，倍率 **×2**；白不算集色 | 亮**白金框** |
   - **跨回合接色**：上回合末色留到下回合；下回合第 1 张若接得上，直接从 `×2` 起步。
   - **集色与彩虹**：每打带色牌点亮色环对应 1 格（跨回合保留，每战开始清空）。集齐 6 色触发**彩虹**：链打完后，把本链所有宝石打出的发（含合白那轮）用彩虹色对**全体敌人再打 2 遍（共 ×3）**，随后从当前色重集。一条链最多触发 1 次彩虹。
   - **单攻与群攻**：带色宝石打**当前选中目标**；**合白额外一轮**与**彩虹重放两遍**打**全体敌人（每只吃满）**。
   - **发数与单发伤害**：
     * 每颗宝石打出「当前链倍率」那么多发（**发数不封顶**）；
     * 每发伤害 = `攻击 × 宝石等级加成 × (1 + 增伤) × (暴击时暴伤) × 盾倍数`；
     * **宝石等级**：打出带红/绿/蓝点的牌，对应颜色攒 1 点经验，每满 10 点升 1 级，每级每发伤害 **+10%**（一趟内跨战保留，重开归 1 级）。

4. **敌方多重血条、颜色护盾与倒计时**：
   - **多重血条**：普通怪 1 条血、强敌 2 条血、首领 3 条血；单条打空切换下一条并刷新该条色盾。
   - **颜色护盾（红/绿/蓝三原色，高阶怪带双色盾）**：
     * 护盾存在时受伤 **×0.75**；击破护盾后受伤 **×1.5**，并**立即把该怪倒计时推迟 1 格**；
     * 每张进链牌按所含对应色宝石颗数削盾（黄牌同时削红/绿各 1 格，白牌三色各削 1 格；合白追加波与彩虹重放不重复削盾）。
   - **倒计时与预告**：怪头顶清晰标出剩余回合圆章与攻击威力（如 `扣半心`、`扣 1 心`、`塞废牌`）。每回合施法后倒计时 -1，到 0 出手并重置。倒计时剩 1 时图标变红跳动警示。

## 三、第 2 步：一局清晰的主线（落果密林 · 第 1~8 步纵深探索）

> **这步的目标**：把你的「出口挂奖励 + 赌撤离 + 攒路子打首领」装进一张像《杀戮尖塔》一样**一眼看穿整局走向**的纵深路线图里，点「深入林地」直接开局，10~15 分钟打完一趟。

### 3.1 路线图设计与清晰指引（核心体验升级！）

彻底告别模糊的「第几层第几片」，整趟探索就是一张**从底部向上攀升的「落果密林探索图（第 1 步 → 第 8 步）」**：

- **结构与节奏（共 8 步纵深，中间设「界门」折返点）**：
  - **林缘段（第 1~4 步）**：
    * **第 1 步（底端起点）**：固定 2 个浅林入口（入门遭遇战：水滴软泥 / 草茎绵羊），一眼知道从哪点进去；
    * **第 2~3 步**：分支展开（2~3 条路），混合布置**遭遇战、林中偶遇、行商营帐、营火整备**；
    * **第 4 步（林缘关口）**：必含 1 个高回报**强敌战（五尾赤豹，红徽章）**与 1 条相对稳妥的分支路线；
  - **【林间界门】岔口（第 4 步打完自动触发，保留你的寻宝撤离基因！）**：
    * 地图中段画有一道醒目的**青苔石门横界线**；
    * 打完第 4 步后，弹出界门抉择界面：
      - **「见好就收 · 折返结算」**：带着目前攒下的金币与战利品安全离开林地，展示本趟战果（为后续第 4 步接回大厅工会留好标准接口）；
      - **「推开石门 · 深入腹地」**：继续踏入第 5~8 步挑战更高收益与林地首领（中途心归 0 则战利品尽失）！
  - **密林腹地（第 5~8 步）**：
    * **第 5~6 步**：高阶生态遭遇战、强敌战（腹口懒兽）、林中偶遇与行商营帐；
    * **第 7 步**：必经**战前营火整备**（打首领前回心或雕琢宝石）；
    * **第 8 步（顶端终点）**：**林地首领 · 千丈古树精**（居中大号王冠古木徽章，所有路线最终汇聚于此）。

- **像《杀戮尖塔》一样明确的视觉指引规范（开发必须做到）**：
  1. **路线一眼看全**：整张第 1~8 步纵深图铺满屏幕主体（可轻微上下滚或整屏完整展示，建议整屏一次看全 8 步无需滚动！），每一步左侧标清清晰的步数刻度（`1` 到 `8`）与生态段名（下半段 `林缘` / 中线 `青苔界门` / 上半段 `腹地` / 顶端 `巨木树冠`）；
  2. **四种连线状态绝不混淆**：

### 4.3 `workshop-adapter.js` 渲染与性能铁律

1. **只借像素堆叠角色和摆件，不要工坊圆台**：用 `StackRenderer` 的 `cached` 模式调用 `prepareActor` + `drawPreparedActor` 绘制所有摆件与角色（按 `y` 远→近排序），底层则绘制 `scene-env.js` 画出的全屏生态地面与落地椭圆投影。
2. **像素清晰防糊**：像素堆叠层关闭平滑（`imageSmoothingEnabled = false`）、取整数倍缩放、**严禁常态小数 `scaleX/scaleY` 拉伸**；文字、血条、卡牌与路线图 UI 保持正常平滑渲染。
3. **干脆的战斗动作反馈**：平时跑待机呼吸（`{ action: 'idle', patrol: false }`）；主角施法与怪出手时做前冲位移，受击做短震动 + 闪白，破盾弹青色「破盾！」，触发彩虹时画面四周泛起柔和七彩边晕。
4. **保留色块切换**：网址带 `?art=blocks` 可一键切回纯色块，方便单测截图与对照排错。

### 4.4 背景音乐、生态氛围音、音效与一键网页打包

- **零依赖 Web Audio 音频系统（`modules/audio/`：`bgm.js` + `sfx.js` + `index.js`）**：全部用浏览器原生 Web Audio 合成，零外部素材即可发声，同时预留标准接口，以后想换成真人录制的 `.ogg` / `.mp3` 只需改 `modules/audio/`，玩法一行不动。
  1. **4 段场景背景音乐（BGM，切场景做 0.6 秒柔和淡入淡出，绝不生硬切断）**：
     - **探索 / 路线图与营火**：林间舒缓五声音阶拨弦与木琴质感低音铺底（约 82 BPM），让人静心看图规划路线；
     - **普通遭遇战**：轻快有律动的林地战斗节拍（约 112 BPM），弹跳低音加清亮主旋律，爽快不吵耳；
     - **强敌 / 林地首领战**：紧张推进鼓点加厚重低音脉冲（约 128 BPM），千丈古树精进入第 3 条血时自动叠一层高频紧迫节拍；
     - **通关 / 撤离结算短乐句**：3 秒明快收尾和弦（播完即停，不死循环）。
  2. **生态微环境音（压低在 BGM 之下约 15% 音量，随当前场景自动切换）**：
     - 落果浅林 / 花甸林隙 / 巨木树冠：柔和滤波林风；
     - 泽畔浅洼 / 苔石古径：零星细水滴与泥沼浅泡声；
     - 营火整备：细碎木柴噼啪声。
  3. **10 种交互与战斗音效（SFX）**：
     - **操作**：①选路线/点按钮清脆木键声；②拖牌/退回轻柔纸牌摩擦声；
     - **排链施法**：③接色成功清脆升调（**链越长音阶越高**，Do→Re→Mi→Sol→La→高Do）；④断色低沉顿挫声；⑤补色**合白**厚重和弦爆发；⑥集齐六色**彩虹**七音琶音连响；⑦宝石命中短促击打声（长链高发数时自动节流，绝不破音刺耳）；
     - **胜负成长**：⑧**破盾**清脆碎裂声；⑨敌方出手与主角**扣心**闷击警示音；⑩获得秘宝印记 / 宝石雕琢升级的明快提示音。
  4. **浏览器防坑与音量控制**：在玩家首次点击/拖牌时解锁 `AudioContext`（未交互前静默不报错）；顶栏放音频按钮，支持**音乐（BGM）**与**音效（SFX）**各自开关或调音量，并记住设置到 `localStorage`。
- **结算页「复制试玩记录」**：一键拷出纯文本摘要（游玩时长、开了几趟、每趟走到第几步、折返还是阵亡、每回合平均思考秒数、撤回次数、选了哪些印记和雕琢）。
- **一键导出网页试玩包（`tools/export-web.js`）**：自动收集 `app/`、`modules/` 与上面 31 个用到的 `/art/` 脚本，产出 `index.html` 在根目录的纯静态 zip（`原型/v2/dist/code00-forest-web.zip`），直接上传 **itch.io（选 Restricted 密码访问）** 发给朋友，**点链接浏览器直接玩，零安装**。
