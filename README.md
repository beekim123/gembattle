# 异能卡牌 · 像素堆叠原型

俯视第三人称、像素堆叠（sprite stacking）画法的原型。Electron + 原生 JS + Canvas 2D，没有别的依赖。

> 现在的代码是**看美术效果的样片**，美术风格定了；玩法正在从 0 重新设计（见 `设计.md`），下面「流程」写的是样片的玩法。

- 启动：双击根目录的 `启动.command`（第一次会自动装 Electron）。或者 `npm install` 一次再 `npm start`；也可以用任意静态服务器打开 `index.html`。
- 流程：大厅 → 进入迷雾森林 → 砍柴坡（一段有边的林子，南边进）→ 碰鬼火开打（红鬼火是精英）→ 打赢选牌（精英和看门的先掉零碎三选一）→ 路上碰石碑歇脚（回心 / 强化 / 删牌）、摸树洞（捡零碎）→ 打倒北边石门前「看门的」→ 石门开 → 老林子（扑棱、木木、看门的大眼珠）→ 蛤蟆塘。大厅的「卡册」里能看所有怪的样子和来历。随时 Esc / 右上“回大厅”（这一趟结束）；心打光也回大厅；回大厅先弹一张结算。每局从起手牌组开始；本机（localStorage）只记次数和最高记录。
- 操作：WASD 走（Shift 跑），Q / E 或拖鼠标转镜头；碰到鬼火进战斗；战斗里点牌（或拖）排进链，按“施法”或空格；链空着时按钮是“攒着”（不出牌，结束回合）。

## 文件
| 文件 | 管什么 |
|---|---|
| `src/engine.js` | 噪声、随机数、体素建模 `build()`（体素返回 `[r,g,b,1]` 就是自发光，另画进发光层）、镜头投影 `proj()`、切片叠画 `drawStack()` |
| `src/pixfont.js` | 像素字：`pixText()` 画伤害数字、施法总数、倍率、倒计时、血量（手画的点阵数字 + 万 / 亿，别的字临时描成点阵；先画在草稿图上再整张贴，任何缩放都方正） |
| `src/models.js` | 所有模型（枯树、树桩、荆棘、石头、菌子、枯苇、主角、提可、石门、路边系红布的木桩），代码逐体素生成 |
| `src/world.js` | 一段一段的林子：`FLOORS` 三段的定义（怪、血量、看门的、地貌 `look`）、7×7 区块的有边地图（南边入口、北边石门、主路、四周密林；主路宽、颜色浅，树给路让开，拐弯插木桩、路边隔一段一丛发光菌子）、石碑和树洞的位置、碰撞、固定的鬼火（普通 / 精英）和看门的、迷雾小地图 |
| `src/spots.js` | 石碑和树洞：碰到以后的菜单（歇脚三选一、挑一张牌强化或删掉、树洞摸出零碎）、树洞上飘的光点 |
| `src/scene.js` | 画林子：地面 → 物件按远近排（挡住主角或跟前主路的树冠变透明）→ 黑暗（只亮宝石周围一圈）→ 冷雾、黑暗里的眼睛 |
| `src/rules.js` | 一仗的规则：摸牌由少到多、色环接链（接上 / 合白 / 断 / 彩虹）、伤害、宝石等级、怪和特性（扑闪、抖伞、扎根、撕页、急性子、盯着）和每种怪的一句来历、以后几段的怪（`MONSTERS_LATER`，卡册用）、精英、零碎的效果、奖励、石碑的强化和删牌、数字格式（1.28万 / 3.6亿） |
| `src/cards.js` | 像素牌面（44×62）：金属边框 + 拱形法阵小窗、切面宝石、法术的图、点数牌、词的记号、糊住的牌背（黄纸红圈问号）；零碎的 12×12 小图、零碎一栏和三选一的大卡 |
| `src/monsters.js` | 怪的样子（战斗、林子里的真身、卡册共用）：自己打光的体素建模（左上冷光边、右下暖光边）、打伞的、老墩、根须圈、扑棱（会飞的书）、木木（提线木偶）、大眼珠（眼仁和符石单独一层，换颜色不重做）、精英的红眼睛；`LOOKS` 管每种怪画哪个模型、离地多高、怎么动、鬼火缩到身上哪儿 |
| `src/battle.js` | 俯视战斗：点牌 / 拖牌排链、施法播放、伤害数字、怪的回合、奖励、逃跑 |
| `src/album.js` | 卡册：每种怪一格（战斗镜头现拍的小像）、点开看大图 / 在哪 / 特性 / 数值 / 来历 / 碰到几次打倒几只、精英切换；`ALBUM_ALL` 测试时全部摊开 |
| `src/lobby.js` | 大厅：林边石碑空地、菜单（进入迷雾森林 / 牌组 / 卡册 / 退出游戏）、存档（跨局的次数、最高记录、卡册记录 `dex`） |
| `src/main.js` | 主循环、输入、大厅 ↔ 探索 ↔ 战斗切换、进下一段、开石门、小地图、探索界面、走近鬼火露出怪的真身 |
| `设计.md` | 现在的设计：从 0 重新设计，开头是「路线」（第 0~10 步）和每步到哪了 |
| `旧/` | 美术样片那版的旧设计（`设计-美术样片.md`）和样片代码的说明、自测方法、坑（`样片说明.md`） |
| `进度.md` | 做到哪、下一步、坑（开头“现在”一段）+ 每步的记录 |
| `tools/shot.cjs` | 无窗口试玩截图：`npx electron tools/shot.cjs <脚本.js> /tmp/shots`，脚本写法见文件开头 |
| `tools/tour.js` | 给 `shot.cjs` 用的脚本：大厅 → 林子 → 进战斗 → 攒牌、点牌排链、施法 → 奖励，一路截图 |
| `tools/floor.js` | 给 `shot.cjs` 用的脚本：整段俯视图 → 打看门的 → 零碎 + 选牌 → 开石门 → 进下一段 → 回大厅结算 |
| `tools/step3.js` | 给 `shot.cjs` 用的脚本：打伞的（抖伞）、凶·提可、老墩（根须）、零碎三选一、石碑、强化、树洞，挨个截图 |
| `tools/step4.js` | 给 `shot.cjs` 用的脚本：老林子地貌、扑棱（撕页糊牌、链里的「？」）、木木、两个精英、大眼珠（盯着）、新零碎和新牌，挨个截图 |
| `tools/rules-test.js` | 规则单测（零碎、根须、孢子、精英、石碑、撕页、盯着、哨子、万花筒、大口袋、跟屁虫、叠罗汉）：`node tools/rules-test.js` |
| `tools/sim.js` | 链伤害粗算：`node tools/sim.js` |

调试：控制台里 `NOLIGHT = true` 关掉黑暗看整片林子。

## 美术
- 画师交的像素堆叠美术放 `art/<版本>/`（现在是 `art/neo-1/`，Neo 第 1 次）。改了 png 以后跑 `python3 art/打包美术.py neo-1` 重新生成 `art-data.js`。
- `src/art.js` 读它，换掉代码生成的树、草、石头、石碑、主角、提可和地面。（网址加 `?art=0` 回到代码生成的那套，已经不维护。）
