# 像素堆叠魔物骨骼化（v3）与防糊清晰度经验指南

> 本文件同步自 `美术/教程-像素堆叠AI制作方案/骨骼化改造交接与经验.md` 并汇总了 `README.md` 中的**防糊与像素清晰度铁律**，供「像素堆叠生物工坊」逐只精制与排错时直接对照使用。
>
> **2026-11-23 渲染器换了一版**（原因和数字见 `性能与流畅度-2026-11-23.md`），下面几条的说法跟着变了，已就地改过：
> - 不再有 `actorBuf` / `actorRaw` 离屏拼合：渲染器先画所有部件外扩一圈的剪影、再按深度画本体，效果一样，生物脚本不用管（二.1）；
> - 半透明分两种：设计上的半透明写 `opacity`，浸水写 `submerge`（水里染水色、不变透明）；
> - 左右对称的部件自动只烘一半角度；
> - 换色后缓存自动作废，不用手动清（二.7）。

## 一、像素堆叠「发糊 / 发脏」核心排错清单（工坊必查）

1. **严禁把非自发光细节放进 `glowKeys`（头号发糊元凶）**
   - `glowKeys` 仅限真正需要霓虹/火焰辉光的 `['emissiveMid', 'emissiveHot', 'emissiveCore']`。
   - **眼睛高光（`eyeGlint`）、金属反光、金币高光绝不能放进 `glowKeys`**，否则渲染器的 1/4 降采样高斯模糊（`ebctx` + `screen` 叠加）会在眼睛和脸部糊上一层发白光晕，瞬间毁掉五官锐度。
2. **常态严禁对已烘焙精灵做非整数 `scaleX` / `scaleY` 缩放**
   - 部件精灵按 `BAKE_SCALE = 2.5` 离屏烘焙后已是定格像素图；若每帧用 `evalBreathing` 输出 `1.03`、`0.96` 这类小数去拉伸 `drawImage(sp.main, dx, dy, dw, dh)`，会产生像素列抖动、重影与发糊。
   - 呼吸感优先通过**部位微位移（`bodyBob` / `packBob` / `headLift`）**与骨骼姿态实现，仅在极短的爆发/变身瞬间临时使用弹性缩放，常态保持 `1:1` 像素无损绘制。
3. **高对比 3 档色阶 + 细分 `partId` 切出清晰结构暗缝**
   - 单材质严格用 3 档高对比色阶（暗面 / 主色 / 露边亮色），避免过多相近灰阶在低分下揉糊轮廓；
   - 盔甲（`armor`）、主鳞（`scale`）、腹甲（`belly`）、皮带（`strap`）、骨饰（`bone`）、金属（`metal`）必须分设独立 `partId`，靠 `applyArtShading` 的 Crease AO 自动切出 1 格清晰结构线；同时把 `eye:head`、`mouthCore:snout/jaw`、`chestCore:body` 加入 `noCrease` 白名单防止五官发黑。
4. **双眼与亮核必须「表面投影 + 0.6 俯视 0 遮挡」**
   - 眼睛不要埋在粗糙大块体素里，也不要被上方粗眉骨在 0.6 俯视倾角下遮挡；应在着色完成后沿表面扫描落点，精雕 `2×2` 锐利双眼（瞳孔 `eyeDark` + 虹膜 `eyeIris` + 单像素锐利高光 `eyeGlint`）。
5. **宽翼用 `paintWingQuad` 曲面弧边，替代粗糙三角堆叠**
   - 龙翼/蝠翼采用带尾缘扇贝弧（`scallop`）的 `paintWingQuad` 铺设翼膜，翼臂用 `armor`/`scale`、翼指用与龙身同色系的细 `scale` 骨、仅腕爪用 `horn`，且体素盒留足边界余量严防 `y = 0` / `y = d - 1` 被切平。
6. **切片严格二值透明 + 双子步压实**
   - 切片 `alpha` 严格 `0` 或 `255`；`BAKE_SCALE = 2.5` 配合 `yy + 1` 半步压实消除 `HS(0.8) > TILT(0.6)` 斜角百叶窗黑缝；所有普通绘制必须 `imageSmoothingEnabled = false`。

## 二、从 `snake`、`siren`、`goblin` 与 `feilong` 沉淀的 8 条骨骼化实战经验

1. **整只一圈 1px 外轮廓（渲染器自动做）**
   - 部件按 `ry + lift * 0.08 + bias` 深度排序；渲染器先把整只所有部件「外扩 1 美术像素的实心剪影」画出来，再按深度画本体。剪影的并集就是整只的外轮廓，内部零拼装黑缝、外圈轮廓锐利统一。
   - 旧版是每只先拼进局部画布 `actorRaw` 再整体描边（`actorBuf`），同屏多了很慢，2026-11-23 换掉了。生物脚本这边照旧只管排好 `bias`。
2. **用数学保证「零穿模」：净空预算 + 层序偏置 `bias` + Node 周期断言**
   - 被包覆的根节加微负 `bias`（如 `-0.3`），外罩件/头部加微正 `bias`（如 `+0.45`）；写完用 Node 脚本遍历动作周期检查零越界、零 NaN。
3. **偏心旋转部件必须「锁死关节枢轴」（防 1~2px 挤捏缝）**
   - 若部件真实关节位于局部 `(px, py)`，摆放世界坐标一律用 `localToWorldXY(jointX, jointY, partYaw, -px, -py)`。**翅膀翼根、大尖耳耳根、武器握柄、尾鳍/长尾尖**全都要用这一招。
4. **杜绝「浮空平移物体」，体现真实生物运动学**
   - **飞龙**：强翼下拍 → 躯干滞后 `0.72 rad` 被升力托起；巡航包含强拍爬升与展翼滑翔；多节龙颈 + 龙头独立环视，多节鞭尾行波摆动。
   - **哥布林**：原地微蹲警戒（转头张望、尖耳独立抖动、木棒轻晃）↔ 低重心前倾 `28°` 疾跑躯干 + 高频碎步 IK + 落地扬尘 + 滞后颠簸包袱。
5. **宽翼边界留白 + 材质统一 + 三段振翅（`up / mid / down`）**
   - 成年宽翼盒扩至 `30×28×26` 杜绝尾缘截断；肩肌内嵌背脊；补齐 `mid` 中间帧平滑过渡，落地增加收翼态（`tuck/rest`）。
6. **多节尾链 Z 高度单调平滑 + 颈头升降联动**
   - 尾链 Z 高度保持单调平滑（如 `[11.2, 10.8, 10.4]`）；抬头时颈部同步分摊 `headLift * 0.45` 防止头颈脱节。
7. **零重建模一键换色（`SKINS`）**
   - 总色数 `≤ 48` 色、0 重色、自亮色物理隔离；换色时只调用 `recolorAsset` 按索引重刷 `ImageData`，资产版本号自动加 1，烘焙缓存自己作废，不用手动清。
8. **量化校验闭环**
   - 每次修改生物脚本后，挂载本地工坊 `core/` 内核用 Node.js 实测全周期（建模耗时、色表数、零越界、零 NaN、状态机闭环），再进浏览器 360° 旋转实看清晰度。

## 三、水生游动、防穿模与柔顺动作精制经验（从 `siren`、`fairy`、`slime` 踩坑沉淀）

1. **水生生物「真游动」必须体现真实俯仰推进，严禁做成「改高度的陆地平移」**
   - **运动学还原**：人鱼/海豚类游动属于**垂直平面海豚式打水**，由腰腹发起向水平双叶尾鳍传递垂直波，并伴随**头朝下俯潜 → 平滑滑翔 → 抬头浮升 → 减速立身踩水**的完整节奏，切忌只上下平移 Y/Z 轴高度或照搬陆地爬行轨迹。
   - **高密连续倾角消除跳帧卡顿**：不要只烘 2~3 档姿态硬切（如俯潜与滑翔直接跳变）。应连续驱动实数倾角 `curPitch`（例如 `0°~108°`），颈口、肩关节、发根坐标全部由连续 `curPitch` 实时解算，并预烘 6~7 档躯干倾角（每档间距约 `15°~18°`），让 2.5D 堆叠呈现出接近 3D 的丝滑俯仰。
   - **游速与爆发节拍**：水生生物游动要敏捷利落，下打水阶段叠加向前爆发加速，上浮阶段顺势滑行，避免慢吞吞拖滞感。
2. **高速转弯时的「长发 / 飘带零穿模」铁律（禁用世界空间滞后插值）**
   - **典型踩坑**：在世界空间对头发节点做 `expSmooth` 滞后跟随，角色高速环游转弯时，发束会沿圆弧内侧弦直接切穿肩膀或背部。
   - **根治方案**：改在**机身局部坐标系**下，沿**脊柱背面外法向** `back = (-cos(pitch), sin(pitch))` 实时计算每个发束节点的位置，确保在直立（0°）、抬头浮升、水平滑行、俯潜（108°）任意倾角下，头发都严格浮在背部与肩鳍外侧净空之外；转弯飘动仅用带限幅的侧向微摆 `clamp(-yawRate * k, -max, max)` 表达，再配合合理的 `bias` 层序，从几何上彻底根治穿模。
3. **手臂/触须告别僵硬：拆分为「两段式关节 + 相位滞后随动」**
   - **典型踩坑**：整条刚性手臂按姿态档位硬切（手端瞬移数格），或仅靠肩关节整体旋转，挥动像木偶一样生硬。
   - **根治方案**：拆分为**大臂 + 小臂**两段独立资产（如 `upperArm` + `forearm`），以精确肩肘正运动学（FK）连续驱动，同时让小臂相对大臂保持约 `0.75~0.85 rad` 的**相位滞后随动（Overlapping Action）**——大臂引领、肘腕滞后柔顺舒展，彻底消除换姿跳变与僵硬感。
4. **俯冲/背视角「腿部与裙摆穿模」排查要点（以 `fairy` 为例）**
   - 飞行类人形生物向前俯冲时，躯干前倾容易在背视角把原本藏在裙内的双腿上部漏出。
   - **排查与修复**：将双腿挂点向内微收（调整局部 `ly`）、适当裁短大腿顶部使其低于裙腰上沿，并给腿部设置更明确的负 `bias`（如 `-2.2`），确保 360° 视角下裙摆都能干净遮盖。
5. **趣味细节与生态互动设计（以 `slime`、`siren` 为例）**
   - **体内可视化道具**：半透明生物可用体内高辨识度体素小道具（如多种水果/虫子/小鱼食物）替代单调气泡；工坊预览期可每隔数秒轮换展示，同时通过配置参数支持游戏内锁死单次随机结果。
   - **去武器化伴游生态**：偏灵动/亲和的水生或自然生物不强行配武器，可设计多款高辨识度小配角（如小丑鱼、章鱼、蓝唐王鱼、河豚、海马、海龟）按「入场 → 环绕嬉戏 → 游离」循环轮换，并让主体视线与伸手动作朝配角自然响应，大幅提升生命力。

## 四、四足生物步态与矢状面 IK 避坑经验（从 `earth3_zheng`、`sand4_karkadann` 踩坑沉淀）

1. **严禁用「髋 → 足射线平面」2D IK 解四足腿，必须用躯干矢状面 3D IK（`PW.Solvers.solveSagittalLegIK`）**
   - **典型踩坑**：旧版 `solveIK2D` 在「髋 → 足」连线的垂直平面内求膝盖位置；一旦后足踩在髋部后方，膝盖就会顺着向后向量甩到臀后，看起来像后腿折断被拖着走，且脚从髋后摆到髋前瞬间还容易发生 180° 翻转奇点。
   - **根治方案**：`core/solvers.js` 中的 `MultiLegGaitSolver` 对 4 足生物已内置 `solveSagittalLegIK`，在躯干前后矢状面内解算膝肘——**前肢肘部恒向后折（`kneeSign: -1`）**，**后肢膝盖恒向前折向腰腹（`kneeSign: +1`）**，360° 视角下始终呈现自然有力的四足 Z 字腿型。
2. **四足告别「阈值触发式」拖行步态，统一采用位移驱动循环步态**
   - **典型踩坑**：旧版 `walk4 / trot` 要等足掌偏离理想点超过 `stepThreshold` 才抬脚，加上对角/四拍互斥锁，稍快起步或转弯就会把后足硬拖到髋后 `7~11` 格，后足抬脚占空比跌到 20%~30%，视觉上像后肢瘫痪拖地。
   - **根治方案**：`MultiLegGaitSolver` 对 4 足已升级为**位移 + 转向角驱动的连续循环步态**（支持 `walk4` 四拍稳步、`trot` 微错相对角小跑、`bound` 前后足腾跃）：支撑期足掌世界坐标钉地（零滑冰）并带最大髋后滞后保护，摆动期后足干脆抬离并主动前探至腰腹下方，停步自动轻抬收回肩胯正下方。
3. **四足中性落点、分节挂点与抬脚高度规矩**
   - **后足中性站位不偏后**：后足 `restY` 应放在髋关节 `hipY` 正下方或微偏前（`restY ≈ hipY + 0.2`），不要把 `restY` 设在 `hipY` 后方 `1~2` 格，避免起步先落后半拍；
   - **分节脊柱必须绑独立锚点**：拆出独立胸肩与腰胯（如五尾红豹）时，后腿须通过 `legAnchors: { BL: pelvisAnchor, BR: pelvisAnchor }` 挂在腰胯局部坐标上，转弯屈脊时后腿不脱胯；
   - **抬脚高度可辨识**：俯视角下 `stepHeight` 建议设在 `2.4~3.6` 格（按体型缩放），低于 `2.0` 格容易显得贴地擦行。
4. **四足 Node 仿真量化红线（改完必跑）**
   - 行进时后足相对髋部的最大滞后应控制在 **`≤ 4.2` 格**以内；
   - 后膝前后位置全程保持在髋部前方（`> 0`），绝不倒拖至臀后；
   - 后足摆动抬脚占空比保持在 **`35%~50%`**，且所有腿段坐标零 `NaN`。
