# 设计文档：UI-02A 七色宝石牌与 8 张秘术牌（`Code00ArtPacks.cards` 牌面部分）

## 一、定位与轻量化原则

- 本包**只负责卡牌牌面与施法链槽**（不画 10 个印记和 6 种战利品图标，那些已独立拆给 UI-02B）。
- **复古奇幻精绘像素风**：硬朗 `#0c121a` 像素描边、锻铁/黄铜像素牌框、高对比三阶明暗宝石切面；绘制采用**简洁高效的几何多边形/像素块面离屏预烘焙**（单文件精炼在 ~500~800 行内即可达到极高质感，绝不为单个图标堆砌冗余点阵数组）。

---

## 二、完整资产清单

### 1. 七色宝石牌（`color: 0..6`，牌面基准 `CARD_W = 62, CARD_H = 88`）
- **彻底弃用大号黑体字「红/黄/紫」**！牌面中央是精绘多面体切面像素宝石，顶部固定 3 颗三原色晶孔（按色环混色点亮红 `#ff5a4a` / 绿 `#52d65a` / 蓝 `#5a8cff` 对应晶珠）：

| `color` | 含三原色点 `[红,绿,蓝]` | 主色 / 暗面 / 亮面 | 独特切面轮廓（形+色双重秒认） |
|---|---|---|---|
| `0` 红 | `[1, 0, 0]` | `#e2483c` / `#8e1f18` / `#ff9e8e` | 竖长红曜菱尖晶 |
| `1` 黄 | `[1, 1, 0]` | `#efc93f` / `#9a7a10` / `#fff6b0` | 宽面琥珀八角盾晶 |
| `2` 绿 | `[0, 1, 0]` | `#4cb050` / `#1f6a24` / `#a6f2a0` | 祖母绿长方阶梯切面晶 |
| `3` 青 | `[0, 1, 1]` | `#3fbac4` / `#14727c` / `#aef6fa` | 碧海泪滴尖顶晶 |
| `4` 蓝 | `[0, 0, 1]` | `#4474dd` / `#1f3f9a` / `#9cc4ff` | 深蓝风筝盾钻 |
| `5` 紫 | `[1, 0, 1]` | `#9254cf` / `#561e8c` / `#dfb0ff` | 紫晶主尖+两侧小晶簇 |
| `6` 白 | `[1, 1, 1]` | `#f4f0e6` / `#9a9684` / `#ffffff` | 百搭六角棱白晶核（带微红绿蓝切边） |

### 2. 八张秘术牌（`card.arcana`）+ 缠藤废牌 + 遮蔽牌背 + 常规牌背 + 施法链槽
- **5 张瞬发秘术（无色，银紫深框 `#6a5ab8`/`#342a68` + 顶沿菱形瞬发徽记 + 牌底清晰 4 字卡名）**：
  1. `spring`（涌泉抽牌）：蓝白涌泉与飞出的两枚卡牌剪影
  2. `ward`（护身结界）：青白六边形晶盾结界
  3. `shatter`（震裂破甲）：晶锥击碎裂纹盾牌
  4. `surge`（魔力沸腾）：沸腾橘红晶焰向上翻涌
  5. `resonance`（双色共鸣）：两道弧形色环节点共振连线
- **3 张入链秘术（带色，按 `card.color` 着底色 + 华丽暖金边框 + 顶部三原色晶孔 + 牌底 4 字卡名）**：
  6. `refract`（逆色折射，白）：白晶棱柱折出补色双芒
  7. `prism`（倍增棱镜，红/绿/蓝）：嵌套菱镜映出 `×2`
  8. `keep`（凝色留存，黄/青/紫）：黄铜沙漏封存稳固宝石
- **`junk`（缠藤废牌）**：枯褐破旧木牌缠满暗绿棘藤，无宝石孔。
- **`masked`（被遮蔽）**：青苔暗石板牌背 + 浮雕 `?` + 底部「已遮蔽」。
- **`drawCardBack`**：深靛蓝木纹牌背 + 黄铜四角饰 + 中央六色罗盘暗纹。
- **`drawChainSlot`**：石刻法阵镶嵌牌槽（替代虚线框；拖拽中 `isNext` 槽位亮起金色四角引导标）。

## 三、合并挂载规范与硬红线（`verify.mjs` 自动查杀）

**必须使用合并挂载（绝不覆盖同对象上 UI-02B 注册的图标方法！）**：
```js
window.Code00ArtPacks = window.Code00ArtPacks || {};
const target = window.Code00ArtPacks.cards = window.Code00ArtPacks.cards || {};
Object.assign(target, {
  id: 'cards', version: 1, cardsName: '七色宝石与秘术卡牌',
  CARD_W: 62, CARD_H: 88,
  init: initCards, initCards, drawCard, drawCardBack, drawChainSlot
});
```
*(提示：`drawCard` 画牌底雕琢角标 `card.carve` 时，若 `target.drawCarveBadge` 已存在则优先调用它；未挂载时画简洁的对应色带字小方徽兜底。)*

- **必须实现的方法**：`initCards(makeCanvas)`（同时导出为 `init`）、`drawCard(ctx, card, opts = {})`、`drawCardBack(ctx, x, y, scale = 1)`、`drawChainSlot(ctx, x, y, w, h, state = {})`；
- `drawCard` 参数：`opts = { frame: 'near'|'comp'|'wild'|'break'|null, lit: bool, dim: bool, masked: bool, tag: string, tagColor: string, t: number }`；
- **硬红线**：零 `ctx.filter`、零 `shadowBlur`、零外部图片/网络 URL、零禁用字、离屏画布总内存 `<= 2 MB`、`initCards` 耗时 `<= 40 ms`、绘制结束必须 `restore()` 且像素绘制关平滑 `imageSmoothingEnabled = false`。

const canvases = [];
function makeCtx() {
  const grad = { addColorStop() {} };
  const state = { filter: 'none', shadowBlur: 0, globalAlpha: 1, imageSmoothingEnabled: true, fillStyle: '#000', strokeStyle: '#000', lineWidth: 1, font: '12px sans-serif', textAlign: 'left', textBaseline: 'alphabetic' };
  let runtimeFilterSet = false, runtimeShadowSet = false;
  return new Proxy(state, {
    get(o, k) {
      if (k === '__flags') return { runtimeFilterSet, runtimeShadowSet };
      if (k in o) return o[k];
      if (k === 'createLinearGradient' || k === 'createRadialGradient') return () => grad;
      if (k === 'createImageData') return (w, h) => ({ width: w, height: h, data: new Uint8ClampedArray(Math.max(1, w) * Math.max(1, h) * 4) });
      if (k === 'measureText') return (s) => ({ width: String(s || '').length * 8 });
      return () => {};
    },
    set(o, k, v) {
      if (k === 'filter' && v && v !== 'none') runtimeFilterSet = true;
      if (k === 'shadowBlur' && Number(v) > 0) runtimeShadowSet = true;
      o[k] = v;
      return true;
    }
  });
}
function makeCanvas(w = 1, h = 1) {
  const c = { width: Math.max(1, Math.round(w)), height: Math.max(1, Math.round(h)), _ctx: null, getContext() { if (!this._ctx) this._ctx = makeCtx(); return this._ctx; } };
  canvases.push(c);
  return c;
}

  for (const fn of ['initCards', 'drawCard', 'drawCardBack', 'drawChainSlot']) {
    check(typeof pack[fn] === 'function', `缺少必需方法：${fn}`);
  }

  const t0 = sandbox.performance.now();
  if (typeof pack.initCards === 'function') pack.initCards(makeCanvas);
  const initMs = sandbox.performance.now() - t0;
  check(initMs <= 40, `initCards 耗时过长：${initMs.toFixed(1)}ms（上限 40ms）`);

  const ctx = makeCtx();
  try {
    for (let c = 0; c < 7; c++) {
      pack.drawCard(ctx, { color: c, carve: c === 0 ? ['sharp', 'pierce'] : [] }, { frame: ['near', 'comp', 'wild', 'break', null][c % 5], tag: '接上', tagColor: '#6fe07a', t: 1.2 });
    }
    for (const [id, col] of [['spring', -1], ['ward', -1], ['shatter', -1], ['surge', -1], ['resonance', -1], ['refract', 6], ['prism', 0], ['keep', 3]]) {
      pack.drawCard(ctx, { color: col, arcana: id }, { lit: id === 'prism', t: 1.2 });
    }
    pack.drawCard(ctx, { color: -1, junk: true }, { dim: true });
    pack.drawCard(ctx, { color: 2 }, { masked: true });
    pack.drawCardBack(ctx, 100, 100, 1);
    for (const st of [{ isNext: true, dragging: true, index: 0, filled: false }, { isNext: false, dragging: false, index: 1, filled: true }]) {
      pack.drawChainSlot(ctx, 200, 200, 45, 64, st);
    }
  } catch (e) {
    errors.push(`接口运行期异常：${e.stack || e.message}`);
  }

  check(!ctx.__flags.runtimeFilterSet, '运行期触发了 ctx.filter');
  check(!ctx.__flags.runtimeShadowSet, '运行期触发了 ctx.shadowBlur');

  const totalBytes = canvases.reduce((s, c) => s + c.width * c.height * 4, 0);
  const mb = totalBytes / (1024 * 1024);
  check(totalBytes <= BUDGET_BYTES, `离屏贴图超标：${mb.toFixed(2)} MB（上限 2.00 MB）`);

  console.log(`- 离屏画布：${canvases.length} 张，合计 ${mb.toFixed(2)} MB（上限 2.00 MB）`);
}

if (errors.length) {
  console.error(`\n❌ 校验未通过（${errors.length} 项错误）：\n  - ${errors.join('\n  - ')}`);
  process.exit(1);
}
