### 一、造型、体素特点与场景要求
注意：文案、皮肤名、技能名严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。正面统一朝向 `+Y`，`z = 0` 贴地。

1. **主体造型**（推荐体素盒约 `34 × 34 × 34`）
   - 矮小精悍、微微前倾的经典异世界哥布林剪影：一对向两侧斜后伸出的大尖耳（截面厚度 ≥ 2 格防止旋转破碎）、微尖长鼻子、略大的狡黠脑袋、0.6 俯视清晰可见的贼亮双眼；
   - 身上穿粗布腰衣/皮肩带，背后背一只鼓鼓囊囊的小皮包袱（里面露出一点绳结或金币边角，与躯干分 `partId` 用 Crease AO 切出层次）；
   - 右手持一根粗实带铁钉的**木棒或锯齿短刀**（半径 ≥ 1.1 防止旋转断裂），左手微曲平衡；
   - **待机与小碎步循环（8 帧）**：双腿交替微蹲垫步、大耳朵随节奏轻颤、右手武器上下晃动、背后包袱轻颠。

2. **场景与受击靶**
   - 圆形泥土/营地石砖底座（周期纹理 + 固定石边环），前方 `+Y` 方向放置像素堆叠训练靶桩（受击抖动、炸黑焦印、掉落弹跳小金币等反馈）。

### 二、4 套色系（零重建模一键换色，快捷键 `C` 或 HUD 按钮切换）
必须基于 `Uint8Array` 索引网格实现 `recolorAsset(skin)`（`< 2ms` 按索引重刷长条图集并清空精灵缓存回收至对象池，**严禁重跑 SDF 建模**），同时联动技能的武器拖尾、旗帜/波纹、炸弹火花色：
1. **苔绿（普通）**：经典草绿皮肤 + 棕皮腰衣与包袱 + 木棒配灰铁钉 + 橘红炸弹火花；
2. **赭红（狂躁精锐）**：赤铜红皮肤 + 暗铁黑皮甲 + 染红铁刺棒 + 炽红暴躁气浪与红旗；
3. **岩灰（洞窟矿工）**：灰青岩色皮肤 + 赭黄粗布装 + 亮银矿镐风格武器配色 + 橘黄尘爆火花；
4. **靛紫（部落巫医）**：灰紫蓝皮肤 + 深靛长布围腰 + 骨白与青绿涂纹武器 + 青紫法粉与增益波纹。

---

### 三、4 个技能演出（按钮或快捷键 `1~4` 触发）
所有技能动作要夸张活泼带点狡黠滑稽感，包含完整 **前摇 → 释放与特效 → 靶桩反馈 → 回位**：
1. **小碎步乱劈（1）**：哥布林迈着高频小碎步快速冲到靶桩面前，大幅度左右连挥两下武器（带两道像素弧形劈斩拖尾与打击火花），靶桩连续晃动，打完小跑退回原位。
2. **丢炸药桶 / 圆炸弹（2）**：身子一缩从背后包袱里掏出一颗滋滋冒烟的黑色像素圆炸弹（引线带跳动亮白火点），大力高抛砸向靶桩，落地砰地炸开一大团像素灰烟、橘红碎火与短暂地面黑焦印，触发轻微震屏。
3. **摇旗鼓舞（3）**：临时举起一面插着小布旗的木杆在原地蹦跳摇晃，脚下接连扩散两圈彩色增益波纹，随后哥布林全身短暂泛起热血红晕、原地动作节奏明显加快。
4. **滑铲偷袭（4）**：压低身体向前疾冲滑铲（脚下扬起一串像素尘土）一脚铲撞靶桩，从靶桩身上震落 4~5 枚叮当弹跳的金色像素小金币，哥布林顺手一捞得意地蹦跳回位。

### 四、工程性能与强制自检闭环（对照 `README.md` v2）
1. **第 0 步先写空间坐标预算表**，确认头部、尖耳、鼻子、眼睛、手臂、武器、背后包袱的 `X/Y/Z` 边界互不穿模，且武器与尖耳截面 ≥ 2×2 格。
2. **极速建模与旋转满帧架构**：
   - `Uint8Array` + 部件级 `fillAABB` + `despeckle()` + 垂直 3 档色阶 / 腔体 AO / 白名单 Crease AO + 单张长条图集（保留 `grid` 供 `recolorAsset` 换色），8 帧建模耗时目标 `< 100ms`；
   - 定倍角度烘焙缓存 `BAKE_SCALE = 2.5`（精确 `step = 2`、`1px` 半步压实、`3°` 量化 + 对象池 + 滚轮缩放不清空缓存）；
   - 预渲染天空 `bgc` + `2×` 小地表缓冲集成双层投影/焦痕/波纹 + 缓存模式精灵直绘 `dctx` + 内外发光 `destination-out` 裁切（从 `minGlowZ` 起）+ `1/4` 独立小画布 `ebctx` 真降采样模糊；
   - HUD 支持：4 套色系一键切换 (`C`)、4 个技能 (`1~4`)、自动旋转、单体描边、模式切换（游戏缓存 / 高清逐层 / 复古低分）、导出带色系名长条 PNG、最短角路径重置视角、实时性能栏（建模耗时 / FPS / 单帧 ms / 绘制次数 / 色数 / 缓存）。
3. **强制验收闭环**：
   - 跑 Node 自动化脚本校验：色数 ≤ 48、无重色、无未着色、无孤立碎点、双眼正面 `+Y` 与 0.6 俯视射线遮挡 = 0、切换 4 套色系耗时 < 5ms；
   - 本地静态服务 + 浏览器实机验收：零 Console 报错；旋转正/斜/侧/背检查大尖耳与武器无断裂；测试 4 套色系与 4 个技能演出；连续拖拽/自动旋转稳跑 60~120fps（单帧 < 2ms）；亲自审片并至少迭代打磨 1 轮后收尾清理临时服务。
