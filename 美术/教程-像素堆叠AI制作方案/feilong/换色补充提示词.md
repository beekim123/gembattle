### 一、为飞龙新增 5 套色系方案（`SKINS` 配置表）
注意：皮肤命名与界面文案严禁使用「灯、烬、影、夜、魂、噬、幽、渊、星、光」及「守×者」「×之×」类套路词。每套皮肤基于现有的调色板语义键（`scaleDark/Mid/Hi`、`armorDark/Mid/Hi`、`bellyDark/Mid/Hi`、`wingDark/Mid/Hi`、`hornDark/Mid/Hi`、`eyeIris`、`emissiveMid/Hot/Core`）进行覆写，且确保任意皮肤下总色表依然 ≤ 48 色、发光 3 键与普通色键零十六进制重色：

1. **赤焰红（默认，保留原版）**
   - 保持现有赤橘红主鳞 + 深赤铜成年背甲 + 浅米黄腹甲 + 暖橘翼膜 + 琥珀眼 + 赤金炽核；
   - 特效色 `fx`：保持原版赤橘火焰、亮白炽核、黑焦余热纹。
2. **寒霜冰蓝**
   - 主鳞：清冽冰蓝系（暗深蓝 / 冰海蓝 / 霜亮蓝）；成年背甲：深靛蓝厚甲；腹甲：雪白浅蓝；翼膜：浅天青白；龙角/翼骨：冷银灰；龙眼：亮冰青；自发光内核：冰蓝 → 冰青 → 霜白；
   - 特效色 `fx`：小火球改为冰焰寒球，喷火束改为极寒冰息束，变身旋涡/火环/火雨改为冰青霜焰，地面焦痕改为霜裂冰痕。
3. **剧毒翠绿**

5. **黑曜熔金**

   - 特效色 `fx`：全部技能与变身旋涡变为黑曜白金炽焰与熔岩金裂地痕。

### 二、核心工程实现要求（零重建模、< 2ms 瞬时切换）
1. **保留体素索引网格**：在 `VoxelModel.prototype.toStripAsset()` 返回的资产对象中保留 `grid: this.grid`（以及原有尺寸与 `activeLayers` / `glowLayers` / `glowSlot`），确保不需要重新跑 `buildJuvenileDragonFrame` 或 `buildAdultDragonFrame`。
2. **实现 `recolorAsset(asset, rgbaTable)`**：
   - 切换皮肤时，仅用新皮肤生成的 `rgbaTable` 遍历 `asset.activeLayers` 与 `asset.grid`，直接重刷该资产已有的 `strip` 与 `glowStrip` Canvas 的 `ImageData`（重用现有 Canvas，不新建 DOM 元素）；
   - 对全部飞龙资产（`youngFrames`、`youngTuck`、`adultFrames`、`adultRoar` 以及若存在的体素火球/熔岩块资产）执行批量 `recolorAsset`，并记录切换耗时（应 `< 5ms`）；训练靶桩与石台底座保持独立不变色（仅地面焦痕/热纹色随皮肤联动）。
3. **清理缓存并回收画布**：切色完成后，将 `spriteCache` 里属于飞龙（非靶桩）的缓存条目清除并把 Canvas 回收至 `canvasPool` 对象池，避免切色产生显存泄漏或掉帧。
4. **消除硬编码特效色**：全面排查并替换 `feilong/index.html` 中所有硬编码的 `#ff521b`、`#ffaa2b`、`#fff6c7`、焦痕/法阵/脉冲闪色等颜色字符串，统一改为读取当前皮肤 `curSkin.fx`（包括：幼年 4 技、成年 5 技、四段变身旋涡与破茧冲击波、地面残留焦痕与热纹、HUD 强调色或标题徽章）。
5. **UI 与导出联动**：
   - 在 HUD 面板新增一行「龙鳞色系（快捷键 C）」按钮组，列出 5 套色系按钮（可带对应色系小圆点），点击立刻瞬时切换，按键盘 `C` 键顺序循环切换；
   - 点击「导出长条 PNG」时，导出文件名自动包含当前形态与色系代号（如 `feilong_adult_frost_62x64x48.png`），且导出的图片就是当前所选色系。
