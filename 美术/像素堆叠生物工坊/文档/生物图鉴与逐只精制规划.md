# 像素堆叠生物图鉴与逐只精制规划（总表）

> 本文件整合了《幻想生物图鉴草稿》中的 **33 只原创生态生物** 与项目既有 **8 只扩展魔物**（共 **41 只**），并扩充了 **18 种细分生境地台**。
> 后续工坊开发将严格按本表**一只一只精制打磨**（每只先做精致体素造型 + 纯自由移动与待机生态 + 专属习性，技能留到后期再挂接），做完一只勾选一只。

## 一、单只「精制」质量标准（告别粗糙初版）

前期为了快速验证通用运动框架，初版生物的体素造型偏简略（偏向基础球体/胶囊拼合）。后续逐只重做与新增时，每只生物必须满足以下 5 条精制标准：

1. **分级体素精度（不再缩水）**
   - **小体型**：体素盒 `16~30` 格，注重外形辨识度与成群生态节奏；
   - **中体型**：体素盒 `36~60` 格，必须雕出清晰解剖细节（头吻/眉骨/甲片/羽翼层次/毛簇/爪趾）；
   - **大体型（Boss）**：体素盒 `80~140` 格（可多部件拼接，画面中可只露主体或半身），注重体量压迫感与背甲/表皮的微生态细节。
2. **像素皮肤与着色质感**
   - 每只定制 3 档高对比色阶 + 专属表皮纹理（鳞片、毛发层次、岩裂、水草、骨甲），单怪色表严格 `≤ 48` 色、零重色；
   - 配套 3 套以上零重建模换色皮肤。
3. **肉体连贯与零穿模**
   - 链式躯体相邻节重叠 `40%~45%`，消除串珠感；
   - 多足 IK 腿采用多段关节连杆 + 弯膝折角，不再用单根竖直圆柱糊弄；
   - 所有偏心旋转部件（尾鳍、翅翼、角饰、挂件）锁死真实关节枢轴，统一进 `actorBuf` 整体 1px 外轮廓。
4. **纯生态自由移动（去技能、重生物感）**
   - 每只具备「原地待机微动 + 自主变速启停探索 + 1 个极具辨识度的专属生态习性」，不绑战斗技能。
5. **命名与文本合规**
   - 全流程避开项目禁用字，代号统一沿用 `天/水/海/地/树/沙/洞/泽/特` 编号。

## 四、生态链与多怪同屏互动规划

工坊支持「多怪同屏」，后续精制完成后可按以下真实生态组合摆盘观察：

- **高空捕食链**：`水5（大鱼）` 成长跃水化为 `天4（吞天长蛇）` → 高空横扫捕食成群 `天2（无脸红囊）`；`天1（长须鸟）` 绕树冠兜圈。
- **河湖共生链**：`水4（巨龟）` 背上住着做窝的 `水2（衔石小鸟）` 与躲在水草里的 `水1（尾手水兽）`；深潭里 `水5` 追逐 `水3（一头十身鱼）`。
- **冰海与环礁**：`海3（岛屿巨怪）` 浮起吐食糜引来成群 `海4（翅鲤）`；`海1（狼鲸）` 沿冰缝巡猎；`特7（潮汐海妖）` 与 `特5（滩涂鱼人）` 守在浅海与滩涂。
- **林地与花甸**：`地2（植物羊）` 养活 `地1（肚嘴巨兽）` 与 `地3（五尾红豹）`；`地4（空心角瞪羚）` 与 `特3（林间妖精）` 共享花丛草甸；`树3（伸缩巨兽）` 走过之处长出 `树2（走果巨树）`。
- **沙漠与溶洞**：`沙3（枯竭独目牛）` 扩大沙域喂养 `沙2（吞铁兽）`；`洞2（岩壁巨蛇）` 掉鳞喂养 `洞1（猫头蛇）`、`洞4（拼骨幼虫）` 与 `特2（洞窟翼蝠）`；`泽1（破土牛犊）` 与 `特1（史莱姆）` 栖息沼泽泥潭。

## 五、逐只精制推进路线建议

建议每次只专注精制 **1 只**（做完进浏览器实看旋转细节、满意再下一只），推荐顺序：

1. **第一批 · 精制标杆重塑（先立画质标杆）**：
   - `地1 · 肚嘴巨兽`（重雕红毛大地懒比例、小头+竖裂肚嘴+反脚掌+四足/直立双态）
   - `水3 · 一头十身鱼`（重雕饱满大鱼头+10 条细腻雄鱼身+搅泥生态）
   - `天2 · 无脸红囊`（重雕半透红囊群落质感+6 条细腿+4 片薄膜翅）
2. **第二批 · 高辨识度中小生物**：`水1（尾手水兽）` → `海1（狼鲸）` → `地3（五尾红豹）` → `树4（吐火竹鸡）` → `洞1（猫头蛇）`
3. **第三批 · 奇观级大体型与变形机制**：`树3（伸缩巨兽）` → `海3（岛屿巨怪）` → `水4（背上住生态的巨龟）` → `沙2（吞铁渐大兽）` → `洞3（单腿雷牛）`
4. **第四批 · 全图鉴补齐与 8 只既有怪精制升级**：依次补齐其余图鉴生物并把 8 只既有怪按同等精度升级。
