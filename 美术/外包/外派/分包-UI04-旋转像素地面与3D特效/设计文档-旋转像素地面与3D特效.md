# 设计文档：UI-04 六生态可旋转像素地面与 3D 像素战斗特效（`Code00ArtPacks.groundVfx`）

## 一、核心痛点与视觉目标（彻底终结 2D/3D 割裂感）

- **旧版问题**：
  - 旧地面是 `1920×1080`（8.3MB）的平滑 2D 矢量草地墙纸，既吃显存又无法跟着 3D 镜头角 `th` 旋转，且残留了大量 2D 假树/假帐篷/假石门，与工坊 3D 像素堆叠角色严重割裂；
  - 旧战斗特效（`attack-fx.js` 与 `bolts`）全是平滑 2D 矢量圆球、贝塞尔弧线、软边 `shadowBlur`，不仅画风割裂，还无法跟 3D 旋转视角联动。
- **重做目标（100% 像素统一 + 360° 丝滑旋转 + 120fps）**：
  1. **8 套无缝/大视野可旋转像素地面纹理（`384×384` 像素原图，单套约 0.56MB，总计 ≤ 6MB）**：
     - 像素质感与工坊 `./core/habitats.js` 同源（逐像素/块面像素绘制，`imageSmoothingEnabled = false`）；
     - **严禁画圆形展示台边框，严禁画任何 2D 树/帐篷/石门/石碑/树洞**（那些立体物体全由工坊 3D 像素模型摆上去！地面只负责铺地貌纹理、路面、水洼、碎叶、青苔、木纹）；
     - 边缘像素与中心色系过渡自然，支持 `WorldStage` 以 3D 仿射矩阵 `(c*SC, TILT*s*SC, -s*SC, TILT*c*SC)` 旋转压扁铺满 16:9 全屏而不穿帮、不露白边！
  2. **全部微粒与战斗特效升级为「3D 世界坐标驱动的硬像素特效」**：
     - 所有位置均从 3D 世界坐标 `[wx, wy, wz]` 经调用方传入的 `proj(wx, wy, wz) -> [sx, sy, depth]` 映射到屏幕（坐标系约定：1 格体素对应工坊世界 1 单位，主角通常在 `(0, +30, 0)`，怪在 `(x, -26, 0)`，屏幕投影 `TILT = 0.6, HS = 0.8`）；
     - 无论玩家把视角旋转到任何角度，生态落叶/火屑、主角七色宝石弹丸、补色合白环形波、彩虹爆发、破盾碎晶、8 只怪各自出手特效，**全部随着 3D 空间同步透视旋转**，且全由硬边像素块/阶梯像素菱形/像素裂纹构成，和堆叠模型 100% 同一画风！

## 二、8 套可旋转像素地面规格（`buildGroundTile`）

色板直接对齐 `./core/habitats.js`（可用 `./core/math.js` 的 `periodicNoise2` 生成像素级自然噪点与有机斑块）：

| `biomeId` | 场景名 | 像素地貌画法要求（严格像素风，零 2D 假摆件、零圆台） |
|---|---|---|
| `forest` | 落果浅林 | 深翠 `#24472c` / 苔绿 `#34663c` / 亮草 `#4b8046` 交错像素草皮、踩踏浅泥小径印、点缀零星像素碎叶与几颗微小红果点 |
| `swamp` | 泽畔浅洼 | 湿褐泥地 `#243826` / 暗泥 `#1b2a1e` 与藻绿浅水洼 `#2f5a58` 像素岸边交错，水洼边缘带浅青像素水纹与 2~3 像素浮萍点 |
| `meadow` | 花甸林隙 | 明快春草坪 `#488244`~`#6ca856` 像素绒草地，散落精致 3×3 像素粉白/暖黄小花丛与踩出的柔和土路纹理 |
| `ruins` | 苔石古径 | 错落拼缝的青灰古石板 `#404a48`~`#5d6966` 像素方砖，石板带 1px 亮顶边与暗裂纹，石缝间爬满厚青苔 `#5a8756` 与零星浅水渍 |
| `canopy` | 巨木树冠 | 宽阔沧桑的巨枝木皮平台 `#3d281b`~`#61412b`，清晰像素木纹年轮沟壑与零星青苔斑，四缘略向深绿叶海 `#1e4526` 过渡 |
| `camp` | 林间营地 | 傍晚压深草坪 `#1c3a26`~`#2c5236`，中央 `(0, 0)` 附近是一块踩实的灰褐篝火土圈与零星炭灰石子（不画假石头和假火堆，3D 营火会直接站在中央！） |
| `trade` | 林间土路 | 压实暖褐黄土大道 `#6a573a`~`#8a7650` 伴像素车辙双痕，两侧衔接林缘绿草与碎石（不画假帐篷和假路牌！） |
| `gate` | 青石林道 | 青灰铺石大道 `#465650`~`#566660` 沿 Y 轴延伸，石缝嵌厚青苔，两侧为暗林草地（不画假石门！） |

## 三、3D 像素战斗特效与微粒规格

### 1. 生态 3D 像素微粒（`drawGroundAmbient3D`）
- `forest`：缓慢斜飘的 2~3px 像素绿/金落叶 + 偶有 1 颗红果在边缘落弹；
- `swamp`：水洼上空升起像素小泡与贴地压扁像素涟漪环 + 极淡像素雾带；
- `meadow`：飘浮的 2px 暖金像素花粉；
- `ruins`：缓升的淡青苔孢像素点与细白暖汽像素块；
- `canopy`：斜掠过空的像素风线与疾飞碎叶（速度乘 `wind`）；
- `camp`：围绕中央 `(0, 0)` 螺旋升腾的暖金/橘红像素火屑；
- `trade`：低空轻飘的暖色像素浮尘；
- `gate`：沿石门附近飘落的青苔像素细屑。

### 2. 主角施法与爆发 3D 特效（`drawSpellBolt3D` / `drawImpactWave3D`）
- **`drawSpellBolt3D(ctx, bolt, proj)`**：
  - `bolt = { from: [wx,wy,wz], to: [wx,wy,wz], k: 0..1, art: 'red'|'green'|'blue'|'white'|'rainbow', big: bool }`；
  - 沿 3D 抛物微弧飞行：前方是一颗带暗描边与亮心的**多面体像素晶弹**，身后拖着 4~5 节递减大小的像素方格星屑尾迹（`rainbow` 时尾迹逐节变七色）。
- **`drawImpactWave3D(ctx, kind, centerW, k, proj)`**：
  - `white_wave`（补色合白）：以 `centerW` 为中心贴地扩开的像素白色菱环 + 四散像素星晶；
  - `rainbow_burst`（彩虹爆发）：三道错相扩开的七彩阶梯像素环 + 向上迸溅的七色像素方块雨；
  - `shield_shatter`（破盾碎晶）：12~16 片带高光边的青白菱形像素护盾碎片按 3D 重力抛物线四溅落地；
  - `ward_block`（护壁格挡）：主角身前展开六边形青白像素盾阵并弹开火星。

### 3. 8 只怪专属 3D 像素出手特效（`drawAttackFx3D(ctx, kind, k, fromW, toW, proj)`）
1. `spit`（水滴软泥）：3D 抛物线蓝绿像素水团，落地炸开 8 颗重力像素水滴与贴地像素水环；
2. `puff`（草茎绵羊）：沿 3D 直线滚涌一串像素白绒毛团，命中迸出十字像素撞击星芒；
3. `club`（拾荒地精）：目标头顶像素木棒重砸轨迹弧 + 地面震开像素碎石与裂纹；
4. `petals`（花甸灵精）：9 片粉白像素花瓣沿 3D 螺旋轨飞向主角；
5. `fruit`（摇果长臂猿）：高弧抛掷带绿蒂的像素大红果，砸中主角炸开深红像素果汁花；
6. `claw`（五尾赤豹）：主角身前斜劈出三道带白芯的灼红阶梯像素爪痕；
7. `bite`（腹口懒兽）：上下两排硬像素尖牙在主角 3D 位置猛然合拢并迸出像素星点；
8. `roots`（千丈古树精）：4~5 根粗壮棕褐像素尖刺树根从主角脚下地面破土窜出，四周飞起泥土像素块。

## 四、技术硬红线与精确导出接口

**全局登记**：
```js
window.Code00ArtPacks = window.Code00ArtPacks || {};
window.Code00ArtPacks.groundVfx = {
  id: 'groundVfx', version: 1, name: '...',
  BIOME_IDS: ['forest', 'swamp', 'meadow', 'ruins', 'canopy', 'camp', 'trade', 'gate'],
  init, buildGroundTile, drawGroundAmbient3D, drawSpellBolt3D, drawImpactWave3D, drawAttackFx3D
};
```

- **零 `ctx.filter`、零 `shadowBlur`、零外部图片/字体 URL、零禁用字**；
- **`buildGroundTile(biomeId, makeCanvas, size = 384)`**：
  - 返回 `{ canvas, size, biomeId }`，**内部按 `biomeId + '_' + size` 做缓存复用**（多次调用同一生态不重复新建画布！）；
  - 全部 8 套地面缓存合计内存严格 `<= 6 MB`（建议默认 `size = 384`，8 套总计仅 `4.5 MB`），单套构建耗时 `<= 30 ms`；
- **状态整洁与无 NaN**：所有绘制结束必须 `restore()`，关平滑 `imageSmoothingEnabled = false`，任意 `k ∈ [0, 1]` 零报错零 NaN。
