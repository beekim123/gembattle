## 二、怎么做出异世界的感觉

**动作像真的，其余不像地球。** 几个办法，设计每只时至少用上一条：

- **换材料**：身子是盐壳、陶土、纤维、气囊、薄膜做的，但走起来像动物。
- **换角色**：吃草的大家伙本身就是别的生物的家；猎手反而一动不动；最小的东西撑着整个生境。
- **每个生境一条怪规矩**：只有那里才有的生态现象，比如戈壁沙丘里有骗人的假水洼。
- **它为什么长这样**：长相要能用它的生活讲通（为什么背是水的颜色？因为要骗来喝水的），不为好看硬加。
- **避开**：地球动物直接放大（巨蜈蚣、巨蟹、巨蜗牛）；奇幻老一套（元素精灵、发条机器人、三头犬、宝箱怪）。

## 六、core 要先加的三样（另加一个小开关）

先查过现在的渲染器：部件只能绕竖轴转（`ro`），按朝向烘焙，**不能前后翻、不能左右侧倾**；没有画线的；地上的效果只有粒子、涟漪、水花、扬尘、尾浪，**没有能留住的印子**；描边是整只一起描的。

1. **地表痕迹层**：贴地、慢慢褪掉的印子（沟、隆起、黏液、霜、焦痕、枯黄、地上的网），用环形缓冲、数量封顶，不另开整屏大的画布；印子也可以变成摆件（嫩芽、蘑菇、石板）。要用的：M18、M20 地网、M22、M37，还有图鉴里的 沙1（沙垄）、沙3（走过变荒）、泽1（水沟）、树3（冒芽），后两只现在是各自手写的。
2. **画线**：1 个美术像素宽、按整数屏幕像素对齐、参与深度排序、能下垂成弧、能抖。要用的：M20 的丝、M26 的细腿（可选）、M36 拴在宿主身上的。
3. **挂到别的生物身上**：一只生物能从 `eco` 拿到别的生物的挂点（`SocketTracker` 已经有），停上去以后位置和朝向跟着宿主。要用的：M30、M36，还有 沙4 的斑鸠、水4 背上的住客。
4. 小开关：**每个部件能不描边**。M33 的散粒、M37 的薄膜要用。

### 第一批的模板卡

#### M18 钻地 / 破土拱行

1. **归不归**：身子大半在地下（沙、泥、土、冰下），地面上只看得见隆起、沙浪、裂纹在移动；时不时拱出一段，或者整条跃出再钻回去。不归：全身在地面上的蛇（M04）；只露一点、出来以后换成别的走法的双态生物（泽1 归 M07）。
2. **拆件**：体节链（`ChainSolver`），每节一个部件，相邻重叠 40%~45%；前端（铲头 / 口器）单独一件；地面隆起用痕迹层，加几块土块部件。
3. **状态机**：地下潜行，只有隆起在动（3~10 秒）→ 弓背拱出一段（1~2 秒）→ 钻回；偶尔整条跃出，抛物线 0.8~1.2 秒，落地扬沙 → 扎回 → 地下潜行。
4. **参数和红线**（沙1 标杆实测）：
   - **体节链与重叠**：9 节体节链（前后对称复用 1 套铲头件 `capEnd` + 2 套交替环体节 `segMain`/`segCrease`），单节轴向长 9.6 格、节距 `SEG_LEN = 5.4` 格，**相邻节重叠率 43.75%**（安全区间 40%~45%）；`ChainSolver` 最大折角 `0.44 rad`。
   - **潜行 / 拱出 / 跃沙高度**：地下隐藏深度 `-4.2` 格，露出绘制阈值 `z > -0.8` 格；弓背拱出跨距 `19.5` 格、拱高 `10.6` 格（稳定露 3~5 节鲜红环躯）；整条跃沙跨距 `30` 格、抛物线峰值 `21.5` 格；潜行时长 `3.2~6.2s`、拱出 `1.75~2.45s`、跃沙 `0.95~1.25s`。
   - **切口零露缝层序**：半露底节（`lift < 2.8`）`bias = -0.35`，破土/钻入土垄件（`moundLarge`，四重对称 `symDeg: 90`）`bias = +0.25`，高拱体节 `bias = +0.55~+1.00`，360° 旋转切口被土垄严密包覆。
   - **贴图与颜色实测**：全怪 5 个轻量资产、20 色 0 重色 0 自亮，4 套零重建模换色皮肤；满 360° 旋转烘焙图集实占 **2.50 MB（3 页 / 28MB 预算）**；地表痕迹层（`VFXPool.decals`，上限 220 条环形缓冲）直接绘入 `gbuf`，0 额外贴图预算；Node 45s 全周期仿真 0 NaN、3 态完整闭环。
5. **渲染**：只画露出地面的节；露出一半的节用土垄部件盖住切口。也可以试试把 `submerge`（浸水染色）推广成「埋进沙里染成地面色」，要改渲染器，先试再定。
6. **生态**：挂「留痕改地表」「受惊连锁」（地面一拱，附近的东西跳开）。吃食已在生态设计数据中暂定为沙下草根（待终审确认）。
7. **标杆**：沙1。
8. **变体旋钮**：在什么里钻（沙 / 泥 / 土 / 冰下）、露出什么（背板 / 一圈触须 / 什么都不露）、几只（一条 / 一群）。下面三只只是示例，还没跟用户定：

#### M19 装成静物 / 折起再展开

1. **归不归**：平时一动不动，形状装成环境里的东西（地面、石堆、水洼、花苞），被触发才展开出手。不归：本来就扎根不动的（M10）；不变形、只是趴着突然弹出去的（M27）；能边走边装的（M38 翻面）。
2. **拆件**：
   - 伪装面：背上那一层，装成环境的样子，薄（2~3 层）、大；
   - 卷边：伪装面四周拆成 4~8 片能抬起的边，每片一个部件，各自锁死枢轴；
   - 藏起来的：口、腿、眼，展开前全在伪装面下面（bias 偏负），展开后才露出来；
   - 体素盒：中体型，宽 36~60 格，高只有 3~8 格。
3. **状态机**：伪装，偶尔微颤一下（8~20 秒）→ 察觉，有东西进了范围，绷紧（0.3~0.6 秒）→ 出手，卷边抬起包住（0.2~0.4 秒）→ 吞下，合拢，能看见里面鼓起来（1~2 秒）→ 复原，慢慢摊平（3~5 秒，这时候伪装最差，是破绽）→ 伪装。很久没东西来，就极慢地挪一小段换地方，像地面在动。
4. **参数和红线**（沙6 标杆实测，`creatures/sand6_mirage_pool.js`）：
   - **部件与防爆策略**：中心薄盘 `poolDisc`（30×30×4，`symDeg: 45`）+ 8 片共享卷边（3 档姿态 `flapFlat` / `flapHalf` / `flapClosed`，16~18 格）+ 鼓动包 `digestBulge` + 钩圈 + 眼柄 + 极简来喝水配角，共 9 资产、单帧峰值 21 部件；水面波纹用 `vfx.addRipple` 叠绘。
   - **伏击流程与色板**：直接调用 `PW.Behaviors.createAmbushCycle`（6 态闭环，配角触发 `fsm.trigger()`）；3 套皮肤 0 重色；60s 全态仿真 0 NaN，挪位 `peakR = 39.9 < 48`。
5. **渲染**：伪装面薄，烘焙最省；「包起来」靠卷边的 `lift` 和 `ro`，不靠翻转（翻不了）。
6. **生态**：伏击。挂「伏击流程」（跟 M27 共用：等 → 被触发 → 出手 → 复原）、「觅食」（引什么东西过来）、「受惊连锁」（出手时周围一圈惊散）。

8. **变体旋钮**：伪装面装成什么、卷边几片、怎么掀（四边卷 / 整块掀 / 一块块翻起）。同类变体（审的时候的另外两个候选）：
   - **一小片假草地**（花丛草甸）：扁身子背上长着真的草和小花，趴着是草地上鼓起的一块；有东西来啃草，整块掀起，下面一圈嘴把它合进去；吃饱了挪到太阳底下晒背上的草，背上的花也给虫子采。

### 第 2 块（2026-11-24 提给用户）：M35、M36、M37 的标杆

每类三个候选，各补一个生态空格。

**M35 一层层拆开 / 在别处拼回来**

- **A. 一摞薄片**（雷云峰顶 · 吃草 + 播种）：十几片薄圆片叠成一根柱子，片和片之间有空隙，风一吹各片轻轻错开晃。片缝里夹住风吹来的种子和孢子，那是它吃的。打雷前后它一片片散开飘走，在别处一片片落下叠回去，散的时候撒下一些种子。
- **B. 留下一层再走**（熔岩火山口 · 改地形）：矮壮，外壳像冷掉的熔岩一层层叠着。它从不走路：要换地方，就从脚底一层层沉进地缝，过一会儿在另一条地缝里一层层冒出来，刚冒出来的上面几层还红热，慢慢变黑。每次走都把最底下一层留在原地，冷成一块石板。火山口能落脚的地方，就是它一块块留下的。
- **C. 一层层浮上去当筏子**（浅海环礁 · 驮着别的）：平时一层层叠着趴在礁底。涨潮时一层层浮到水面，摊成几张筏子，小鱼躲在下面；退潮前再一层层沉回去叠好。层在水里深浅不同，染的水色也不同，一眼看得出分层。

**倾向 B**：火山口最空（只有 特8）；「留下一层变成石板」是看得见的生态痕迹；从下往上一层层吞进地里、再从下往上冒出来，拆层动作最完整。A 写进模板卡当变体；C 也可以留给以后环礁用。

**M36 挂在别的生物身上**

- **A. 给大家伙啃死皮的**（林地、戈壁 · 清洁共生）：小小的、扁扁的，一群趴在大家伙（地1、沙4 这类）背上，啃它身上的死皮和小虫。大家伙会主动停下来让它们上下；一只大家伙啃干净了，它们就下地等下一只。
- **B. 长在别人身上的花**（林地、花甸 · 寄生 + 播种）：种子粘在路过的生物背上，长成一丛花，从宿主身上吸养分；花熟了，宿主走到哪就把种子撒到哪。宿主会去蹭树、蹭石头，想把它蹭掉。
- **C. 拴在大鱼身上被拖着走的**（河湖深潭、远洋 · 搭车）：咬住一条大鱼（水5、海1 这类）不放，用一根细长的身子拴着，被拖着到处走；大鱼吃东西时，它吃掉下来的碎渣。

**倾向 B**：一份资产能长在任何一只生物身上，最能说明「挂到别的生物身上」这个模板；寄生和播种两个空格一起补；「那只犀牛背上开了花」一眼就看得出生态。A、C 写进模板卡当变体（C 要等画线）。

**M37 铺开的菌毯 / 网**

- **A. 朝死东西长过去的网**（地下暗河溶洞 · 分解）：平时缩成一小块。地上有死掉的东西（别的吃剩的），就朝那里一条条长出脉络，把它盖住、慢慢化掉，再缩回去，原地留下一圈小蘑菇，洞3、洞4 可以吃。
- **B. 沙上的一层皮**（戈壁沙丘 · 改地形）：下过雨或起雾以后在沙上铺开一层薄皮，把流沙定住，种子才长得出来。被踩碎的地方留下脚印，要好一阵才长回来。
- **C. 地下连着植物羊的网**（林地落果空坪 · 分解 + 供养）：在地下连着一只只 地2，脉络里一跳一跳地往外送养分；哪片草被啃秃了，网就往那里送，草慢慢长回来。

**倾向 A**：补「分解」最直接；长出、盖住、化掉、缩回、留蘑菇，动作完整；给溶洞的食物链加了一环。B、C 写进模板卡当变体。
