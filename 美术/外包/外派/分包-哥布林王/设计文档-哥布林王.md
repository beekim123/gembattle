# 设计文档：第二个大 Boss · 哥布林王（`boss_goblin_king`）

- **资产 ID**：`boss_goblin_king`
- **定位**：部落型蛮横大 Boss（归属 `T09 林地落果空坪` / `T16 苔藓古石遗迹` 营地），与前作普通「苔绿哥布林」血脉同源，但体型放大至 **Boss 级宽厚壮硕体态**，兼具「贪财滑稽」与「蛮力暴君」的反差气场。
- **技术底座**：纯原生 JS + Canvas 2D，100% 调用本包自带 `./core/`（`PW.Math`、`PW.Voxel`、`PW.Solvers`、`PW.Behaviors`、`PW.Renderer`、`PW.Assets`），严禁修改 `./core/`。
- **坐标约定**：`+Y` 为正前方，`z = 0` 为地面，渲染器常数 `TILT = 0.6`、`HS = 0.8`、`BAKE_SCALE = 2.5`。

## 一、外观与四大标志记忆点（0.6 俯视角一眼认出「暴君王者」）

必须严格执行**「体貌特征放大 + 高对比 3 档色阶 + 独立 `partId` 切暗缝」**：

1. **歪戴的巨型嵌宝石锯齿金冠（`crown`）**：
   - 金灿灿的大锯齿王冠，冠额正中并排镶嵌**红、绿、蓝三颗大宝石**（呼应游戏三原色宝石机制！）；
   - 平时微微歪斜在脑门上随步伐轻晃，施法蓄力时宝石脉动，破盾硬直（`stagger`）时歪弹一下再滑回脑门。
2. **狞笑大头 + 超长横展双尖耳 + 獠牙大嘴（`head` + `earL`/`earR`）**：
   - 继承 `./references/goblin.js` 的苔绿肤色与黄橙邪眼（`eyeGlint` **绝不进 `glowKeys`**，确保 0.6 俯视角 0 遮挡、锐利不糊）；
   - 宽阔下颚露出两颗雪白上翘大獠牙；一对超长横展大尖耳（带金耳环）偏心锁死耳根枢轴，大笑、蓄力、受击时独立狂抖或耷拉。
3. **满溢金币与宝石的赤红王者披风 + 巨型黄金大宝袋（`cape` + `lootSack`）**：
   - 宽厚圆鼓的大肚腩，裹着带金边皮带的皮革战裙与厚重赤红大披风；
   - 背后背着一只鼓胀到快撑破的巨型黄金宝袋，袋口堆满金锭与红绿蓝晶石，行进时滞后颠簸并偶尔颠落金色碎粒。
4. **右手超巨型镶金狼牙重锤（`mace`）+ 粗壮二足重步**：
   - 双臂拆为**大臂 + 小臂**两段连续 FK 驱动（小臂滞后随动），右手紧握一把黑铁镶金刺狼牙重锤（柄根用 `pivotToWorldXY` 严格锁死在右手腕枢轴，挥砸零脱节！）；
   - 粗壮短腿深嵌战裙与大肚腩下方（遵循 `goblin.js` 防身腿分离铁律：腿根上延深嵌躯干 `≥ 3` 格、收拢步距、限制脚部最大偏移半径），迈步沉稳厚重。

## 四、动作清单与 4 大 Boss 技能演出 + 战斗机制设计

在 `Def.actions` 中登记全部 7 个动作，由 `eco.action` 与 `eco.actionTime` 连续驱动，`loop: false` 播完自动平滑归位：

```js
actions: [
  { id: 'patrol',            name: '霸道巡营',   loop: true,  status: 'done' },
  { id: 'idle',              name: '叉腰狞笑',   loop: true,  status: 'done' },
  { id: 'stagger',           name: '破盾歪冠',   loop: false, duration: 1.5, status: 'done' },
  { id: 'skill_mace_smash',  name: '霸王重锤',   loop: false, duration: 2.4, status: 'done' },
  { id: 'skill_gold_rain',   name: '撒币乱砸',   loop: false, duration: 2.8, status: 'done' },
  { id: 'skill_rally_horde', name: '摇旗召众',   loop: false, duration: 3.0, status: 'done' },
  { id: 'skill_greed_charge',name: '贪财蛮冲',   loop: false, duration: 3.2, status: 'done' }
]
```

### 技能 1：`skill_mace_smash` · 霸王重锤（时长 `2.4s`）
- **视觉演出**：
  - `0.0s ~ 0.85s`（高举蓄力）：整只后仰蓄劲，右手抡起巨型狼牙重锤高举过顶，锤头 `emissive` 脉冲亮起，双耳向后紧贴；
  - `0.85s ~ 1.45s`（重步猛砸）：大步前跨 `+5` 格，重锤沿清晰弧线狠砸前方地面，瞬间爆出 `vfx.addDecal` 裂纹焦痕（`kind: 'crack'`）+ 环形震波与飞溅碎石粒子；
  - `1.45s ~ 2.4s`（拔锤喘气回位）：用力把锤从地面拔起扛回肩侧，大步退回原位。
- **对应 code00 战斗机制**：重击扣主角 1 颗心（可被破盾推迟倒计时或打断）。

### 技能 2：`skill_gold_rain` · 撒币乱砸（时长 `2.8s`）
- **视觉演出**：
  - `0.0s ~ 0.6s`（反手抓宝 + 狂笑）：左手叉腰挺肚大笑（头仰、双耳高频狂抖、王冠乱晃），右手伸向背后大宝袋抓出一大把金块；
  - `0.6s ~ 2.1s`（漫天抛洒）：连续向正前方扇形抛射 **6 枚立体 `goldChunk` 金块**，各自沿不同高度抛物线落地弹跳 2 次并溅出金色粒子碎屑；
  - `2.1s ~ 2.8s`（拍肚得意归位）：拍两下圆鼓肚皮，重锤回手。
- **对应 code00 战斗机制**：扣半颗心并往弃牌堆塞入 1 张「沉重假币」废牌（同时暂夺少量金币，击杀哥布林王后双倍奉还！）。

### 技能 3：`skill_rally_horde` · 摇旗召众（时长 `3.0s`）
- **视觉演出**：
  - `0.0s ~ 0.9s`（高举战旗狂摇）：左手猛然擎出巨型赤红 `warBanner` 部落战旗左右大幅挥舞，头顶扩散出 2 道醒目红色声波粒子环；
  - `0.9s ~ 2.4s`（双喽啰窜出冲锋）：左右两侧尘土扬起，窜出 **2 只复用 `minionGoblin` 迷你喽啰**，绕着哥布林王前方高跳碎步冲锋挥棒呐喊；
  - `2.4s ~ 3.0s`（收旗退场）：喽啰跃回尘烟消散，哥布林王收起战旗恢复持锤警戒。
- **对应 code00 战斗机制**：召唤 2 只低血哥布林喽啰并给 Boss 补 2 格色盾，逼玩家用**补色合白**或**彩虹**一波清场！

### 技能 4：`skill_greed_charge` · 贪财蛮冲（时长 `3.2s`）
- **视觉演出**：
  - `0.0s ~ 1.05s`（低身刨地蓄势）：身体大幅前倾压低重心，重锤横抱胸前，双脚原地急促踏地扬起浓尘，王冠三色宝石与锤头高频亮脉冲；
  - `1.05s ~ 2.15s`（重坦蛮冲 + 沿途掉币）：整只向前猛冲 `+18` 格，身后留下泥土犁痕（`vfx.addDecal` `mound`）且大宝袋剧烈颠簸甩落一串金色粒子；终点猛然横扫一记大回旋重锤！
  - `2.15s ~ 3.2s`（挺肚慢步回位）：得意洋洋挺起肚腩、大步走回原位。
- **对应 code00 战斗机制**：蓄力 2 回合的终极大招（亮出红+蓝双色护盾 5+5 格），击破双色盾立即打断冲锋并触发 **`stagger`（破盾歪冠）**！

### 通用硬直：`stagger` · 破盾歪冠（时长 `1.5s`）
- 整只向后踉跄下沉 `2.5` 格，头顶巨型金冠猛然歪飞弹出 `4` 格再扣歪回脑门、大宝袋颠出金色粒子、双尖耳耷拉发抖，`1.5s` 后气急败坏伸手扶正王冠恢复警戒。
