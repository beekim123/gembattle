# 外派与扩展美术交付收口目录（总工坊母库）

本目录隶属于 **总资产母库** `美术/像素堆叠生物工坊/`，用于统一归档所有外派或新增的 UI 皮肤、特效图集、图标包与外部美术交付包（例如后续的 `UI-01` ~ `UI-04`）。

## 美术双库交付铁律

1. **优先进总工坊**：凡是新交付或修改的美术资产（含怪物、NPC、场景、建筑、UI 皮肤/特效包），一律先放进 `美术/像素堆叠生物工坊/`（本目录或对应脚本目录）作为唯一真源归档。
2. **游戏用到再同步**：只要该资产在游戏实装库里用到了（或新决定进游戏），就同步放一份进 `美术/游戏实装美术库/`：
   - 体素模型 / 场景 / NPC / 建筑：登记进 `美术/游戏实装美术库/manifest.json`，运行 `node 美术/游戏实装美术库/tools/sync-from-workshop.js` 单向同步；
   - UI 外派包（`UI-01` ~ `UI-04` 等）：验收通过后同步拷贝至 `美术/游戏实装美术库/art-packs/`。
3. **不提交 Git**：按项目 `CLAUDE.md` 规范，整个 `美术/` 目录不提交 git。
