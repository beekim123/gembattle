# code00（暂名）

俯视的卡牌肉鸽，探索方式学哈迪斯。异世界的寻宝冒险家在工会接任务，进森林、遗迹一片一片往里走，用红绿蓝三色宝石按色环接链打仗，带着东西活着回来交任务、换金币、买装备、雇队友，再出发。

- 技术：Electron + 原生 JS + Canvas 2D，不用引擎和 3D 库。
- 现在是**原型阶段**：画面只用色块，什么都不取名。正式美术以后用俯视像素堆叠来做。

## 目录

| 位置 | 是什么 |
|---|---|
| `CLAUDE.md` / `AGENTS.md` | 接手的人先看：规矩和读的顺序（两份内容一样，给不同的模型看） |
| `进度.md` | 开头「现在」：做到哪、下一步、要注意什么；后面「记录」：每一步一行 |
| `设计/设计.md` | **正式设计稿**：只写现在定成什么样，按系统分节，审核和开工都看这份 |
| `设计/讨论记录.md` | 设计的过程记录：每一步怎么跟用户对的、没选的方案和原因。2026-11-23 起不再往下写 |
| `审核/` | 别的 AI 的审核结果，一个审核者一个目录（`neon/`、`claude/`）。规矩在 `审核/README.md`，给审核者的提示词在 `审核/审核提示词.md` |
| `原型/` | 以后的原型代码，一个做的人一个目录，可以几种 AI 各做一份横向对比。规矩在 `原型/README.md` |
| `旧/` | 隔离开的旧东西，只当参考。`旧/美术样片/` 是以前看美术效果的样片（代码、美术、工具、旧设计），能单独跑，以后做正式美术时回来参考 |

## 读的顺序

1. 这份 README；
2. `CLAUDE.md`（规矩）；
3. `进度.md` 的「现在」；
4. `设计/设计.md`；
5. 想知道为什么这么定，再翻 `设计/讨论记录.md`。

`旧/` 平时不用看。

## 跑以前的美术样片

```bash
cd 旧/美术样片 && npm install && npm start
```

也可以双击 `旧/美术样片/启动.command`。说明见 `旧/美术样片/README.md`。
