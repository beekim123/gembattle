## 一、任务指令模板（可直接复用）

```markdown
你要用“像素堆叠（Sprite Stacking）v3 模块化骨骼方案”为我制作：[填写主题，如：双形态赤翼飞龙 / 滩涂鱼人战士 / 林间妖精仙子]。

请严格按以下工程与美术规范执行，不要跳步：

### 第 0 步：先写「模块化部件预算表与关节净空表」
在写任何体素代码前，先把生物拆解为轻量模块化体素部件（严禁做 6~8fps 僵硬整块翻页动画！），列出每个部件的：
- 盒尺寸 W × D × H（原点在水平中心，正面统一朝向 +Y）；
- 局部关节锚点 / 旋转枢轴（如颈口、肩部、翼根、尾尖、武器握把）；
- 防穿模净空约束（例如裙摆/披风/甲片底沿 Z 必须严格高于下方摆动尾根或肢体，确保 360° 零穿模）；
- 若存在俯身游泳/冲刺/飞行俯冲等大倾角姿态，单独用绕 X 轴倾倒 SDF（pitchPt）构建流线姿态部件，不要生硬 2D 拉伸。

### 1. 投影、格式与旋转满帧渲染管线规范（120fps 铁律）
- 俯视角参数：地面沿 Y 轴压扁 TILT = 0.6，每层抬高 HS = 0.8，严禁平滑（imageSmoothingEnabled = false）。
- 资产存储格式：每部件打包为**单张长条图集**（宽 = W × H，高 = D，z = 0..H-1；alpha 严格仅允许 0 或 255；统一色表 ≤ 48 色且零重色；自亮色键与普通色键物理隔离），严禁每层建独立 <canvas>。记录 activeLayers / glowLayers 跳过空层。
- **定倍角度烘焙缓存（Sprite Cache）**：
  1. 固定黄金倍率 BAKE_SCALE = 2.5（0.8 × 2.5 = 2.0 精确整数步进 + 1px 半步压实防百叶窗漏缝），按 3° 量化 + LRU 缓存，滚轮缩放不清空缓存；对称小部件声明 symDeg = 90 共享缓存；
  2. 零 GC 分配：全局复用 2 张 scratch 临时画布，LRU 淘汰画布回收到 canvasPool 对象池；
  3. 局部整体外轮廓（actorBuf，除强鳞节蛇类外必用！）：裸部件按 wantOutline = false 缓存 → 每帧在紧凑局部缓冲 actorRaw（如 240×246，预留最高抬手/最远摆尾边距零裁切）内按 3D 深度拼合 → 对 actorRaw 做 1 次 1px 整体外轮廓 → 单次贴回 dctx。保证内部光滑融合无拼装黑缝、与场景靶桩轮廓清晰分离、全程 120fps；
  4. 消除全屏 Overdraw + 真 1/4 降采样柔化：天空预渲染到 bgc；地面/投影/水纹全合成进 2× 小地表缓冲再 1 次贴图；自亮层从 minGlowZ 起做 destination-out 遮挡裁切，并在 1/4 尺寸独立小画布 ebctx 上执行 filter=blur（严禁在全屏主画布 dctx 上设 filter）。

### 2. 高性能体素建模与零重建模一键换色
- 性能铁律：网格用 Uint8Array 存色表索引与 partId；各部件通过 fillAABB / paintCapsule / paintEllipsoid / paintFinTri 局部遍历，全套部件总建模耗时目标 < 35ms。
- 垂直明暗（严禁左右方向明暗）：单材质 3 档高对比色阶，组合「露边提亮 + 上方 3×3 腔体 AO + 白名单过滤部件暗缝（Crease AO，对眼睛/亮核/躯干接缝免压暗）+ 部件局部归一化高度」。细结构半径 ≥ 1.05，薄鳍/翅膜 halfThick ≥ 1.05，最后执行 despeckle(protectedParts)。
- 零重建模换色（SKINS）：toStripAsset 保留原始索引数组 grid；切换色系时调 recolorAsset (< 2ms 重刷长条 + 仅清理该角色在 spriteCache 中的条目)，严禁重跑 SDF；全部技能特效、拖尾、地面残留与导出 PNG 同步联动当前色系。

### 3. 120fps 连续运动学、物种真实生态与环境嵌入
- 双常驻生态（快捷键 S 切换）：
  1. 原地鲜活待机：呼吸起伏、摆尾/振翅/飘发/探头顾盼/武器小动作全程连续驱动；
  2. 物种真实巡游（拒绝“浮空平移物体”！）：按真实生物推进规律运动——如水生生物用「俯身流线泳姿 + 脉冲摆尾加速滑行（Burst-and-Glide）+ 波浪潜浮 + V 形尾流」；飞行生物用「下拍提速与滑翔起伏 + 盘旋压弯」；陆行生物用「步态弹跳/碎步 + 落地尘土」；软体用「体积守恒 Squash & Stretch + 内核弹簧滞后」。
- 关节防脱节与防穿模：
  - 链式部件（尾/颈/长发/触须）使用行进波 + Follow-the-Leader 约束（relaxChain）+ 指数平滑（1 - Math.exp(-dt * k)）；
  - 偏心末端部件（尾鳍、翅膀、武器、盾牌）必须用 localToWorldXY(jointX, jointY, partYaw, -pivotX, -pivotY) 把旋转枢轴锁死在关节处，彻底消除大幅摆动时的 1~2px 挤捏缝；
  - 浸水/贴地交互：禁止对宽精灵用 2D 水平 rect() 一刀切（会切出齐平黑边）；改按 3D 深度柔化透明，并在**角色绘制之后**向 dctx 叠加前景破水白沫弧 / 落地扬尘，把角色真正嵌进场景。
- 技能全程骨骼联动：全部技能蓄力、出手、爆发、收招均由骨骼连续插值驱动，严禁冻结在静态帧。HUD 面板保持紧凑（max-width ≤ 420px），巡游路径不钻入面板背后。

### 4. 强制「Node 量化断言 → 浏览器实机多视角审片」闭环
1. 先跑 Node 自动化脚本，全部通过方可进浏览器：
   - JS 语法检查 + 中文可见文案禁用词检查；
   - 色表 ≤ 48 色、0 重色、0 未着色体素、0 孤立点、全套建模耗时 < 40ms；
   - **关键锚点可见性射线断言**：双眼与武器亮核沿 +Y 与 0.6 俯视射线 0 遮挡；
   - **关节衔接与防穿模断言**：验证站立/俯身各关节世界坐标误差 < 1 格；遍历全周期验证互斥部件（如裙摆 vs 尾链）最小带符号净空 > 0。
2. 本地静态服务 + 浏览器实机检验并**亲自查看截图**：
   - Console 0 报错；自动旋转/巡游/技能爆发全程 60~120fps（单帧 < 1.0ms）；
   - 多角度近景核查（正斜、正侧、背斜）：零穿模、尾鳍/翼根零挤捏缝、actorBuf 整体轮廓无内部黑线且极值动作零裁边、巡游体态符合真实生物规律、HUD 无遮挡。发现瑕疵必须修完复测后再交付。
```

## 二、高发踩坑速查表（供 AI 审核与自检）

| 现象 | 根因 | 修复方式 |
|---|---|---|
| 待机抽搐生硬、技能演出僵死不动 | 用 6~8fps 整块 8 帧翻页且技能锁死单帧 | 升级为 v3 模块化小部件 + 120fps 连续运动学骨骼 + 技能全程骨骼插值 |
| 拆部件骨骼化后角色满身黑线像拼装玩具 | 对每个小部件单独描边 | 裸图缓存后在局部 `actorBuf` 深度拼合再做 **1 次**整体外轮廓（强鳞节蛇类除外） |
| 尾巴/四肢与裙摆/甲片穿模 | 裙摆过低 + 尾根立刻弯入裙摆范围 | 抬高裙摆底沿留 Z 净空，尾根前两节先垂直下延离开裙沿，加 `bias` 偏置并用 Node 断言净空 `> 0` |
| 尾鳍/翅膀大幅甩动时根部出现 1~2px 挤捏缝 | 部件围绕盒中心而非真实关节枢轴旋转 | 用 `localToWorldXY(jointX, jointY, yaw, -px, -py)` 把旋转轴心锁死在关节上 |
| 巡游像“浮空平移的硬物体” | 竖直定姿匀速绕圆 + 角色 100% 画在背景上方 | 切换俯身泳姿/飞行压弯/弹跳步态 + 脉冲推进节律 + **角色后绘前景破水白沫弧/落地尘圈** |
| 用 2D 水平 `rect()` 裁切水面把宽尾鳍劈出齐平黑边 | 0.6 俯视下高于水面的近端边缘落于中心水面线下方 | 去掉 2D 矩形硬裁，改按 3D 浸水深度柔化透明 + 前景水沫覆盖层 |
| 水面静态白斑/通长直线抢戏，看不清动态尾流 | 池底纹理加了太多亮白斑块和平行长直线 | 池底保持干净深浅水色，改用短小柔和波弧，把纯白留给动态破水环与双线 V 形尾流 |
| 转动视角帧率从 120fps 暴跌到 30~40fps | 按 Retina 物理 `SCALE` 烘焙 + 全屏 `dctx.filter=blur` + 全屏中间层 Overdraw | 固定 `BAKE_SCALE=2.5` + 复用 2 张 scratch 与对象池 + `minGlowZ` 剪枝 + 1/4 `ebctx` 模糊 + 2× 地表缓冲直绘 `dctx` |
| 高分斜角下斜管/翅膀现百叶窗层间黑缝 | `HS (0.8) > TILT (0.6)` 错位层露出 `0.2 × SCALE` 空隙 | 烘焙时启用双子步压实绘制（`yy + BAKE_HALF`） |
| 角色游/飞到左上角被控制面板遮住 | HUD 卡片过宽或巡游轨道半径过大 | 控制 `.card` `max-width ≤ 420px` 并收紧巡游半径，保证 `1280×800` 下全轨道清晰可见 |
| 眼睛或亮核在默认俯视下被挡住 | 没列空间坐标预算表，上方结构压住眼层 | 动工前写预算表并用 `+Y` / `0.6` 俯视射线脚本断言遮挡数 = `0` |
| 旋转到背面时明暗反转 | 切片里画了左亮右暗方向光 | 改为纯垂直明暗（`z` 高度 + `topEmpty` + 上方 3×3 腔体 AO + `botEmpty`） |
| 细小部件或眼眶周围一圈发黑 | Crease AO 一刀切压暗细部件邻边 | 给 Crease AO 加 `NO_CREASE_LUT` 免暗缝白名单 |
| 转多圈后点重置视角疯狂倒转 | 直接把累积角 `th` 往 `thTarget` 插值 | 重置前把 `th` 规整到 `[thTarget - π, thTarget + π]` 最短角区间 |
