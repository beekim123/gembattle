# 设计文档：UI-04 六生态可旋转像素地面与 3D 像素战斗特效（`Code00ArtPacks.groundVfx`）

## 一、核心痛点与视觉目标（彻底终结 2D/3D 割裂感）

- **旧版问题**：
  - 旧地面是 `1920×1080`（8.3MB）的平滑 2D 矢量草地墙纸，既吃显存又无法跟着 3D 镜头角 `th` 旋转，且残留了大量 2D 假树/假帐篷/假石门，与工坊 3D 像素堆叠角色严重割裂；
  - 旧战斗特效（`attack-fx.js` 与 `bolts`）全是平滑 2D 矢量圆球、贝塞尔弧线、软边 `shadowBlur`，不仅画风割裂，还无法跟 3D 旋转视角联动。
- **重做目标（100% 像素统一 + 360° 丝滑旋转 + 120fps）**：
  1. **8 套无缝/大视野可旋转像素地面纹理（`384×384` 像素原图，单套约 0.56MB，总计 ≤ 6MB）**：
     - 像素质感与工坊 `./core/habitats.js` 同源（逐像素/块面像素绘制，`imageSmoothingEnabled = false`）；
     - **严禁画圆形展示台边框，严禁画任何 2D 树/帐篷/石门/石碑/树洞**（那些立体物体全由工坊 3D 像素模型摆上去！地面只负责铺地貌纹理、路面、水洼、碎叶、青苔、木纹）；
     - 边缘像素与中心色系过渡自然，支持 `WorldStage` 以 3D 仿射矩阵 `(c*SC, TILT*s*SC, -s*SC, TILT*c*SC)` 旋转压扁铺满 16:9 全屏而不穿帮、不露白边！
  2. **全部微粒与战斗特效升级为「3D 世界坐标驱动的硬像素特效」**：
     - 所有位置均从 3D 世界坐标 `[wx, wy, wz]` 经调用方传入的 `proj(wx, wy, wz) -> [sx, sy, depth]` 映射到屏幕（坐标系约定：1 格体素对应工坊世界 1 单位，主角通常在 `(0, +30, 0)`，怪在 `(x, -26, 0)`，屏幕投影 `TILT = 0.6, HS = 0.8`）；
     - 无论玩家把视角旋转到任何角度，生态落叶/火屑、主角七色宝石弹丸、补色合白环形波、彩虹爆发、破盾碎晶、8 只怪各自出手特效，**全部随着 3D 空间同步透视旋转**，且全由硬边像素块/阶梯像素菱形/像素裂纹构成，和堆叠模型 100% 同一画风！

## 三、3D 像素战斗特效与微粒规格

### 1. 生态 3D 像素微粒（`drawGroundAmbient3D`）
- `forest`：缓慢斜飘的 2~3px 像素绿/金落叶 + 偶有 1 颗红果在边缘落弹；
- `swamp`：水洼上空升起像素小泡与贴地压扁像素涟漪环 + 极淡像素雾带；
- `meadow`：飘浮的 2px 暖金像素花粉；
- `ruins`：缓升的淡青苔孢像素点与细白暖汽像素块；
- `canopy`：斜掠过空的像素风线与疾飞碎叶（速度乘 `wind`）；
- `camp`：围绕中央 `(0, 0)` 螺旋升腾的暖金/橘红像素火屑；
- `trade`：低空轻飘的暖色像素浮尘；
- `gate`：沿石门附近飘落的青苔像素细屑。

### 2. 主角施法与爆发 3D 特效（`drawSpellBolt3D` / `drawImpactWave3D`）
- **`drawSpellBolt3D(ctx, bolt, proj)`**：
  - `bolt = { from: [wx,wy,wz], to: [wx,wy,wz], k: 0..1, art: 'red'|'green'|'blue'|'white'|'rainbow', big: bool }`；
  - 沿 3D 抛物微弧飞行：前方是一颗带暗描边与亮心的**多面体像素晶弹**，身后拖着 4~5 节递减大小的像素方格星屑尾迹（`rainbow` 时尾迹逐节变七色）。
- **`drawImpactWave3D(ctx, kind, centerW, k, proj)`**：
  - `white_wave`（补色合白）：以 `centerW` 为中心贴地扩开的像素白色菱环 + 四散像素星晶；
  - `rainbow_burst`（彩虹爆发）：三道错相扩开的七彩阶梯像素环 + 向上迸溅的七色像素方块雨；
  - `shield_shatter`（破盾碎晶）：12~16 片带高光边的青白菱形像素护盾碎片按 3D 重力抛物线四溅落地；
  - `ward_block`（护壁格挡）：主角身前展开六边形青白像素盾阵并弹开火星。

### 3. 8 只怪专属 3D 像素出手特效（`drawAttackFx3D(ctx, kind, k, fromW, toW, proj)`）
1. `spit`（水滴软泥）：3D 抛物线蓝绿像素水团，落地炸开 8 颗重力像素水滴与贴地像素水环；
2. `puff`（草茎绵羊）：沿 3D 直线滚涌一串像素白绒毛团，命中迸出十字像素撞击星芒；
3. `club`（拾荒地精）：目标头顶像素木棒重砸轨迹弧 + 地面震开像素碎石与裂纹；
4. `petals`（花甸灵精）：9 片粉白像素花瓣沿 3D 螺旋轨飞向主角；
5. `fruit`（摇果长臂猿）：高弧抛掷带绿蒂的像素大红果，砸中主角炸开深红像素果汁花；
6. `claw`（五尾赤豹）：主角身前斜劈出三道带白芯的灼红阶梯像素爪痕；
7. `bite`（腹口懒兽）：上下两排硬像素尖牙在主角 3D 位置猛然合拢并迸出像素星点；
8. `roots`（千丈古树精）：4~5 根粗壮棕褐像素尖刺树根从主角脚下地面破土窜出，四周飞起泥土像素块。

## 四、技术硬红线与精确导出接口

**全局登记**：
```js
window.Code00ArtPacks = window.Code00ArtPacks || {};
window.Code00ArtPacks.groundVfx = {
  id: 'groundVfx', version: 1, name: '...',
  BIOME_IDS: ['forest', 'swamp', 'meadow', 'ruins', 'canopy', 'camp', 'trade', 'gate'],
  init, buildGroundTile, drawGroundAmbient3D, drawSpellBolt3D, drawImpactWave3D, drawAttackFx3D
};
```

- **零 `ctx.filter`、零 `shadowBlur`、零外部图片/字体 URL、零禁用字**；
- **`buildGroundTile(biomeId, makeCanvas, size = 384)`**：
  - 返回 `{ canvas, size, biomeId }`，**内部按 `biomeId + '_' + size` 做缓存复用**（多次调用同一生态不重复新建画布！）；
  - 全部 8 套地面缓存合计内存严格 `<= 6 MB`（建议默认 `size = 384`，8 套总计仅 `4.5 MB`），单套构建耗时 `<= 30 ms`；
- **状态整洁与无 NaN**：所有绘制结束必须 `restore()`，关平滑 `imageSmoothingEnabled = false`，任意 `k ∈ [0, 1]` 零报错零 NaN。

  const HABITAT_MAP = Object.create(null);
  for (const h of HABITAT_DEFS) HABITAT_MAP[h.id] = h;

  const platformCache = Object.create(null);

  function buildHabitatPlatform(habitatId, makeCanvas, size = 200) {
    const def = HABITAT_MAP[habitatId] || HABITAT_DEFS[0];
    if (platformCache[def.id]) return platformCache[def.id];

    const base = makeCanvas(size, size);
    const bg = base.getContext('2d');
    const bim = bg.createImageData(size, size);
    const half = size * 0.5;
    const rOuter = size * 0.485;
    const rRim = size * 0.435;
    const rInner = size * 0.405;

    const rgba = {};
    for (const k in def.pal) rgba[k] = hexToRgba(def.pal[k]);

    for (let y = 0; y < size; y++) {
      for (let x = 0; x < size; x++) {
        const dx = x - half, dy = y - half;
        const dist = Math.hypot(dx, dy);
        if (dist > rOuter) continue;

        const ang = Math.atan2(dy, dx);
        const wave = Math.sin(ang * 8) * 1.3 + Math.cos(ang * 5) * 0.9;
        const n1 = periodicNoise2(x, y, 64, 64, 16, 19);
        const n2 = periodicNoise2(x + 13, y + 7, 32, 32, 8, 47);
        const v = n1 * 0.62 + n2 * 0.38;

        let key = 'mid';
        if (def.id === 'tavern') {
          if (dist > rRim) {
            const seg = ((ang + Math.PI) / (Math.PI * 2)) * 32;
            const seam = Math.abs(seg - Math.round(seg)) < 0.08;
            if (dist > rOuter - 2.0) key = 'deep';
            else if (seam) key = 'deep';
            else key = ((Math.floor(seg) & 1) ? (v > 0.56 ? 'stoneHi' : 'rimB') : 'rimA');
          } else if (dist > rInner) {
            const seg = ((ang + Math.PI) / (Math.PI * 2)) * 28;
            const seam = Math.abs(seg - Math.round(seg)) < 0.08;
            const isHearthArc = Math.abs(ang + Math.PI * 0.5) < 0.46 && dist < rInner + 3.2;
            if (isHearthArc && ((Math.floor(seg * 2) & 1) === 0)) key = 'hearth';
            else if (seam || dist < rInner + 1.2) key = 'deep';
            else key = ((Math.floor(seg) & 1) ? 'rimB' : (v > 0.58 ? 'stoneHi' : 'rimA'));
          } else if (dist <= 44.0) {
            // 中央金边绛红圆形编织地毯
            const weave = ((x + y) & 1) ^ (((x >> 1) + (y >> 1)) & 1);
            const petal = Math.sin(ang * 16);
            if (dist > 41.6) {
              key = (petal > 0.15) ? 'speck' : 'rugDark';
            } else if (dist > 37.8) {
              const motif = Math.abs(Math.sin(ang * 12));
              key = (dist > 39.2 && dist < 40.4 && motif > 0.45) ? 'rugDark' : 'speck';
            } else if (dist > 17.5 && dist < 20.5) {
              key = (Math.sin(ang * 8) > -0.25) ? 'speck' : 'rugHi';
            } else if (dist < 7.5) {
              const centerDiamond = Math.abs(dx) + Math.abs(dy);
              key = centerDiamond < 5.2 ? 'speck' : 'rugHi';
            } else {
              if (v > 0.68 && weave) key = 'rugHi';
              else if (v < 0.34 || !weave) key = 'rugDark';
              else key = 'foam';
            }
          } else {
            // 深暖胡桃木拼接长条木板（板缝清晰、带微木纹）
            const plankH = 11;
            const rowIdx = Math.floor(y / plankH);
            const inRowY = y - rowIdx * plankH;
            const jointX = (x + rowIdx * 37) % 36;
            const grain = Math.sin(x * 0.16 + rowIdx * 1.9 + n1 * 3.2);
            if (inRowY === 0 || jointX === 0) {
              key = 'deep';
            } else if (inRowY === 1) {
              key = grain > 0.15 ? 'hi' : 'mid';
            } else if (inRowY === plankH - 1) {
              key = 'deep';
            } else {
              const rowTone = (rowIdx * 13) % 3;
              if (grain > 0.48 || (rowTone === 0 && v > 0.56)) key = 'hi';
              else if (grain < -0.58 && rowTone === 2) key = 'deep';
              else key = 'mid';
            }
          }
        } else if (dist > rRim + wave * 0.45) {
          key = (dist > rOuter - 2.2 || v > 0.66) ? 'foam' : (v < 0.38 ? 'deep' : 'mid');
        } else if (dist > rInner + wave * 0.4) {
          const seg = ((ang + Math.PI) / (Math.PI * 2)) * 26;
          const seam = Math.abs(seg - Math.round(seg)) < 0.09;
          key = seam ? 'rimA' : ((Math.floor(seg) & 1) ? 'rimB' : 'rimA');
        } else {
          if (def.id === 'desert') {
            const dune = Math.sin((x * 0.12 + y * 0.08) + n1 * 2.2);
            key = dune > 0.45 ? 'hi' : (dune < -0.4 ? 'deep' : 'mid');
            if (v > 0.74) key = 'foam';
          } else if (def.id === 'oasis') {
            // 沙地环抱中央浅碧绿洲水潭 + 岸边棕榈草缘
            const poolR = 46 + Math.sin(ang * 3 + n1 * 2.4) * 7.5;
            if (dist < poolR - 5) key = (v > 0.52) ? 'mid' : 'deep';
            else if (dist < poolR) key = 'foam';
            else if (dist < poolR + 9 && n2 > 0.42) key = 'speck';
            else key = (v > 0.58) ? 'hi' : 'rimB';
          } else if (def.id === 'sky') {
            const puff = Math.sin(x * 0.09) * Math.cos(y * 0.09) + v;
            key = puff > 0.85 ? 'foam' : (puff > 0.45 ? 'hi' : (puff > 0.15 ? 'mid' : 'deep'));
          } else if (def.id === 'thunderPeak') {
            const bolt = Math.abs(Math.sin(x * 0.08 + y * 0.06 + n1 * 4.2));
            if (bolt < 0.06 && dist < rInner - 10 && n2 > 0.58) key = bolt < 0.025 ? 'speck' : 'foam';
            else key = v > 0.66 ? 'hi' : (v < 0.36 ? 'deep' : 'mid');
          } else if (def.id === 'iceSea') {
            // 洁白冰面裂开深蓝冰缝
            const fissure = Math.abs(Math.sin(x * 0.065 - y * 0.045 + n1 * 3.2));
            if (fissure < 0.14 && dist < rInner - 4) key = fissure < 0.07 ? 'deep' : 'mid';
            else key = v > 0.56 ? 'foam' : (v > 0.34 ? 'speck' : 'hi');
          } else if (def.id === 'openSea') {
            const swell = Math.sin(y * 0.14 + Math.sin(x * 0.05) * 2.0 + n1 * 1.4);
            if (swell > 0.86) key = 'foam';
            else if (swell > 0.30) key = 'hi';
            else if (swell < -0.35) key = 'deep';
            else key = 'mid';
          } else if (def.id === 'stoneBay') {
            // 浅滩鹅卵石 + 岸边岩缝 + 漫过浅水
            const riverBand = Math.sin(x * 0.045) * 16 + dy;
            if (Math.abs(riverBand) < 26 + n1 * 12) key = (v > 0.62) ? 'foam' : (v > 0.35 ? 'mid' : 'deep');
            else key = (n2 > 0.68) ? 'speck' : (v > 0.46 ? 'hi' : 'rimB');
          } else if (def.id === 'canopy') {
            // 粗壮树干横枝 + 层叠叶冠
            const branch = Math.abs(Math.sin((dx * 0.032 - dy * 0.028) + n1 * 1.8));
            if (branch < 0.18 && dist < rInner - 6) key = v > 0.5 ? 'speck' : 'rimB';
            else key = v > 0.72 ? 'foam' : (v > 0.50 ? 'hi' : (v < 0.30 ? 'deep' : 'mid'));
          } else if (def.id === 'bamboo') {
            // 竹林地台 + 横向竹节纹 + 散落竹叶
            const stalk = ((Math.round(x + n1 * 3) % 14) === 0);
            const node = ((y % 18) === 0 && (x % 14) < 3);
            if (node) key = 'foam';
            else if (stalk) key = 'deep';
            else if (n2 > 0.80 && ((x + y) & 3) === 0) key = 'speck';
            else key = v > 0.64 ? 'hi' : (v < 0.34 ? 'deep' : 'mid');
          } else if (def.id === 'cave') {
            // 地下暗河贯穿深色溶洞岩台
            const stream = Math.abs(dx + Math.sin(dy * 0.06) * 18);
            if (stream < 18 + n1 * 8) key = (stream > 14 && v > 0.52) ? 'foam' : 'deep';
            else key = v > 0.66 ? 'hi' : (v < 0.32 ? 'speck' : 'mid');
          } else if (def.id === 'volcano') {
            const crack = Math.abs(Math.sin(x * 0.07 + n1 * 3.8) + Math.cos(y * 0.07 - n2 * 2.5));
            if (crack < 0.14 && dist < rInner - 6) key = crack < 0.06 ? 'foam' : 'speck';
            else key = v > 0.64 ? 'hi' : (v < 0.34 ? 'deep' : 'mid');
          } else if (def.id === 'forest') {
            if (n2 > 0.86 && ((x * 5 + y * 3) & 7) === 0) key = 'foam';
            else if (v > 0.66) key = 'hi';
            else if (v < 0.32) key = 'deep';
            else if (n2 > 0.78) key = 'speck';
            else key = 'mid';
          } else if (def.id === 'meadow') {
            if (n2 > 0.84 && ((x + y) & 3) === 0) key = ((x * 7 + y) & 1) ? 'foam' : 'speck';
            else key = v > 0.65 ? 'hi' : (v < 0.34 ? 'deep' : 'mid');
          } else if (def.id === 'ruins') {
            const tile = (x % 16 === 0 || y % 16 === 0);
            if (tile) key = 'speck';
            else if (v > 0.70) key = 'foam';
            else key = v > 0.55 ? 'hi' : (v < 0.35 ? 'deep' : 'mid');
          } else if (def.id === 'tideflat') {
            if (v > 0.56) key = v > 0.72 ? 'speck' : 'hi';
            else if (v > 0.48) key = 'foam';
            else key = v > 0.32 ? 'mid' : 'deep';
          } else if (def.id === 'carcass') {
            // 黑褐腐土打底 + 5 道白色肋骨拱（带暗边）+ 淡青菌斑
            key = v > 0.66 ? 'hi' : (v < 0.36 ? 'deep' : 'mid');
            for (let k = 0; k < 5; k++) {
              const ribX = 42 + k * 29 + Math.sin(y * 0.036 + k * 0.9) * 9;
              const dRib = Math.abs(x - ribX);
              if (Math.abs(dy) < 70 && dRib < 2.7) { key = 'foam'; break; }
              if (Math.abs(dy) < 70 && dRib < 4.0) { key = 'rimA'; break; }
            }

(function (PW) {
  const TAU = Math.PI * 2;
  const clamp = (v, a, b) => Math.max(a, Math.min(b, v));
  const lerp = (a, b, t) => a + (b - a) * t;
  const smoothstep = (e0, e1, x) => {
    const t = clamp((x - e0) / (e1 - e0), 0, 1);
    return t * t * (3 - 2 * t);
  };
  const smin = (a, b, k) => {
    const h = clamp(0.5 + 0.5 * (b - a) / k, 0, 1);
    return lerp(b, a, h) - k * h * (1 - h);
  };
  const expSmooth = (dt, speed) => 1 - Math.exp(-Math.max(0, dt) * speed);
  const wrapAngle = (a) => ((((a + Math.PI) % TAU) + TAU) % TAU) - Math.PI;
  const lerpAngle = (a, b, t) => a + wrapAngle(b - a) * t;

  // 局部坐标转世界坐标（正面 +Y，绕 Z 轴旋转 yaw）
  function localToWorldXY(rx, ry, yaw, lx, ly) {
    const cy = Math.cos(yaw), sy = Math.sin(yaw);
    return [rx + cy * lx - sy * ly, ry + sy * lx + cy * ly];
  }

  // 关节枢轴锁死摆放：若部件真实旋转轴在局部 (px, py)，返回体素盒中心的世界坐标
  function pivotToWorldXY(jointX, jointY, partYaw, pivotX, pivotY) {
    return localToWorldXY(jointX, jointY, partYaw, -pivotX, -pivotY);
  }

  // 绕 X 轴向前倾倒（pitch > 0 时 +Z 倒向 +Y）
  function pitchPt(pt, pitch, pivotY, pivotZ) {
    const cp = Math.cos(pitch), sp = Math.sin(pitch);
    const dy = pt[1] - pivotY, dz = pt[2] - pivotZ;
    return [pt[0], pivotY + dy * cp + dz * sp, pivotZ - dy * sp + dz * cp];
  }

  function distSeg3Sq(px, py, pz, ax, ay, az, bx, by, bz) {
    const abx = bx - ax, aby = by - ay, abz = bz - az;
    const apx = px - ax, apy = py - ay, apz = pz - az;
    const denom = abx * abx + aby * aby + abz * abz || 1;
    const t = clamp((apx * abx + apy * aby + apz * abz) / denom, 0, 1);
    const dx = apx - abx * t, dy = apy - aby * t, dz = apz - abz * t;
    return [dx * dx + dy * dy + dz * dz, t];
  }

  function distTri3Sq(px, py, pz, a, b, c) {
    const abx = b[0] - a[0], aby = b[1] - a[1], abz = b[2] - a[2];
    const acx = c[0] - a[0], acy = c[1] - a[1], acz = c[2] - a[2];
    const apx = px - a[0], apy = py - a[1], apz = pz - a[2];
    const d1 = abx * apx + aby * apy + abz * apz;
    const d2 = acx * apx + acy * apy + acz * apz;
    if (d1 <= 0 && d2 <= 0) return apx * apx + apy * apy + apz * apz;
    const bpx = px - b[0], bpy = py - b[1], bpz = pz - b[2];
    const d3 = abx * bpx + aby * bpy + abz * bpz;
    const d4 = acx * bpx + acy * bpy + acz * bpz;
    if (d3 >= 0 && d4 <= d3) return bpx * bpx + bpy * bpy + bpz * bpz;
    const vc = d1 * d4 - d3 * d2;
    if (vc <= 0 && d1 >= 0 && d3 <= 0) {
      const v = d1 / (d1 - d3);
      const qx = apx - abx * v, qy = apy - aby * v, qz = apz - abz * v;
      return qx * qx + qy * qy + qz * qz;
    }
    const cpx = px - c[0], cpy = py - c[1], cpz = pz - c[2];
    const d5 = abx * cpx + aby * cpy + abz * cpz;
    const d6 = acx * cpx + acy * cpy + acz * cpz;
    if (d6 >= 0 && d5 <= d6) return cpx * cpx + cpy * cpy + cpz * cpz;
    const vb = d5 * d2 - d1 * d6;
    if (vb <= 0 && d2 >= 0 && d6 <= 0) {
      const w = d2 / (d2 - d6);
      const qx = apx - acx * w, qy = apy - acy * w, qz = apz - acz * w;
      return qx * qx + qy * qy + qz * qz;
    }
    const va = d3 * d6 - d5 * d4;
    if (va <= 0 && (d4 - d3) >= 0 && (d5 - d6) >= 0) {
      const w = (d4 - d3) / ((d4 - d3) + (d5 - d6));
      const qx = bpx - (c[0] - b[0]) * w, qy = bpy - (c[1] - b[1]) * w, qz = bpz - (c[2] - b[2]) * w;
      return qx * qx + qy * qy + qz * qz;
    }
    const denom = 1 / (va + vb + vc || 1);
    const v = vb * denom, w = vc * denom;
    const qx = apx - abx * v - acx * w, qy = apy - aby * v - acy * w, qz = apz - abz * v - acz * w;
    return qx * qx + qy * qy + qz * qz;
  }

  function hash2i(ix, iy, seed) {
    let h = (ix * 374761393 + iy * 668265263 + seed * 1442695041) | 0;
    h = Math.imul(h ^ (h >>> 13), 1274126177);
    return ((h ^ (h >>> 16)) >>> 0) / 4294967295;
  }

  function periodicNoise2(x, y, periodX, periodY, cell, seed) {
    const gx = x / cell, gy = y / cell;
    const px = Math.max(1, Math.round(periodX / cell));
    const py = Math.max(1, Math.round(periodY / cell));
    const ix = Math.floor(gx), iy = Math.floor(gy);
    const fx = gx - ix, fy = gy - iy;
    const ux = fx * fx * (3 - 2 * fx), uy = fy * fy * (3 - 2 * fy);
    const wMod = (v, m) => ((v % m) + m) % m;
    const x0 = wMod(ix, px), x1 = wMod(ix + 1, px);
    const y0 = wMod(iy, py), y1 = wMod(iy + 1, py);
    return lerp(
      lerp(hash2i(x0, y0, seed), hash2i(x1, y0, seed), ux),
      lerp(hash2i(x0, y1, seed), hash2i(x1, y1, seed), ux),
      uy
    );
  }

  // 1D/2D 连续平滑值噪声（P5.js noise 风格，用于自然漂浮、微动与呼吸）
  function valueNoise1(x, seed = 11) {
    const ix = Math.floor(x);
    const fx = x - ix;
    const u = fx * fx * (3 - 2 * fx);
    return lerp(hash2i(ix, 0, seed), hash2i(ix + 1, 0, seed), u);
  }

  function fbm1(x, seed = 11, octaves = 3) {
    let sum = 0, amp = 0.5, freq = 1, norm = 0;
    for (let i = 0; i < octaves; i++) {
      sum += valueNoise1(x * freq, seed + i * 31) * amp;
      norm += amp;
      amp *= 0.5;
      freq *= 2.03;
    }
    return sum / (norm || 1);
  }

  function hexToRgba(hex) {
    const n = parseInt(hex.slice(1), 16);
    return [(n >> 16) & 255, (n >> 8) & 255, n & 255, 255];
  }

  PW.Math = {
    TAU, clamp, lerp, smoothstep, smin, expSmooth, wrapAngle, lerpAngle,
    localToWorldXY, pivotToWorldXY, pitchPt, distSeg3Sq, distTri3Sq,
    hash2i, periodicNoise2, valueNoise1, fbm1, hexToRgba
  };
})(window.PixelWorkshop);

const canvases = [];
function makeCtx() {
  const grad = { addColorStop() {} };
  const state = { filter: 'none', shadowBlur: 0, globalAlpha: 1, imageSmoothingEnabled: true, fillStyle: '#000', strokeStyle: '#000', lineWidth: 1 };
  let runtimeFilterSet = false, runtimeShadowSet = false, badCoord = false;
  const checkNums = (args) => { for (const a of args) if (typeof a === 'number' && !Number.isFinite(a)) badCoord = true; };
  return new Proxy(state, {
    get(o, k) {
      if (k === '__flags') return { runtimeFilterSet, runtimeShadowSet, badCoord };
      if (k in o) return o[k];
      if (k === 'createLinearGradient' || k === 'createRadialGradient') return () => grad;
      if (k === 'createImageData') return (w, h) => ({ width: w, height: h, data: new Uint8ClampedArray(Math.max(1, w) * Math.max(1, h) * 4) });
      return (...args) => { checkNums(args); };
    },
    set(o, k, v) {
      if (k === 'filter' && v && v !== 'none') runtimeFilterSet = true;
      if (k === 'shadowBlur' && Number(v) > 0) runtimeShadowSet = true;
      o[k] = v;
      return true;
    }
  });
}
function makeCanvas(w = 1, h = 1) {
  const c = { width: Math.max(1, Math.round(w)), height: Math.max(1, Math.round(h)), _ctx: null, getContext() { if (!this._ctx) this._ctx = makeCtx(); return this._ctx; } };
  canvases.push(c);
  return c;
}
